# Run Details producer diagnostic

The Runtime Run Details contract includes an optional, nullable
method_execution_producer_diagnostic. The dashboard validates its bounded
emission inventory, exact artifact-reference kinds and profiles, reference
status coherence, and contiguous emission indexes before exposing it through
the typed RunDetailsView.

This diagnostic is labeled candidate_only. Its presence does not establish
workflow authority, scientific validity, or publication authority. It does not
replace or modify the separately owner-bound direct-method selection shown by
the HTE summary.
