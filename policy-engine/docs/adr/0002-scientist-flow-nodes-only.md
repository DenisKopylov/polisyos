# ADR-0002: Сводим Scientist на flow_nodes-only

- **Дата**: 2026-01-12
- **Решение**: Единственный публичный вход Scientist — `build_workflow()` и `run_experiment()` на базе `flow_nodes.py`. Все legacy-ноды (`orchestrator/nodes.py`, прочие вспомогательные сохранения в `logs/`) переносятся в `_legacy/` с DeprecationWarning и исключаются линтером.
- **Контекст**: В оркестраторе сосуществуют два пути исполнения: новый LangGraph workflow и старый набор нод с прямыми вызовами Foundry и записью в `logs/`. Это создаёт параллельные миры и несогласованность артефактов.
- **Последствия**:
  - Публичный API Scientist ограничен официальными функциями.
  - Legacy-импорты сигналят DeprecationWarning и запрещены в production-коде.
  - Запись артефактов унифицируется через runtime API (`runs/<run_id>/...`), директория `logs/` не создаётся workflow-путём.
- **Точка удаления**: через 60 дней или два минорных релиза после деплоя ADR (что наступит раньше). После даты T `_legacy`-модули Scientist удаляются, а DeprecationWarning убирается.
