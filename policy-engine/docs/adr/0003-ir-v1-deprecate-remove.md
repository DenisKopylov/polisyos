# ADR-0003: IR v1.0 → deprecate → remove

- **Дата**: 2026-01-12
- **Решение**: Повсеместно принимать только `PolicySurfaceIR` (v2). Для входов v1 использовать единый совместимый загрузчик/миграцию. `PolicyRequestIR` помечается deprecated и удаляется после окончания compat окна.
- **Контекст**: В системе одновременно присутствуют v2 Surface IR (актуальный путь) и v1 PolicyRequestIR (legacy совместимость). Дублирование логики миграции и разных API увеличивает риск расхождений.
- **Последствия**:
  - Входные payloads v1 проходят через единый compat loader и миграцию в v2.
  - API/оркестратор/инструменты не принимают v1 напрямую.
  - Тесты/демо, опирающиеся на v1, переводятся в миграционные тесты или удаляются.
- **Точка удаления**: через 60 дней или два минорных релиза после деплоя ADR (что наступит раньше). После даты T `PolicyRequestIR` и связанные пути удаляются, остаётся только v2.
