`docs/plans/archive/2026-05-07-repository-best-in-class-remediation-master-plan.md`.

Wave 1 should not immediately replace central registries. A safer path is:

1. Add per-package files as report-only inputs.
2. Generate or validate a read-only rollup against current central registries.
3. Keep fail-closed gates reading the existing central files until the rollup is
   proven stable.
4. Promote the rollup source-of-truth only in the later fail-closed conversion
   wave.

The per-package file shape should be narrow: package identity, owners, public
facade, allowed/forbidden dependencies, test topology, shared directory names,
dynamic import slots, generated artifact families, and shim references. Global
layering, repo topology, docs nav, workflows, and lockfiles should stay in
central queue-owned files.
