# Bureaucratic Rendering Law

PolicyOS bureaucratic rendering must look legitimate because it is explicit
about provenance, authorship and draft status, not because it imitates state
authority.

## Product Law

Every official-looking artifact is a draft until signed outside PolicyOS.
Generated documents must carry the visible and machine-readable watermark:

```text
Generated by PolicyOS / Draft / Not an official state document
```

The watermark must appear in the on-screen preview, exported HTML metadata,
PDF/DOCX source metadata and any print surface. It must never be removable by a
genre switch, locale switch or Trust View toggle.

## Required Identity

Every rendered bureaucratic document must expose:

- `packet_id`
- `packet_hash`
- `template.id`
- `template.version`
- `template.legal_review_status`
- `render_timestamp`
- `status = draft` unless an external signing workflow marks otherwise

The template badge is part of the trust layer. It is not decorative chrome.

## Jurisdictional Templates

The first supported Ukrainian genres are:

- `ua.kmu.postanova.v1` — Постанова КМУ
- `ua.rada.zakonoproekt.v1` — Законопроект
- `ua.expert_vysnovok.v1` — Експертний висновок
- `ua.analitichna_zapyska.v1` — Аналітична записка

Template changes require a new version and migration note. Do not silently
change numbering, реквізити, signature placeholders or disclaimer language under
an existing template id.

## Trust Layer

Document blocks must preserve:

- authorship and timestamp where available;
- epistemic origin: evidence-filled, model-generated, operator-filled or
  imported-from-source;
- raw source refs and compact provenance;
- decision-bearing numbers as `QuantityValue` envelopes.

HTML preview must render decision-bearing numbers through `<Quantity>`.
Exported HTML must keep machine-readable quantity and lineage attributes so the
export remains auditable even when it is no longer interactive.

## Official Symbols

PolicyOS must not render real seals, signatures or state authority marks by
default. Symbol-like assets are placeholders unless the asset provenance file
records public-domain or licensed use and a legal/document specialist approves
the template.

## Review Gate

`legal_review_status` is read from
`docs/brand/bureaucratic-template-review.json`. It stays
`pending_external_review` until that registry records an approved Ukrainian
legal/document specialist sign-off for:

- structure and реквізити for all four genres;
- watermark and disclaimer language;
- numbering rules;
- signature and seal placeholders;
- asset provenance.

Until then, UI language may say "draft", "source", "preview" or "template", but
must not say "official", "signed", "adopted" or "state-issued".
