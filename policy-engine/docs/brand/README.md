# Brand Docs

Wave 1 brand and visual-language specifications live here. The DS0 decision is
the governing entry point; v4 documents are retained as dated baseline
evidence used by DS2 comparison and DS4 migration.

## Scope and evidence

These pages contain design rules, accepted design decisions, proposals, and
historical review material. A design rule, Figma frame, Storybook story,
generated image, component, or current dashboard consumer is not by itself a
publishable policy capability or evidence of policy authority. Capability
claims still require the typed contract, producer, persisted artifact/event,
bridge, consumer, verification, and surface evidence required by the failure
and repair register.

For the source-backed dashboard routes, API/client bindings, generated-output
owners, and candidate-versus-authority display semantics inspected at
`bafca83bff9ff49eef1466bc491a8420b5cd1dbb`, start with the
[current frontend surface map](../reference/frontend/current-surface-map.md).
That map records code and test locations; the tests were inspected but not run,
and this documentation pass did not use a browser, server, or deployment.
Historical DS1/DS2/DS6 reports below retain their own dated facts and verdicts;
the current map is not a rerating of those records.

The Storybook Wave 1 folder is a dated static review snapshot. Its scripts and
manifests are not a recording receipt, a current visual review, or a public
deployment record.
