# English ADR Reader Translations

These pages provide English readings of ten historical ADRs whose source
records contain Russian prose or quoted Russian acceptance evidence. The source
records, generated titles, status values, links, and URLs remain unchanged.

Each page identifies its source path, SHA-256, and source snapshot. The
translation is an informational derivative: it does not ratify, amend, promote,
or establish implementation of the source decision. Use the source ADR for
decision provenance and its exact status. In particular, `unknown` and
`accepted` describe the source record as represented in the generated index;
neither label proves that the decision is implemented.
