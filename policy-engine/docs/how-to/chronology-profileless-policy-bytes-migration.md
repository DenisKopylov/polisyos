# Migration for chronology typed bytes containing profileless artifact references

The shared recursive chronology mapper is the compatibility boundary. It is used by several byte and identity routes, and the changed case is conditional: a typed model graph must contain a nested `ArtifactRef.manifest_profile_sha256` with value `None`, whose Pydantic `Field(exclude_if=...)` metadata omits that value. A selected profile remains serialized and content-bound. Required nullable values such as `required_native_head_role` remain explicit `null` when their own field metadata does not exclude them.

The complete source call-site inventory includes `core/contracts/chronology.py`, `core/security/anchor_lineage.py`, `core/security/chronology_anchor.py`, `core/artifacts/signed_evidence.py`, `runtime/quality/chronology_proof.py`, `runtime/quality/semantic_epoch.py`, and `runtime/quality/semantic_epoch_qualification.py`. These paths do not all change on every call: the effect occurs only when the actual typed value graph carries an excluded value. This does not claim that every chronology record, every profileless reference, or every signed artifact contains such a value.

Reader behavior is consumer-specific. The policy/admission reader reports `PolicyBindingMismatchFailure` with `status="rejected"` for the old explicit-null alternate. `parse_canonical_statement` raises `ValueError` when its strict typed reserialization differs from the stored statement bytes. Other signed-record, hash, and projection consumers may observe changed canonical bytes or identities without producing a reader status; their own result semantics remain in force.

New canonical writes use the shared mapper. Keep existing CAS bytes immutable, do not reuse a reference for different bytes, and do not infer an absent profile. An owner may reissue only after it independently resolves the source, selected profile epoch, content, custody, signatures, lineage, and admission bindings. Reissue creates a new reference and digest, and dependent signatures, admissions, lineage edges, and identity projections must be rebuilt and revalidated. Authority and currentness do not transfer automatically.

If required source or custody evidence is unavailable, retain old bytes and report the exact observed typed refusal or limitation. No production CAS census was performed, so the prevalence of this representation and the set of affected production records remain `not_established`. Transparent compatibility for profileless history and bulk replacement are not established or authorized by this change.
