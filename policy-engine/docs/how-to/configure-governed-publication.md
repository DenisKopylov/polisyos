# Configure bounded governed publication

The runtime can publish an exact initial Claim-owner root snapshot for bounded public custody.
It cannot appoint an institution, establish policy performance, establish first publication,
or establish complete history. The production signing slot is empty by default. A report key
configured through `POLISYOS_PUBLIC_VERIFICATION_CONFIG` does not fill it.

## Prepare, authorize, issue

1. For an indexed, tenant-owned run with an admitted current Claim owner, invoke the existing
   authenticated `POST /api/v1/runs/{run_id}/public-verification-record` with query
   `publication_class=governed_public_record_candidate` and no body. The private response gives
   a candidate artifact reference, exact public document and digest; it creates no public URL.
   Unsupported metadata, material private references, transition heads after the initial root,
   or ineligible claims refuse preparation.
2. An external institution supplies a signed `PublicationMandateStatement` persisted in the
   runtime artifact store with its manifest and Ed25519 sidecar. Its schema is defined in
   `src/polisyos/scientist/governance/continuous/governed_public_record_contracts.py`.
   Bind the exact prepared digest, packet, owner scope, ledger, publisher identity/key, profile,
   rule, authority basis, validity interval, custody interval and independently configured
   trust epoch. The mandate purpose is `governed_public_record_mandate`. No HTTP request can
   appoint a signer or submit a substitute source document.
3. Set `POLISYOS_PUBLIC_PUBLICATION_CONFIG` to a JSON file. Relative key paths resolve against
   that file. Its fields are `issuer_id`, optional `private_key_path`, `publisher_trusted_keys`,
   `mandate_trusted_keys`, and optional `mandate_ref` (the existing strict `ArtifactRef` shape).
   Each trust row has `public_key_path`, `issuer_id`, `purposes`, and optional `revoked`.
   Publisher purpose is `governed_public_record`; institutional mandate purpose is distinct.
   The publisher private key must pass the existing restricted-permissions check. No key is
   generated. Malformed configured trust fails startup. Compute the mandate's epoch with
   `publication_trust_epoch` over those actual configured keys and issuer; the mandate reference
   itself is excluded to avoid a content-address cycle.
4. Restart the runtime to load that configuration. Invoke the same POST with
   `publication_class=governed_public_record`. The owner reuses the prepared candidate only
   for the same exact source, checks current eligibility and authorization, signs, persists,
   and verifies readback before returning a `gpr_` public path. Source changes require a new
   candidate and newly bound mandate. Missing or invalid appointment is an honest HTTP 409
   refusal, not a partially issued record.
5. Anonymous `GET /api/v1/public-decisions/verification?record_id={record_id}` and
   `/public/decisions/{record_id}` resolve/render the record. Installed custody maintenance
   separately reads the admission owner's complete controlled index and reconciles it with
   the supplied inventory; omitted/additional IDs or unverifiable governed records refuse a
   watched population. The existing maintenance lifecycle and outbox consume admitted members.

Omitting the query preserves the existing `verification_report_only` response and refusal
semantics. Clients handling governed mode must accept the new discriminated response arm.
The runtime OpenAPI, shared client and dashboard types are regenerated by their existing owners.

## Meaning and retention

Only issuer issuance and exact-profile projection faithfulness may be established. The other
PV-K01 dimensions remain independently `not_established`. Opaque `gph_` handles preserve private
reference equality and JSON types; they are neither CAS hashes nor evidence retrieval URLs.
Every selected raw source field is retained or the profile refuses. The viewer exposes claim
text, statuses, limitations and the complete document. Private source and mandate references
never enter public proof metadata.

Historical verification replays immutable initial-root owner closure rather than asserting today's head
or a historical pending-event cutoff. Revoking a retained key does not erase past issuance or
custody; removing the trust anchor or required retained evidence makes verification fail closed.
Keep the configured verification anchors and private retained source/admission artifacts for
as long as the signature stands. The controlled index does not establish outside publications.

The behavioral commissioning witness is `tests/unit/runtime/http/test_public_export.py`.
Its keys and institution are explicitly synthetic. It demonstrates executable configuration,
HTTP and installed maintenance, and is not evidence of an actual institutional publication.
