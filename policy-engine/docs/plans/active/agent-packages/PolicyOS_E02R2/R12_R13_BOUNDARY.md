# R12/R13 — N7 fixture repair and bounded production route fence

Status: **bounded repair**, not closure of R13. The existing `AcquisitionWorldGrowthBridge` remains the admitted world-growth owner. This change refuses a route-shaped local FileTabular ACQ-01 receipt in a production N6 cycle before it can rebuild a WMR or re-enter N5. Contract-testing retains the synthetic route. The R12 bootstrap checker now classifies the actual read-only registry-entry recomputation by data flow instead of a verifier function name; its claim is limited to the examined constructor census.

## Property and divergence

The property is that a production acquisition cannot create a grown world through the local ACQ-01 route without Data Forge overlay admission, a passport and a qualified epoch. Before this repair, `_reenter_cycle_after_n7_acquisition` could use the route's `capture_store_root` and `grown_world_after_ref`, rebuild a WMR and invoke N5. The production receiver now checks the same mapping shape consumed by `_rebuild_n7_acq01_route_context`, then records `n7_acq01_route_not_admitted` before those operations. A mere `acq01_route` key whose value is `None`, scalar or list is not a route and does not trigger this fence.

The checker’s `owner_entry_recomputations` field denotes locally recomputed entries whose observed uses are read-only comparisons. Its AST predicate does **not** establish that the comparison is against a persisted owner entry: `expected_entry is not None` is a divergent case. It also cannot discover dynamic writers outside the named builder calls. These are declared P38 limitations, not evidence of owner-binding closure. The runtime receiver fence is independent of that checker classification.
