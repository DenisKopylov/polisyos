# R1 source map: trusted run band and candidate computation

**Scope:** source-only R1 design correction after the Phase 0 review. This records an owner-first mechanism and its unresolved witnesses; it is not an implementation or runtime receipt. No source/tests were edited or run for this map. The shared run-intent outcomes and admission fields below coordinate with the R5 proposal in `PolicyOS_E02R2/IMPLEMENTATION_MAP.md@00050e3e` and do not create a second R5 selector.

## Property and present divergence

**Property:** an ordinary authenticated natural-language run can produce and retain a candidate when no `CycleSubstrateContext` is established. It carries that unknown as typed data. Protected, promotion, publication, and S8 authority remain unavailable without their current owner evidence. A protected intent with absent, malformed, stale, or mismatched admission must observably refuse before candidate/simulation completion; it must never become ordinary candidate work by omission.

`NaturalLanguageRunRequest` has an untyped `context: dict[str, Any]`, an `execution_profile`, and policy flags, but no trusted run-intent admission. `launch_nl_run` copies caller context into the persisted payload. `_admit_evaluation_safety_attempt` returns `None` when no attempt key exists. The worker therefore cannot distinguish a normal candidate request from a protected request whose EvalSafety evidence disappeared. `execution_profile` is profile/policy metadata, not a run-band authority. [policy-engine/src/polisyos/core/contracts/control.py@b9a5fe8f66d159a635bc12adeade419f16c5d9d4; policy-engine/src/polisyos/runtime/http/services/control/run_lifecycle.py@a3827ed1677df17f09827d479db7510ffdb70e6e]

The HTTP composition first tries `_build_cycle_substrate_context_from_owner`; if it still has no context, an explicit N4 is rejected. Removing only that HTTP refusal is insufficient: the default `N4GenerationPort.__call__` returns `_N4OwnerContextUnavailableResult` before invoking the existing design-generation owner. The canonical `generate_design_candidate_bundle_under_a` already accepts `cycle_substrate_context=None`. That is a plausible owner route for candidate-only work, not proof of a served path. [policy-engine/src/polisyos/runtime/http/services/control/generation_cycle.py@055cca6c9424deac61fa61543143a2a2d2310b1a:571–586,747–801; policy-engine/src/polisyos/runtime/quality/generation_cycle.py@65d830f71dccd9c3b1e943e5e132678f7221ed8a:1510–1555; policy-engine/src/polisyos/runtime/quality/design_generation.py@81875449b9568232790ae1c4602d75dd51b8e07a:884–925]

The recursive HTTP call currently supplies an empty `evaluation_contexts_by_node` mapping when both EvalSafety and cycle-substrate contexts are absent. The recursive exact-leaf denominator is conditional on a non-empty mapping. This cannot stand in for a durable intent decision. R1 restores only candidate-band computation; R5 independently requires current EvalSafety at every non-simulation leaf. [policy-engine/src/polisyos/runtime/http/services/control/generation_cycle.py@055cca6c9424deac61fa61543143a2a2d2310b1a:654–669; policy-engine/src/polisyos/runtime/quality/recursive_generation_cycle.py@ddff9abd228378166bce8437862ebe487ae00149:823–839]

## One admission owner shared with R5

Use one server-owned, content-bound `RunIntentAdmission` artifact/event from authenticated launch through persisted job, worker replay, and recursive leaf dispatch. Do not add a second R1/R5 admission artifact. Its band is a routing/admission constraint, never authority to promote or publish.

The R5 vocabulary is the shared vocabulary:

| Outcome | Selection rule | Missing or invalid evidence |
|---|---|---|
| `candidate_only` | Positively selected by the versioned server policy for the authenticated ordinary `/runs/nl` action, with no protected mode intent. The client cannot set this band. | Ambiguous action/route or contradictory declared intent is `not_established`, not candidate. |
| `simulate_only_attempt` | A well-formed attempt is resolved by the canonical `resolve_evaluation_mode` owner to `simulate_only`, and the attempt is bound to this job generation. | Absent/malformed attempt does not imply simulation-only. |
| `eval_safety_required` | Server-authenticated action or the canonical resolver identifies non-simulation work. The caller requests an action/mode; it does not supply the band. | Missing/refused/stale EvalSafety evidence is a typed refusal before N6; no fallback. |
| `not_established` | Legacy row, unknown route/action, malformed or contradictory mode, missing admission, failed readback, or failed binding. | Non-runnable; surface the typed refusal and keep the job from completing as a candidate. |

Derive action from the authenticated route registration plus the server-side action policy/version. Where a request can declare a mode, classify that declaration using the canonical evaluation-mode resolver and compare it with the route's allowed action. An explicit protected declaration can never be erased by a missing attempt field. A conflicting route and mode, an unauthenticated action, or an action that cannot be distinguished yields `not_established`. Only the ordinary authenticated NL action can positively select `candidate_only`; neither caller context, an enum in the body, nor a missing field selects it.

Bind at least: schema/rule version; job and run IDs; tenant and authenticated submitting actor; exact payload reference and digest; authenticated route/action and resolved intent; declared-attempt identity and monotonic generation; requested-mode token digest if present; canonical resolver status/mode; selected outcome; creation time; and, for a retry, the predecessor admission digest. Freeze the admission in the runtime-supplied tenant-bound artifact store. Extend the append-only `job_created` event/outbox with the admission reference and digest. The mutable job row is a lookup, not the authority. On worker open, resolve and compare artifact, event, current row, tenant, payload bytes, route/action, run ID, and current attempt generation before dispatch. An unreadable or inconsistent chain is `not_established` and non-runnable.

The row, progress, event, and outbox are presently created in `ControlPlaneStore.create_job`, while the event payload is only `{"state":"pending"}` and `ControlJobRecord` lacks an admission binding/content hash/schema. The owner change must make admission binding atomic with job creation, or provide idempotent recovery that reconciles the exact same admission before any worker dispatch. A CAS artifact left by a failed database transaction is unreferenced and non-authoritative. Legacy rows remain readable but are non-runnable as `not_established`; do not infer a band or restamp old events. [policy-engine/src/polisyos/runtime/http/services/control/control_plane_store.py@4a49eef3c1d7da25e40436c0346778e28df13034:844–867,2398–2462; policy-engine/src/polisyos/runtime/http/services/control/run_lifecycle.py@a3827ed1677df17f09827d479db7510ffdb70e6e:2274–2308,4013–4134]

**Retry/attempt rule:** every admitted execution has a unique generation and exact attempt identity. A retry is a new immutable admission for the same job/run and same declared intent, linked to the previous admission digest and bound to the owner-issued incremented attempt generation; it preserves the outcome and revalidates current EvalSafety for `eval_safety_required`. A worker whose lease/attempt no longer matches cannot consume either admission. A changed route, requested mode, payload, or intent requires a new job/run and a new admission. Ambiguous crash recovery may replay only the identical generation/admission; if ownership or generation cannot be reconciled, refuse as `not_established` instead of creating a candidate fallback. This generation/successor behavior is a proposed owner contract; current source does not establish it.

For `eval_safety_required`, the worker must preserve that outcome when the attempt is absent, malformed, stale, or refused. It may not call the ordinary candidate path and report successful completion. For `candidate_only`, the existing N4 producer and N5 simulation may run without an owner-bound cycle substrate only as candidate work; they must persist the limitation below and cannot produce a protected value, promotion, publication, or S8 authority. `simulate_only_attempt` remains pure computation and does not weaken R5's non-simulation denominator.

## Typed missing-context limitation and historical wrapper replay

The existing `OpenWorldRiskPublicLimitation` is not suitable: it requires a vector artifact reference and describes a different limitation. The compiled HTTP owner already binds `design_problem_ref` to the full `DesignProblem`, binds the recursive root to that ref, and hashes its self-identity projection. Give that owner a dedicated v2 field:

```text
field: cycle_substrate_context_limitation: CycleSubstrateContextLimitation | None
type schema_version: Literal["policyos.runtime.cycle_substrate_context_limitation.v1"]
type status: Literal["not_established"]
type code: Literal["cycle_substrate_context_not_established"]
type design_problem_ref: sha256:<64 lowercase hex>
```

The type is frozen and strict (`extra="forbid"`). The field is present exactly when `cycle_substrate_context_ref is None`, and its `design_problem_ref` must equal the compiled wrapper's ref; when a context ref exists the limitation is absent. This typed unknown is neither a run band nor proof that the candidate is adequately simulated. If N5 lacks its required world substrate, retain an N5 pending/limited result; do not claim a completed world-model simulation. The type is proposed here at the existing compiled-wrapper owner boundary; no new public Open World Risk DTO is needed.

The wrapper schema is currently `policyos.runtime.http.compiled_recursive_generation_cycle.v1`; the new field must not be added to v1. Bump the writer to v2 and dispatch self-identity serialization by schema version. The v1 projection must preserve the exact historical key set, omission/default behavior, and canonical bytes, excluding the new field; the v2 projection includes and hashes the typed limitation. V1 data with an injected v2 field is invalid. Parsing v1 must not synthesize a limitation or upgrade/restamp the old hash. ## Removal probe, preserving control, and R5 separation

**Class-wide removal probe:** keep all outcome enums, field names, wrapper schema markers, job/event IDs, and “protected” strings. Remove or corrupt only the admission artifact/event binding (and test the row-only/mutable-marker variant). Launch a server-authenticated protected action with no current EvalSafety admission. The behavioral assertion must observe `not_established`/typed refusal, no candidate-success terminal state, no N4/N6 candidate completion, and no protected value or S8 authority. Then prove the same test goes red when the admission replay guard is removed: the protected request must reach candidate completion. Do not count a constructor check, marker census, or `ValuePort` not-called assertion alone as the witness. Run a separate variant disabling every admission/replay guard so later S8 guards cannot mask the missing property.

**Candidate-preserving control:** issue the authenticated ordinary `/runs/nl` action with no CycleSubstrateContext and a valid `candidate_only` admission. The real N4 owner must run and persist a candidate with the v2 typed limitation. Where no N5 world substrate exists, assert an N5 pending/limited result rather than inventing a simulation. Assert protected value, promotion, publication, and S8 authority remain absent. This proves the ordinary front door stays useful without treating unknown custody as established.

**R5 separation:** R1's admission determines which run intent was authenticated and durably bound. R5's exact-leaf EvalSafety predicate determines whether every non-simulation leaf consumes the current EvalSafety head. Candidate flexibility does not alter that predicate. Retain the Appendix A `test_non_simulation_leaf_requires_current_eval_safety_head`. R5's proposed `test_eval_safety_required_custom_factory_refuses_unconsumed_context` remains a bounded refusal unless a context-aware custom-factory owner is implemented; do not infer its context consumption from its `(node_ref, problem)` signature. ## P40, decision draft, and gate classification

**P40 bucket:** optional arbitrary context, missing launch selector, mutable-row-only binding, thin job-created event, retry reuse, and recursive empty-map bypass are the same class: **run intent is not durably bound and replayed from authenticated request admission through served leaf execution**. A second such escape widens this single owner mechanism; it is not another instance patch at N4, HTTP, a database field, or an EvalSafety helper.

**Decision draft (R1):**

- **Decision:** allow an authenticated ordinary NL action to compute/retain a candidate under unknown cycle-substrate context; keep protected modes, promotion, publication, and S8 authority bound to current owner evidence.
- **Options and costs:** (A) one immutable server-issued `RunIntentAdmission`, persisted with the job event and consumed through recursive dispatch; cost is owner/store/replay work and an end-to-end witness. (B) refuse all context-free runs until the R13 owner route is complete; cost is continued ordinary-front-door over-refusal. (C) trust client markers or synthesize context; rejected because it converts unknown scope into a custody fact and bypasses the existing owner.
- **Premises:** candidate output is non-authoritative; the route/action classifier is server-owned and versioned; EvalSafety remains its own owner check; no-context WMR is unresolved and N5 may remain limited.
- **Remainder:** served N4-to-S8 positive coverage, tenant-bound WMR context, and cross-run epoch currentness are not established. The S8 fixture's expected result depends on four-base context resolution and a real handoff.
- **Revisit trigger (falsifier):** protected authenticated intent with missing/corrupt admission completes as candidate, or ordinary authenticated NL cannot produce a real candidate with a typed unknown and no authority effect.
- **Where it binds:** launch, durable job/event admission, retries, worker replay, and recursive leaf. It grants no authority to the generated candidate and does not appoint an institutional signer.

**P37:** user-declared mode is intent evidence only. The route/action, tenant/actor, exact payload, intent-policy version, attempt generation, and admission/event equality must be recomputed or independently reconciled. EvalSafety status/head/appointment/evidence remain owner-recomputed/current. Mutable-row presence, a request `run_band`, caller context, an exit status, or an artifact marker cannot satisfy the gate.

**P38:** the property is “the served leaf obeys the authenticated intent admitted for this exact job attempt and preserves unknown substrate scope.” Current code tests optional context/port and optional EvalSafety-attempt presence; its leaf denominator is conditional on a non-empty mapping, and the default N4 returns unavailable when owner resolution has no context. The divergent examples are (1) a protected intent whose attempt field disappears and is indistinguishable from ordinary work, and (2) ordinary candidate intent with owner resolution returning `None`, which currently does not reach N4 candidate computation.

**Limits / not established:** no durable run-intent admission or retry-successor contract is present in current source; no served positive candidate path under missing context has been demonstrated; the root-CAS owner builder does not establish tenant custody; S8 fixture owner-context resolution is unknown until four-base replay; six historical wrapper records require byte-exact replay after v2; no expected-status change is authorized by this map. These are design and verification obligations, not completed repairs.
