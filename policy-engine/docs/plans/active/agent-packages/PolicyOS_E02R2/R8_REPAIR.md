**Repair.** `ControlPlaneStore` carries the worker identity in a store-owned `ContextVar`, which the existing `BlockingDependencyGuard.run` copies to the executor thread. Each protected mutation recomputes the persisted `running + owner + attempt + unexpired lease` predicate. Worker-bound manifest mutation and action-head append are covered alongside the existing complete/fail/progress lifecycle. Unbound pre-enqueue requested-head writes retain their separate owner path, and an unbound direct manifest call still uses its existing job-id-only contract. The action-head predecessor comparison, lease check, insert, and readback occur in one store transaction. This keeps the existing store as the owner.
