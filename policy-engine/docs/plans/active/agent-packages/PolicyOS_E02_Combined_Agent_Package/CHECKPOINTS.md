# Шесть окон CP1–CP6

CP заменяет активное K1–K6 E01; source legacy K01–K36 не перенумерован. Никакого нового окна на каждый LA.

**[CP1](checkpoints/CP1.md) — Первый полезный путь и явные inputs.** 2 кандидата,2–3 метода; real compiler/CAS readback; actual N7 typed/request/resolver path; FRY import/layout/seed preservation; FRC-01 отсутствие выдуманного pass без блокирования честного conditional result.

**[CP2](checkpoints/CP2.md) — Сохранность, данные, поколения и миграции.** Два worker/connector,1MiB queue witness B24, небольшие files/arrays. Отдельно tiny HNSW+NPZ generation/readback, Scholar v1/v2 без live HTTP, Ukraine period/iterator, two-root RunManifest и canon golden bytes. Sequence, не параллельные suites.

**[CP3](checkpoints/CP3.md) — Поиск и доказательная точность diagnostics.** Короткая search history/GP/index и state→service cutover. Calibration100 small observations с empty/valid intervals; BERL2 features; DDM5 states,expiry/mismatch и R2 signoff. Ни больших моделей, ни реального deployment.

**[CP4](checkpoints/CP4.md) — Calibration model и actual execution.** Один механизм,2 старта,2–4 параметра, короткий scan/Hessian/draws. Сохранённые baseline laws/RNG после relocation; один tiny trainer update с actual action influence; FRC bridge только на совместимом estimand. Не статистическая аттестация на всех данных.

**[CP5](checkpoints/CP5.md) — Causal graph/query и исправленные shared helpers.** Малые panels/SCM; конечные200 ADMG/2400 запросов; ordinary/dedicated DiD и old plan replay; active surgery/law. Сборка unsupported RBC/conditional profiles не имитируется labels.

**[CP6](checkpoints/CP6.md) — Итоговая поставка и вывод лишних поверхностей.** Фиксированный integration SHA; один последовательный выбранный regression set и второй пользовательский случай. Один wheel/sdist/installed-import inventory для всех принятых moves/removals, один runtime-client generated-family pass с corruption checks. Native/Linux/server/unavailable matrix явно сохранена.
