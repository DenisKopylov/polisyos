## Поручение и минимальная приёмка

Сохранить явную проекцию групповых координат на node.field. Передавать covariance с этой проекцией и зависимостью полей, а не копировать одну группу как независимые оценки. Условный mean/std-law отделить от эвристического статуса отображаемой полосы.

**Различающие тесты и сохраняемое поведение.** Два поля одной tied-группы имеют дисперсии и cross-covariance=0.0025, оставаясь одной степенью свободы. Переименование группы не теряет envelopes. Отображение уровня 0.8/0.95 не меняет исходный STD=1; heuristic/gate prohibition остаётся. Untied и unknown-STD контроли сохранены.

**Не считать исправлением.** Не угадывать mapping по разбору строки и не ставить confidence_level=0.95 ради правильной формулы extract_std. Произвольная полоса не задаёт Normal-law.

**Цикл работы:** зафиксировать actual scope и нужный characterization; оформить equivalent move и намеренный behavior fix раздельно; выполнить указанные малые tests через I1; независимый reviewer проверяет actual owner; передать commit, path map и остатки. CLI/test selectors разрешаются по настоящему checkout до запуска, не выдумываются из названия находки.

## B197. Связанные параметры получают covariance в другой системе имён и теряют envelopes

**Основание.** При связывании параметров `tie_id` становится `group_id`. Hessian и `CalibrationUncertainty.params` используют эти групповые имена. `calibrated_params` формируется в именах `node_id.field_name`. `envelopes_from_calibration` перебирает второе множество, а `envelope_from_calibration_param` требует точного присутствия ключа в первом. Явной проекции групп на поля на этом переходе нет. [C19.R02; C19.R03]

**Различающий пример.** Два поля `A.rate` и `B.rate` имеют общее значение 0,25 и tied-группу `shared_rate`. При наличии STD=0,05 для группы адаптер возвратил ноль envelopes. В контроле без связывания параметров с совпадающими именами возвратил два. Исходные точки и covariance при этом не обязательно потеряны в самом CalibrationReport — теряется их пригодное downstream-сопоставление. C19-P10–P12.

**Рекомендуемое исправление.** Сохранить отображение групповых координат на конкретные поля и передавать его вместе с результатом. Для точного скалярного равенства θA=θB=g проекция имеет строки [1] и [1], поэтому Σθ=JΣgJᵀ: обе дисперсии и перекрёстная covariance равны 0,0025. Это одна степень свободы, не два независимых свидетельства. Для нелинейного отображения использовать соответствующую локальную либо точную семантику преобразования.

**Минимальная реализация.** Групповое представление остаётся основным; поля получают проверяемые ссылки/alias и проекцию. Не копировать группу как два независимых Normal-распределения, не подгонять имена строковым разбором и не добавлять фиктивные STD. Настоящее отсутствие uncertainty по полю по-прежнему должно давать ограниченный результат.

**Приёмка.** Tied и untied конфигурации сохраняют точные адреса параметров, размерность и зависимость. Изменение технического имени группы не убирает результат. Несовместимые bounds и неразрешённая проекция отвергаются адресно.

**Статус.** Исполнены выбранные producer-loops naming и полный adapter с report-фикстурой; оптимизация и нативный DTO отчёта не запускались. Не касается маршрута без tied-групп либо с дополнительной внешней проекцией.

## B198. Эвристическая полоса Hessian меняет STD при следующем чтении

**Основание.** Адаптер Hessian правильно выдаёт `HEURISTIC_RANGE`, `confidence_level=None`, `is_heuristic_ci=True`, `gate_eligible=False`. В metadata сохраняется действительный вычисленный `std`; границы строятся через z для запрошенного отображаемого уровня. Но `extract_std` читает только границы и confidence level. При `None` использует width/(2√3), игнорируя сохранённый параметр закона. [C19.R03; C19.R04]

**Различающие проверки.** Один и тот же report с STD=1 дал извлечённое STD=1,131585734 при отображаемом уровне 0,95 и STD=0,739904141 при 0,8. В обоих envelopes metadata оставалось `std=1`. Статистический Normal-интервал с известным уровнем корректно восстановил STD=1. Эвристический статус и отсутствие допуска сохранились в положительном контроле. C19-P13–P16.

**Рекомендуемое исправление.** Представление условного закона и статус его обоснованности должны быть раздельны. Передавать типизированный параметрический носитель mean/std либо проверяемую ссылку на covariance; потребитель использует этот закон, сохраняя эвристические ограничения. Metadata допустима как переходный источник только по точному проверенному профилю, а не как универсальная доверенная строка.

**Чего не делать.** Не ставить confidence_level=0,95 только ради включения правильной формулы. Это повысит статус по технической причине. Не заменять всякий неизвестный интервал нормальным распределением: для произвольной полосы STD вообще может быть не определён.

**Приёмка.** Изменение только запрошенной формы отображения не меняет уже заданную sigma. Сохранение и последующая propagation представляют тот же условный закон; вывод не получает новых полномочий. При отсутствии подходящего carrier возвращается явная неоднозначность.

**Статус.** Полные adapter и covariance исполнены; сквозной Monte Carlo здесь не запускался. Это отдельная проблема от перестановки covariance B187 и зависимости входов B188: информация о масштабе уже существует, но неверно восстанавливается.
