**Цикл работы:** зафиксировать actual scope и нужный characterization; оформить equivalent move и намеренный behavior fix раздельно; выполнить указанные малые tests через I1; независимый reviewer проверяет actual owner; передать commit, path map и остатки. ## B16. Область задачи должна ограничивать выборку до LIMIT и агрегации

*Источник карточки: A:B16. Унаследовано из прочитанной сводки A; не новый интеграционный прогон.*

**Происхождение и подтверждение:** P2; код. Загрузчик профиля L1 фильтрует canonical_var, наличие значения и периода, затем применяет сортировку и `LIMIT 20000`. Регион/популяция конкретной задачи не передаются ему явно; несколько источников для пары unit-period усредняются. Сейчас профиль используется для формы данных/выбора метода, а положительная причинная ветвь далее не установлена. [A.R04: 4460–4635]

**Экономное расширение:** передать область задачи и семантику измерения до ограничения объёма; различать усечение, неполноту и отсутствие. Сохранять источники и единицы; усреднять только по объявленному допустимому правилу. Не исправлять проблему простым повышением LIMIT.

**Критерий:** подходящие строки не исчезают из-за сортировки чужих областей; перемешанные единицы не усредняются; реально маленькая выборка не выдаётся за полную. Изменение области задачи меняет фактически потреблённый набор и его идентичность.

**Ограничение и приоритет:** не утверждается, что опубликован неверный причинный эффект. Это риск входного профиля, обязательный к проверке при открытии B08. Высокое влияние на корректность; средняя локальная сложность.

## B31. Проекция неопределённости сжимает интервал и вводит произвольную ширину

*Источник карточки: L:F29. Унаследовано из Library S01; не дублируется с A.*

**Основание:** Код + арифметические пробы P4-02; положительный consumer не продемонстрирован. **Происхождение:** P4 — новая находка. **Приоритет:** A до подключения B08. **Охват изменения:** M — затрагивает семантику контракта.

**Наблюдение и барьер.** Helper для point делает lower=upper=estimate; для proxy симметризует через половину ширины, 10% estimate и минимум 0.01. Пример estimate=2, CI=[0,10] даёт [-3,7], не охватывающий исходный интервал. Минимум 0.01 не инвариантен смене единиц. Canonical ValueOuterSet сам требует почти нулевую ширину point. [L.S22, L.S23]

**Минимальное расширение.** Сначала определить, что несут bounds: идентификационное множество или суммарную неопределённость. Сохранять нативную статистическую/модельную неопределённость отдельным проверяемым каналом; не объявлять её исчезнувшей при point-identification. Не вводить ширину без основания. Координату задавать предметным estimand и единицей, а метод хранить как происхождение.

**Проверка результата.** Ненулевой статистический интервал не теряется; асимметричный интервал не сужается без основания; смена единиц согласована; два метода одного estimand не становятся разными предметными координатами только по имени метода.

**Граница вывода.** Нулевая ширина идентификационного множества сама по себе не ошибка. Ошибка возникнет, если её выдать за полную точность или потерять отдельный канал неопределённости. Нельзя локально расширить interval под прежним point: это противоречит текущему типу. Штатный N8 пока отказывает, поэтому ложный опубликованный результат не заявляется.

## B33. Граф переноса строится шаблонно из имён treatment, outcome и ковариат

*Источник карточки: L:F31. Унаследовано из Library S01; не дублируется с A.*

**Основание:** Код прочитан; применимость графа — открытый предметный вопрос. **Происхождение:** P4 — новая находка. **Приоритет:** A перед эмпирическим transport. **Охват изменения:** M.

**Наблюдение и барьер.** _build_candidate_selection_diagram строит T→Y и C_i→Y для каждой ковариаты, затем добавляет измеренные различия источника и цели. Топология этим участком создаётся заново, а не считывается из обоснованной причинной модели. Сами значения ковариат не доказывают направление этих рёбер. [L.S24, L.S29, L.E05]

**Минимальное расширение.** Передавать selection diagram из именованной модели/идентификационного плана. Шаблон допустим как явно условная гипотеза для исследования, но не как основание универсального transport-сертификата. При недостатке структуры запускать конкурирующие сценарии либо сохранять пробел.

**Проверка результата.** Две модели с одинаковыми именами и маргинальными данными, но разными причинными связями не получают один и тот же сертификат по одному шаблону. Отсутствующее основание структуры не дополняется именем переменной.

**Граница вывода.** В этой работе не доказана неверность конкретного полученного эмпирического вывода: стандартный N8 останавливается раньше. Нужен точный договор о допустимых целях использования helper, а не утверждение, что вся библиотека transport неправильна.
