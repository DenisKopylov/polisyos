## Поручение и минимальная приёмка

Разрешить полный набор fixed и varying inputs, реально обоснованную модель/affine-карту и ожидаемые outputs. Убрать Python float cast с дифференцируемого tracer. Missing sensitivity остаётся неизвестной/явной гипотезой, не автоматически mapped; отсутствие output не становится нулевой константой.

**Различающие тесты и сохраняемое поведение.** y=x*scale при scale=2 сохраняет 20 в nominal/delta/MC, не 10. Для реальной affine-карты dispatcher выбирает delta без сотни fallback calls. y=x−2 при baseline=0 имеет ненулевую дисперсию, если Var(x)>0. Missing output не даёт [0,0]; настоящая константа 0 остаётся допустимой. Малые массивы и JAX grad по одному слоту.

**Не считать исправлением.** Не открывать быстрый delta отдельно от исправления смысловой карты B190. Не угадывать связи каждого output со всеми params и не повторять один структурный TypeError сотни раз.

**Цикл работы:** зафиксировать actual scope и нужный characterization; оформить equivalent move и намеренный behavior fix раздельно; выполнить указанные малые tests через I1; независимый reviewer проверяет actual owner; передать commit, path map и остатки. CLI/test selectors разрешаются по настоящему checkout до запуска, не выдумываются из названия находки.

## B186. Фиксированные nominal-параметры пропадают в delta и Monte Carlo

**Основание и причина.** `DeltaMethodPropagator` и оба MC sampling-loop строят kwargs только из ключей `input_envelopes`. Остальные `nominal_params` не передаются. При этом `_safe_nominal_outputs` вызывает функцию с полным nominal. Один отчёт может соединить номинальный результат одной задачи с выборкой другой. C18.R05, R07–R08; P05–P08.

**Воспроизведение.** Для y=x×scale, nominal x=10, scale=2, и envelope только у x, delta вернул 10 вместо 20: использован Python-default scale=1. MC nominal дал 20, а среднее 200 sampled-вызовов — 9,950506. Если scale обязателен и default отсутствует, номинальный вызов всё ещё даёт 20, но все 100 sampled-вызовов завершаются ошибкой. Обёртка, объединяющая фиксированный nominal с изменяемой частью, вернула point=20 и дисперсию 4 при σx=1.

**Предпочтительное исправление.** Один раз разрешить полный эффективный набор входов и разделить его на фиксированные и варьируемые. При каждом прогоне менять только объявленные случайные координаты; все прочие параметры, версии модели и артефактов сохраняются. Использовать эту же привязку в пробной дифференциации, nominal, delta и MC. Большие неизменяемые объекты не копировать целиком: замыкание или типизированные ссылки достаточны.

**Оговорки и приёмка.** Если API намеренно требует, чтобы фиксированные значения были замкнуты вызывающей стороной, это должно проверяться и документироваться до запусков. Native-node из C18.R09 номинал строит только по envelope-ключам и может избегать данного контрпримера. Не создавать нулевую неопределённость каждой фиксированной константе ради обхода; не повторять сто раз один TypeError. Проверить совпадение effective kwargs, сохранение реальных defaults только при их намеренном выборе и адресный отказ при неразрешённом входе.

## B189. Штатная функция отклика ломает собственный быстрый delta-путь

**Основание и причина.** Scientist-node передаёт `is_jax_differentiable=True`, но созданный `_build_propagation_fn` внутри вызывает `float(current)` на параметре, по которому берётся Jacobian. `eval_shape/jacfwd` dispatcher получает tracer; преобразование к Python-float невозможно. После диагностического сообщения выбирается MC. C18.R05, R07, R09; P15–P17.

**Воспроизведение.** Для явно заданного линейного отклика y=10×[1+(x−2)/2] дифференцирование узловой функции дало `ConcretizationTypeError`; dispatcher выбрал Monte Carlo. Тестовый MC-driver с настоящим выбранным random-loop выполнил 100 образцов. Та же формула без scalar-cast выбрала delta и вернула point=10, variance=25 при Var(x)=1.

**Предпочтительное исправление.** Разрешать Python-константы до трассировки, а изменяемые значения сохранять в JAX-совместимых выражениях. Конвертировать конечные результаты в Python только на границе отчёта. Для явно известной affine-карты возможен ещё более дешёвый Jacobian, но он должен совпадать с настоящим отображением и его единицами.

**Оговорки и приёмка.** MC — нормальная стратегия для действительно недифференцируемых моделей, не ошибка сама по себе. Не отключать fallback; различать неподдержанную математическую модель и дефект адаптера. Удаление cast не доказывает научную достоверность синтетической карты — B190 исправляется совместно. Опыт не измеряет многократное ускорение всей системы: штатная карта сравнительно дешева, а full production-node и настоящий MC report не запущены. Проверить eager/JIT, kwargs, точный Jacobian и отсутствие лишних sampled-вызовов на известном линейном контроле.

## B190. Неизвестная чувствительность заменяется произвольной связью, а нулевой baseline подавляет всю неопределённость

**Основание и причина.** При отсутствии явной карты и совпадений имён `_resolve_sensitivity_map` создаёт малые связи каждого выхода со всеми параметрами и отмечает их `mapped`. `_build_propagation_fn` умножает baseline выхода на 1+относительную поправку. Если есть хоть одна явная карта, остальные выходы могут остаться просто константами. Это модельная эвристика, не вызов существующей полной симуляции. C18.R09; P18–P20.

**Воспроизведение.** Для неизвестной связи x→y и baseline y=0 helper построил коэффициент x=1 и mapped={x}, но y остался 0 при x=2 и x=3. При явно заданном только y остальные z=20 не менялись. Контроль настоящего отображения y=x−2 при x₀=2 имел тот же нулевой baseline, но дисперсию 1; отсутствие эффекта в baseline не означает отсутствия чувствительности.

**Предпочтительное исправление.** Различить установленную карту, исследовательское предположение и неразрешённую связь. Переиспользовать реально исполненную модель, сохранённый Jacobian или явно заданную affine-карту с происхождением и единицами. Для нулевого baseline допустим размерный аддитивный отклик, если его смысл установлен; нельзя заменять ноль epsilon и считать вопрос решённым.

**Оговорки и приёмка.** Простая surrogate-карта полезна как отдельная гипотеза. Она должна быть помечена соответствующим образом, не выдаваться за консервативную границу и не подтверждать полноту mapping по числу автоматически добавленных имён. Неизвестность не обязана блокировать все известные выходы: сохранить частичную проекцию с адресным запросом на недостающую связь. Проверить нулевой и ненулевой baseline, частичные карты, масштаб единиц и настоящую постоянную модель. Производственный допуск или публикация эвристической карты в опыте не проверялись.

## B191. Отсутствующий выход в delta становится нулевым интервалом

**Основание и причина.** `_vectorized_fn` берёт `result.get(metric_id, 0.0)`, и аналогичный default используется в проверке применимости dispatcher. Для отсутствующего ключа Jacobian нулевой. Метод затем запрашивает Normal-envelope с point=0, интервалом [0,0] и `gate_eligible=True`. C18.R05, R07; P21–P23.

**Воспроизведение.** Функция вернула только `actual`, а запрос содержал `missing`: локальный производитель сформировал [0,0]. В MC отсутствие этого же выхода записывается как NaN, а не ноль. Настоящий постоянный нулевой выход корректно даёт [0,0] и не должен быть запрещён.

**Предпочтительное исправление.** До дифференциации связать ожидаемые выходы с их реальными производителями, именами и формой. Отсутствующий ключ — структурный пробел, не константа и не причина слепо повторить сотни вычислений. При допустимом частичном ответе сохранить присутствующие выходы; для остальных вернуть адресную недоступность. Если отсутствует весь запрошенный результат, не считать пустое вычисление успешным оцениванием.

**Оговорки и приёмка.** `RecordingDTO` только зафиксировал аргументы конструктора; настоящий валидатор composition_provenance/gate и CAS не запускались. Нулевой сертификат мог бы быть отвергнут дальше, поэтому не заявляется выданное ложное разрешение. Native-node по C18.R09 строит список выходов из исходных метрик и обычно сохраняет все ключи своей карты; generic API остаётся проверенной областью риска. Проверить одинаковую семантику отсутствия для delta и MC, именованные реальные нули и частично выполненную функцию.
