## S02. Модельный контекст под вопрос вместо обязательной сборки «всего мира»

**Предложение:** собирать из общих хранилищ и механизмов необходимый для данного вопроса контекст с явной областью, временем, разрешением, зависимостями и внешними условиями. `WorldModelRecord` уже предусматривает соответствующие координаты и references. Не нужен отдельный store на каждый кейс. [A.R13; A.R01]

Сужение не может исключать смешивающие причины, общий ресурс или обратную связь только ради удобства. Исключённое влияние либо обосновывается, либо остаётся внешним условием/диапазоном/нерешённой зависимостью. Реальная цена сборки небольшого WMR пока не измерена; «дешёвая локальная модель» — рабочая гипотеза.

**Проверка:** две разные задачи используют разные необходимые проекции общего знания без отдельного кода для каждой; важное внешнее влияние не исчезает из semantics. Изменение несущественного внешнего файла не запускает весь пересчёт, изменение существенного входа — запускает нужный.
