## S03. Полноценная исследовательская ветвь без выдачи предположений за authority

**Предложение:** условно вычислимый объект должен быть доступен для исследования даже тогда, когда не хватает основания для защищённого применения результата. Показывать не только красный статус, а сценарий, его предпосылки, результаты, чувствительность и следующий допустимый шаг. В плане уже различаются исследовательские и решающие множества; институциональное отсутствие не должно блокировать само построение допустимой демонстрации. [A.R01; A.R03]

Это не универсальный «research mode» для обхода access control. Работа с чувствительными данными, внешнее действие и публикация по-прежнему имеют собственные требования. Условный расчёт — отдельное содержательное обещание, а не облегчённый способ присвоить доказательную силу.

**Проверка:** пользователь видит полезный ограниченный результат; тот же объект не проходит в запрещённое применение. По B05 ограничение использования не становится запретом любого последующего вычисления.
