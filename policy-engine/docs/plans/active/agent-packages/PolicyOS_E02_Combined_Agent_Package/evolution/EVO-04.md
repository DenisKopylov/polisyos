## S04. Несколько допустимых объяснений и анализ чувствительности

**Предложение:** при спорном графе или prior сохранять несколько допустимых моделей/наборов предпосылок и исследовать, какие выводы зависят от их различий. Это позволяет работать без преждевременного выбора «единственно правильной» структуры. Использовать существующие disputed-edges и set-valued контракты, а не вторую систему уверенности. [A.R01; A.R16]

Нечувствительность к нескольким выбранным сценариям — не гарантия для всех возможных моделей. Вероятности сценариев не назначаются языковой моделью по убедительности объяснения. Отдельно учитываются prior sensitivity, численная ошибка, неопределённость параметров и неидентифицированная структура.

**Проверка:** противоположные правдоподобные объяснения не усредняются молча в один «уверенный» ответ; пользователь видит условие расхождения и предел охвата рассмотренного множества.

**Уточнение Library S01, сохранённое здесь.** Наличие scenario_set/polytope в словаре ValueOuterSet не означает готовую непустую реализацию: прочитанный валидатор поддерживает заполненные interval_box и отвергает непустое содержимое остальных форм. Для многомодельного исследования сначала использовать действительные выходы отдельных моделей и не обещать ещё не реализованное множество. Отдельно проверять B31–B33. [L.S23, L.S28]
