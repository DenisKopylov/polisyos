## S05. Поиск различающих и опровергающих оснований

**Предложение:** к запросам поддержки текущих рёбер добавить альтернативные объяснения, нулевые/обратные результаты, контекстные модераторы и условия, которые различают конкурирующие модели. В `PriorMiner` исследованные targets формируются из уже выбранных required/high-confidence/disputed edges; это естественная точка расширения, не доказательство подтверждающего уклона всей системы. [A.R15]

Самым полезным следующим источником может быть не ещё одно подтверждение, а материал, который меняет выбор между двумя объяснениями. Поисковые истории, отклонённые материалы и дубликаты исследований сохраняются. Много публикаций об одном эксперименте не считаются независимыми повторениями; настройка prior после просмотра результата учитывается отдельно.

**Проверка:** при добавлении достоверного контрсвидетельства меняется модельное множество/следующее действие, а не только bibliography. Самосогласие нескольких LLM не подменяет независимое эмпирическое основание.
