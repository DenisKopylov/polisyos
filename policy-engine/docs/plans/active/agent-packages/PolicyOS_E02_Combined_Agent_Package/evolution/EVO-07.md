## S07. Доказательная достаточность относительно конкретного утверждения

**Предложение:** не требовать полного обоснования всего проекта для выдачи каждого корректного частичного результата. Расчёт затрат, условное следствие модели, эмпирический эффект и разрешённость применения — разные claims. В конституции weakest-boundary не означает механический минимум по всем несвязанным материалам. [A.R03]

Проверять действительные зависимости конкретного утверждения, сохранять их versions и повторно проверять только затронутую часть при изменении. Цена сужения — доказать отсутствие пропущенного существенного пути, а не просто выбрать удобный короткий список. Новый обнаруженный dependency создаёт новую версию основания и ограничивает текущий claim; прошлое не переписывается.

Человеку направлять точный спорный вопрос: сопоставление переменной, извлечение эффекта, применимость, выбранное ценностное правило. Подпись под всем пакетом не заменяет его содержательную проверку. Отсутствующее полномочие не препятствует построению формы или проверке bytes, но препятствует акту, который этого полномочия требует.

**Проверка:** независимый корректный результат переживает локальный сбой; зависимый от испорченного основания — отзывается. Никакой «частичный режим» не превращает отсутствие существенного доказательства в допустимость.

**Дополнение L:F23.** Специалисту передаётся точный спорный объект: исходный фрагмент, сопоставление переменной/популяции, альтернативы и правило оценки. Отрицательное или неизвестное заключение сохраняется с областью действия. Подпись всего пакета не является универсальной заменой такой проверки. Реальных интервью или испытаний с экспертами в этих проходах не было.
