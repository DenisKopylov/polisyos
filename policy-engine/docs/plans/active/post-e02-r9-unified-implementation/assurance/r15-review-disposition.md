## Исследование и независимость

Root использовал пять прямых исследовательских помощников: `r15_trajectory`, `r15_studies`, `r15_method_profiles`, `r15_comodel_repo`, `r15_comodel_research`. Они читали ограниченный source/plan и первичные технические источники; два scope сообщили об отсутствии optional ignored frontier notes и продолжили по tracked sources. Их выводы не выданы за полный code census. Root написал итоговые документы и машинные изменения.

Три других прямых помощника — `r15_red_semantics`, `r15_red_dispatch`, `r15_red_comodel` — атаковали actual documentary delta. Дочерних агентов, продуктовых процессов, environments и implementation не создавали. После исправлений проводилось delta-only review; неизменные части не получили фиктивный новый runtime PASS. Web sources и ограничения методов указаны рядом с решениями. Research suggestions являются inputs, root проверял placement/claims и принимал или уточнял их.

## Что осталось условным

Exact executable/source/backend/profile identity перепривязывается после E02. Actual institutions, permissions, model validity/transport, calibration, study results, pricing/rights и selected deployment inputs не созданы этим планом. Cross-model adapters, expected-map numerical guarantees и external master выбираются по нужному свойству; неподдержанный scope не обещается. Изменения ratified SDD/authority/time/shared ABI требуют отдельного компетентного решения; здесь таких изменений нет. No new mandatory SDD proposal found necessary for the selected native extensions.

Документарные проверки перечислены в [r15-validation.json](r15-validation.json); это parse/set/link/anchor/history проверки, не продуктовые тесты. Тяжёлые hooks/tests/builds/installations пропущены по прямому ограничению пользователя. Resource priority остаётся у исполнителя E02.
