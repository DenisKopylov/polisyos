## Findings

### GY-R11-1 — Medium — same class, one level deeper (P02: false prerequisite / orchestration inversion)

**Evidence.** GY-O3’s source says a confirmed O1 effect or O2→O1-promoted hypothesis plus AS3 writes the append-only Fabric branch/event and versioned WMR; a later cycle reads it, and the self-confirmation quarantine survives reprocessing (`GY-engine-subordination.md@413c120:L5475-L5491`). The workstream explicitly says “O3 depends on O1 and AS3, not O2” (`workstreams/03-gy.md:L7`). GYD-12 additionally lists “DS21 surface” as a required other mechanism (`tasks.json@413c120:L2414-L2415)); UI-08 is the DS21 readout and itself depends on GYD-12 (`tasks.json@413c120:L4518-L4522`).

**Divergent scenario.** If the required-mechanism list is honored as an actual prerequisite, O3 waits for the DS21 surface while the DS21 task waits for O3. If it is treated as informational, the same field falsely implies the readout is an O3 producer dependency.

**Minimal fix.** Remove DS21 from GYD-12 prerequisites; keep it as the downstream readout/consumer after O1/O3. Preserve GYD-09 + GYD-11 as the O3 task dependencies.

**Affected task IDs:** GYD-12, UI-08.

### GY-R11-2 — Medium — same class, one level deeper (P04: milestone/closure collapse)

**Evidence.** The canonical GY-PR1 row states that PR1a’s data-only receipt and PR1b’s institution-bound protected pilot are distinct milestones; the authentic O0 near-miss is separate (`GY-engine-subordination.md@413c120:L1799`; `workstreams/03-gy.md:L5`). GYD-01’s deliverable describes both, but its single positive conjunction requires an authentic N4 input and `EvalSafety=blocked + near_miss=true` together (`tasks.json@413c120:L1690-L1691`).

**Divergent scenario.** PR1a can produce its complete, valid data-only N4 receipt while no authentic field-pilot near-miss has occurred. The task has no explicit independent milestone outcome, so the positive condition cannot distinguish “PR1a complete, PR1b open” from “both complete”; an implementation may either withhold PR1a closure unnecessarily or read one overall GYD-01 state as closure of both obligations.

**Minimal fix.** Add separately recorded PR1a and PR1b acceptance/owner-disposition results. Keep the source row blocked until its full criterion is met; attach the authentic near-miss only to PR1b and never promote a fixture to field evidence.

**Affected task IDs:** GYD-01.

### GY-R11-3 — High — same class, one level deeper (P37/P38: declared cutoff basis instead of independently tested property)

**Evidence.** GY-FA1 makes writer independence decisive and requires “falsifying the declared cutoff basis while keeping the declaration” to fail (`GY-engine-subordination.md@413c120:L1814`). GYD-15’s named criteria require a typed contract, producer, receipt, reader, and negatives for missing/self-authored/wrong-scope/unverifiable receipts, but its positive/removal conditions do not name the cutoff-basis falsifier (`tasks.json@413c120:L2626-L2629`). The generic acceptance step “independent oracle where needed” does not freeze this particular predicate.

**Divergent scenario.** A writer changes the actual admitted subtree while retaining its declared path list and a valid signature over that declaration. Generic missing/self-authored/wrong-scope tests may still pass, although the gate is green on a false cutoff basis.

**Minimal fix.** Make the cutoff falsification probe mandatory for the cutoff capability: mutate the actual source set while preserving the declaration, reconcile against an independent source, and require refusal. Classify/freeze the basis predicate at admission under P37; never grant authority from same-writer walks.

**Affected task IDs:** GYD-15.
