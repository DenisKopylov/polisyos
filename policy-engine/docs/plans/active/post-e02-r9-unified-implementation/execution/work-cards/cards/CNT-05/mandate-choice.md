# CNT-05.mandate-choice — Зафиксировать отдельный authorized normative selector

Группа: [G02 — Смысл оснований: право, метрики, ценности и участники](../../groups/G02.md). Родитель: [CNT-05](../../parents/CNT-05.md). Роль: `consumer`.

Плановая рабочая карточка. Реализация только после E02 acceptance и exact source/lease rebind; эта запись не является execution grant или closure. [Общие правила](../../README.md).

**Проверяемый результат.** Named authorized principal and remit select among valid metric alternatives using explicit objectives/thresholds/tradeoffs; principal branches remain separate and selection provenance is visible.

**Предпочтительное решение.** Keep value choice distinct from metric definition and CNT-07 mandate evidence. Reuse existing claim/value decision consumer; never infer objective from model, consultation tally or default.

**Граница владельца.** Only the existing native value/claim authority selector may persist an operative choice under its native canonical lease family; actual principal supplies normative content. CNT-07 supplies evidence only when selected, not the selector. Exact paths/overlap must be rebound after E02.

**Входы.** Validated measure-profile alternatives; real principal supplies objectives, thresholds, tradeoffs and mandate provenance. CNT-07 evidence is conditional for collective mandate premises.

**Выход и consumer.** Versioned principal/remit/selector record linked to exact alternatives; keep principal-authorized hard floors as separate non-compensable constraints. A fully supported conditional result retains its existing support status without collective mandate; only collective winner/endorsement is denied. Fresh value/decision and selected public readers preserve that distinction.

**Что можно готовить независимо.** Choice contract can be prepared; no operative default until real principal and valid alternatives arrive, accepted E02 source/lease/permit.

**Где результат соединяется с другими.** Join qualified metric results with authorized selection only for an operative collective choice. Absence of that choice does not demote independently supported conditional results. Metric arithmetic cannot invent, relax or repair a hard floor. Bind the existing public selected-basis/limitation projection with same-generation scope, audience and rights; missing reader remains surface_missing and is assigned to this card under its native projection owner.

**Positive.** Authorized principal выбирает valid basis; comparison показывает alternatives/reversal, а fresh selector/history reader сохраняет prior authorized choice на исходных formula/principal/rule versions. Это selector-owned часть составного `task.positive` и уже назначенного `task.rollback`; пересчёт metric не переписывает историю выбора.

**Distinguishing negative.** No principal/remit, incompatible measure, response count or preference is used as authority.

**Matched removal.** Input-negative: при отсутствии collective mandate qualified conditional calculations сохраняют support, но winner/endorsement не выдаётся. Для mechanism removal оставить те же inputs, отключить только mandate admission в existing selector и проверить неизменённой независимой assertion отсутствие ложного winner; false endorsement должен дать FAIL. Отдельные formula/hard-floor negatives выполняются через своих owners в parent join: mandate не исправляет отсутствующую основу.

**Граница контекста.** CNT-07 can support authority evidence, but normative selection stays here and never becomes a new central owner.
