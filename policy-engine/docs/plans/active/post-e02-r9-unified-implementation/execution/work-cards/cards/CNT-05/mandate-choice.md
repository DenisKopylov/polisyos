# CNT-05.mandate-choice — Зафиксировать отдельный authorized normative selector

Группа: [G02 — Смысл оснований: право, метрики, ценности и участники](../../groups/G02.md). Родитель: [CNT-05](../../parents/CNT-05.md). Роль: `consumer`.

Плановая рабочая карточка. Реализация только после E02 acceptance и exact source/lease rebind; эта запись не является execution grant или closure. [Общие правила](../../README.md).

**Проверяемый результат.** Named authorized principal and remit select among valid metric alternatives using explicit objectives/thresholds/tradeoffs; principal branches remain separate and selection provenance is visible.

**Предпочтительное решение.** Keep value choice distinct from metric definition and CNT-07 mandate evidence. Reuse existing claim/value decision consumer; never infer objective from model, consultation tally or default.

**Граница владельца.** Only the existing native value/claim authority selector may persist an operative choice under its native canonical lease family; actual principal supplies normative content. CNT-07 supplies evidence only when selected, not the selector. Exact paths/overlap must be rebound after E02.

**Входы.** Validated measure-profile alternatives; real principal supplies objectives, thresholds, tradeoffs and mandate provenance. CNT-07 evidence is conditional for collective mandate premises.

**Выход и consumer.** Versioned principal/remit/selector record linked to exact metric alternatives and claim; fresh value/decision reader consumes it.

**Что можно готовить независимо.** Choice contract can be prepared; no operative default until real principal and valid alternatives arrive, accepted E02 source/lease/permit.

**Где результат соединяется с другими.** Final decision reader joins measure-profile with authorized selection. Preparation of either output need not wait for the other.

**Positive.** Authorized principal selects a valid basis and comparison shows alternatives/reversal.

**Distinguishing negative.** No principal/remit, incompatible measure, response count or preference is used as authority.

**Matched removal.** Remove selector provenance but keep chosen label: fresh consumer cannot treat it as operative; mandate cannot rescue invalid formula.

**Граница контекста.** CNT-07 can support authority evidence, but normative selection stays here and never becomes a new central owner.
