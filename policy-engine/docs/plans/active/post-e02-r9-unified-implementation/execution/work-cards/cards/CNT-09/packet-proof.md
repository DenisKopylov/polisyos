# CNT-09.packet-proof — Доказать выбранный foundation packet через fresh consumer

Группа: [G10 — Независимые проверки и качество свидетельств](../../groups/G10.md). Родитель: [CNT-09](../../parents/CNT-09.md). Роль: `verification`.

Плановая рабочая карточка. Реализация только после E02 acceptance и exact source/lease rebind; эта запись не является execution grant или closure. [Общие правила](../../README.md).

**Проверяемый результат.** One real commissioned case produces selected native artifacts/receipts and verifier results; existing fresh recommendation/status reader changes correctly, with audit/reviewer/permitted projections aligned on scope, time, rights and limits, or returns bounded costed refusal.

**Предпочтительное решение.** Compose only selected outputs through existing acquisition/lifecycle and G2/G4/G5 consumers. Prove real input→persisted artifact→bridge→fresh status consumer→audience projection with positive/adversarial/removal cases. UI-17 is only the owner of its selected acquisition surface; actual claim/dossier/document readers stay with their selected native UI/CNT/DES contracts. This card verifies, not reimplements those surfaces.

**Граница владельца.** No new source/runtime writer. Native acquisition, legal, measure/value, claim, permission, GYD-30 and each selected UI/CNT/DES reader owner retain their canonical leases. UI-17 owns only its selected acquisition surface, not every claim, dossier, document, API or export reader. Any changed path requires exact `write:exact-path/{canonical_repo_path}` lease and complete E02 overlap census; unresolved sibling paths are not presumed disjoint.

**Входы.** Sponsor selects real jurisdiction/population/intervention/authority and suppliers; custodians supply permitted data/definitions/law/acts/studies/holdouts/testimony/mandate/capacity. CNT-03 receipt and CNT-08 basis result; CNT-04/CAP-05 legal, CNT-07 participation only when selected. Examples/method refs do not appoint suppliers.

**Выход и consumer.** Selected packet manifest maps each selected facet to source/version/purpose/rights/time, native artifact/receipt, verifier, downstream consumer/status/refresh/surface; or a costed refusal.

**Что можно готовить независимо.** Prepare selection map/oracle plan. Authentic positive waits for commissioned case, source permission, E02 rebind, owner artifacts/verifier, actual fresh reader, the exact lease for each selected native surface (UI-17 only for its selected acquisition surface) and permit. Fixture-only evidence cannot fill source slots.

**Где результат соединяется с другими.** Fresh existing recommendation/status consumer on selected acquisition/lifecycle→G2/G4/G5 path; then same-generation Expert/Machine and reviewer views plus selected native UI/CNT/DES readers. Include UI-17 only if its acquisition surface is selected; include Atlas/API/public projection only when the exact reader and audience/right filter are bound. No leaf PASS sum substitutes.

**Positive.** A permitted input persists owner output and changes recommendation/limited/contested/blocked/publishable status; aligned audit shows limitations.

**Distinguishing negative.** Foreign scope, revoked grant, incomplete response, wrong notice, shared ancestry, changed denominator or exploratory-only evidence appears green; fixture is called authentic.

**Matched removal.** Remove event-to-decision, owner check, alternate-metric behavior or export gate but keep markers: fresh semantic consumer fails, and private/query-only bytes remain gated.

**Граница контекста.** Retain as one vertical integration proof. It consumes CNT-01's all-26 grammar output but one case cannot close the program-wide grammar obligation.
