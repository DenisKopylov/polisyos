# DES-01.intent-frame-handoff — Сохранить намерение при выборе рамки

Группа: [G04 — Содержательный поиск политик и перенос опыта](../../groups/G04.md). Родитель: [DES-01](../../parents/DES-01.md). Роль: `mechanism`.

Плановая рабочая карточка. Реализация только после E02 acceptance и exact source/lease rebind; эта запись не является execution grant или closure. [Общие правила](../../README.md).

**Проверяемый результат.** A persisted set preserves the original question and materially distinct frames; only an exactly selected, in-remit frame and its declared unknowns enter the actual N4 request.

**Предпочтительное решение.** Extend the existing request-frame/formulator handoff. Reuse native request, hypothesis, and N4 contracts; retain unchosen frames and unbound concepts as candidates. Do not create a domain-template menu or promote an LLM framing to authority.

**Граница владельца.** DES-01 owns only the native intent bridge in lease families write:design-intent-formulator and, if changed, write:g6-intake-if-changed. UI-05 owns Clerk/API; DES-02 owns N4 generation. Shared formulator paths with DES-02/DES-08 are one writer family; E02 rebind must resolve exact paths and serialize unresolved overlap, never presume disjointness.

**Входы.** Existing request/frame/mandate records and exact user selection when required; UI-05 supplies the actual selection through its existing interface.; A source-bound selected frame and declared unknowns; actual N4 invocation is needed for the composed acceptance, while intake preparation may proceed on agreed interfaces.

**Выход и consumer.** Versioned frame records linked to original intent and the selected frame; the real N4 consumer receives the exact selected scope/goal/population and unknowns, and the reviewer can still resolve alternatives.

**Что можно готовить независимо.** After E02 acceptance and task-scoped accepted-source rebind, trace producer, sink, N4 consumer and companions. UI/interface preparation may proceed independently; protected authority and composed acceptance wait for actual selection and N4 output.

**Где результат соединяется с другими.** Join the persisted frame and selection through the existing fresh N4 generation-input reader and UI-05 reviewer view. No G6 PUBLIC recommendation text is produced here.

**Positive.** An ambiguous but usable request retains distinct framings; selecting one changes the actual N4 input while preserving the original question and unresolved assumptions.

**Distinguishing negative.** Changing population, jurisdiction, goal or value basis under an unchanged frame ID cannot silently alter the chosen task; prompt injection cannot expand tools/rights; unrepresentable ideas remain unbound.

**Matched removal.** Keep frame IDs but remove original-intent/selection binding; a fresh N4 input comparison and reviewer readback detect the meaning loss.

**Граница контекста.** This is one cohesive handoff, not an intake UI or generator rewrite. Scope edits that change meaning create a branch; UI-05 and N4 keep their owners. The actual file lease remains unresolved until accepted-source rebind.
