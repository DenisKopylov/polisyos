# DES-04.feedback-choice — Вернуть проверенную обратную связь в выбор

Группа: [G04 — Содержательный поиск политик и перенос опыта](../../groups/G04.md). Родитель: [DES-04](../../parents/DES-04.md). Роль: `mechanism`.

Плановая рабочая карточка. Реализация только после E02 acceptance и exact source/lease rebind; эта запись не является execution grant или closure. [Общие правила](../../README.md).

**Проверяемый результат.** A permitted, property-bound counterexample, actual outcome or method warning changes a later candidate/branch choice, or yields an honest limited next action with rejected, unexecuted and truncated branches visible.

**Предпочтительное решение.** Extend the existing N6 bridge using native candidate/evaluator lineage, current fronts, actual emitted-set/terminal accounting and bounded continuation duty. Send only permitted diagnostics; sealed confirmatory outcomes do not tune the proposer. Retain grammar fallback and distinguish candidate hints from causal evidence.

**Граница владельца.** DES-04 is the only N6 feedback/generation-cycle bridge writer under write:n6-generation-cycle. DES-08 may prepare later memory influence but does not gate the first within-run loop. DES-02 candidate production, DES-03 numerical search, LIF invalidation and GYD/CAP evidence owners remain their own writers. Exact paths rebind after E02; unresolved overlap is not presumed disjoint.

**Входы.** Actual candidate, evaluator/property, evidence origin and result from DES-02/DES-03/native owners; selected authorized diagnostic feedback only.; Bounded duty/event inputs and native terminal/actual emitted-coverage reasons; absence of empirical support limits claim, not the whole candidate loop.

**Выход и consumer.** Persisted feedback/rejection and next-choice event tied to candidate/property/evaluator, with actual branch coverage, terminal reasons, budget, and fresh N6/Cycle Board reader.

**Что можно готовить независимо.** May prepare interface and controlled disconfirmation cases after E02 source rebind. Real update waits on an admitted event and selected duty; no deferred MCTS/meta/Portfolio prerequisite or unbounded historical replay.

**Где результат соединяется с другими.** The fresh N6/Cycle Board consumer compares the pre-event and actual next candidate/branch. Acquisition-return outputs are a separate input when selected; feedback cannot mint authority or an evidence posterior.

**Positive.** A material counterexample revises or rejects the affected branch; a scoped interaction changes the candidate family; a useful next action remains after honest budget exhaustion.

**Distinguishing negative.** Paraphrases cannot count as exploration, high proxy/weak grounding remains outside DecisionFront, full declared input coverage cannot substitute for emitted/visited coverage, and a local method failure cannot be transported as a causal finding.

**Matched removal.** Keep history/front markers but disable actual feedback, bounded dispatch or grammar reachability; the next-choice consumer no longer changes or loses a reachable candidate.

**Граница контекста.** Owns the within-run N6 feedback property and bounded continuation, not upstream evaluation or acquisition evidence. DES-08 later memory influence is optional for this first loop.
