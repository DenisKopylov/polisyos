# DES-06.private-policy-documents — Выпустить частные документы с привязкой к смыслу

Группа: [G08 — Документы, интерфейсы и понятные человеку результаты](../../groups/G08.md). Родитель: [DES-06](../../parents/DES-06.md). Роль: `mechanism`.

Плановая рабочая карточка. Реализация только после E02 acceptance и exact source/lease rebind; эта запись не является execution grant или closure. [Общие правила](../../README.md).

**Проверяемый результат.** A fresh reader resolves a coherent private candidate document set whose material statements and cells bind to exact native claims, quantities, legal roles, audience, purpose, edition and actual output bytes; unavailable bases are refused only for uses that need them.

**Предпочтительное решение.** Extend native PolicyArtifactBundle/BureaucraticDocument rendering and existing export/UI paths. Bind semantic span/cell roles to exact candidate/claim/metric/provision; include rationale, alternatives/no-op, affected groups, uncertainty and monitoring as selected profiles. LLM prose is never authority evidence.

**Граница владельца.** DES-06 owns document producer, edition schema and private policy output under write:policy-document-owner, write:policy-output and conditional write:runtime-api-generated-family if actually changed. DES-07 owns import/edit-back and consumes the shared versioned schema; one exact-path writer agreement is required. CNT-09 reads real case output. UI-05 is intake only; public prose/release is out of scope here. Resolve lease paths after E02, never presume shared files disjoint.

**Входы.** Actual selected candidate/design and native claim refs; consume DES-05 legal branches and GYD-05 membership/ruling only when a material claim uses them, and DES-09 invocation records only for selected LLM-assisted content; audience/purpose remain bound.; Native numerical basis for recomputation only where required and available; otherwise sufficient retained bound evidence/receipt plus explicit replay limitation.; DES-07 agreed document/edit interface; its implementation need not precede independent document preparation.

**Выход и consumer.** Persisted candidate policy document edition(s) and exact selected DOCX/PDF/rendition bytes with material-role/content binding, source/edition refs, qualifiers and replay/rights limitations; fresh semantic reader and independent actual-format reader resolve the same result.

**Что можно готовить независимо.** After E02 acceptance and source rebind, agree shared DES-06/07 versioned schema and trace existing renderer/export/UI. Public projection remains restricted; format/language usability inputs are conditional and do not gate mechanical source binding.

**Где результат соединяется с другими.** Fresh authorized private/reviewer/EXPERT reader and actual DOCX reader consume the exact selected rendition; CNT-09 can project only permitted case output. An HTML preview alone is not export proof.

**Positive.** A substantive options/proposed-measure/explanation set traces material statements and recomputes selected derivations where required; the actual DOCX text/tables preserve semantic roles and a new profile preserves basis without central domain edits.

**Distinguishing negative.** Unsupported claims stay proposals; changed denominator/rounding, missing qualifications, counterfeit document, restricted audience, or candidate-as-enactment cannot produce a trusted view.

**Matched removal.** Keep citations/watermark/section labels but remove quantity/status/source binding, or replace real DOCX bytes with HTML-in-JSON; fidelity and real-format checks fail.

**Граница контекста.** One document producer-artifact-reader capability with four contained checkpoints: (1) bind selected semantic/source claims, legal-time status and audience/rights; (2) persist the coherent edition/schema and exact rendition bytes; (3) compare sidecar meaning against fresh semantic and independent DOCX/PDF readback, including a changed-cell/sentence removal probe; (4) conditionally verify permitted retained-result use after verified raw erasure with explicit replay limits. The fourth checkpoint does not own erasure or relax rights. DES-05/GYD-05/DES-09 are selected evidence inputs, not writers; DES-07 remains the separate edit-back bridge.
