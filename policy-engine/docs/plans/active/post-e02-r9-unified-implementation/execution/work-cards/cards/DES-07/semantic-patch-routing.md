# DES-07.semantic-patch-routing — Направить изменения к владельцам смысла

Группа: [G08 — Документы, интерфейсы и понятные человеку результаты](../../groups/G08.md). Родитель: [DES-07](../../parents/DES-07.md). Роль: `mechanism`.

Плановая рабочая карточка. Реализация только после E02 acceptance и exact source/lease rebind; эта запись не является execution grant или closure. [Общие правила](../../README.md).

**Проверяемый результат.** Material document edits become scoped candidate patches to the native design/method/legal owner; ambiguous edits remain unresolved, and independent changes compose only when dependency closure proves independence.

**Предпочтительное решение.** Reuse stable semantic IDs and native owner contracts. Route parameter/population/mechanism edits to search/evaluation, factual/legal edits to their owners, and value/goal edits to an explicit alternative or authorized selection. Prose-only rewrites still recheck material entailment; no universal law AST or second LLM equivalence authority.

**Граница владельца.** DES-07 owns edit dispatch/revision composition under write:artifact-document-route and its non-overlapping portion of write:policy-document-owner after agreement with DES-06’s single schema writer. Native Scientist/legal/method owners recompute their own semantics; DES-07 writes candidate patches and dependency routes only. Exact path overlap is unresolved until E02 and cannot be assumed disjoint.

**Входы.** carrier-identity’s exact-base span map; DES-06 shared schema; native owner semantic contracts and dependency graph.; Explicit human mapping only for materially ambiguous edits; unresolved meaning stays candidate/unbound.

**Выход и consumer.** Persisted typed candidate patches/change map with affected native owner, base version, semantic delta, unresolved status and dependency closure; no native owner’s result is directly modified by the import.

**Что можно готовить независимо.** Build mapping tables and single/joint-edit cases independently against the agreed shared schema after interface agreement; do not wait for a carrier instance to prepare them. Actual carrier maps join when routing a selected import. Native recomputation still waits for accepted patches and each owner’s own source/rules.

**Где результат соединяется с другими.** At actual import, join the resolved carrier map and route candidate patches to existing native owners; compose known-independent changes only with actual dependency closure. The fresh-owner-readback card joins actual recomputed owner outputs.

**Positive.** A threshold edit changes the actual numerical trial, a legal exception changes the selected legal/design comparison, and a mechanism edit creates a candidate; known-independent patches preserve each changed meaning.

**Distinguishing negative.** Copied citation with changed assertion, separate spans that jointly alter population/exception, uncertainty removal, ambiguous value/goal change or unsupported prose normalization cannot silently inherit support or merge.

**Matched removal.** Keep revision IDs but remove edit-to-owner dispatch, dependency closure or conflict detection; the fresh recomputation/concurrency discriminator fails.

**Граница контекста.** The card produces candidate patches only; policy design, numerical and legal owners recompute. Bundled edit clauses are reconciled against named native owners and carrier input, not implemented by an import parser as domain logic.
