# DES-08.memory-transfer — Перенести пригодный опыт в последующий поиск

Группа: [G04 — Содержательный поиск политик и перенос опыта](../../groups/G04.md). Родитель: [DES-08](../../parents/DES-08.md). Роль: `mechanism`.

Плановая рабочая карточка. Реализация только после E02 acceptance и exact source/lease rebind; эта запись не является execution grant или closure. [Общие правила](../../README.md).

**Проверяемый результат.** A later search choice changes usefully under an eligible, rights/currentness/contamination-qualified evaluated lesson, or a justified no-transfer is recorded, without turning memory into causal evidence or authority.

**Предпочтительное решение.** Wire existing LessonRegistry, balanced retrieval, transfer/Pareto seeds and hypothesis ledger into later candidate generation. Separate actual evaluated success/failure/opportunity lessons from LLM hypotheses; preserve candidate-only envelope and native ban on active influence modes for LLM-origin BalancedMemory.

**Граница владельца.** DES-08 owns retrieval adapter and durable lesson sink under write:scientist-policy-search, write:search-lessons and write:balanced-memory-consumer. DES-03 shares search.py and remains numerical evaluator writer; LIF-07 owns influence lineage/revocation; GYD-25 owns retrieval adequacy. Exact shared paths must be serialized at E02 rebind, not presumed disjoint.

**Входы.** Actual evaluated source runs and lawful reuse rights; candidate-only hypotheses keep truthful provenance; consume DES-09 call records only if a selected memory-influenced search call actually uses a provider. GYD-09/12 confirmation and activation remain separate obligations, not prerequisites for candidate search learning.; LIF-07 current influence/revocation/eligibility lineage; compatible later task and the predeclared memory-on/off comparison.

**Выход и consumer.** Persisted typed lessons and candidate-only hypotheses with exact refs, eligibility/expiry/revocation/contamination, selected/rejected influence and measured downstream choice/cost; fresh process can retrieve exact references.

**Что можно готовить независимо.** After E02 source rebind, trace native CAS/index/query consumers and inject durable sink only where source proves it missing. No GYD-09/12 confirmation activation is required for candidate learning; protected O1/O3 mutation remains forbidden.

**Где результат соединяется с другими.** The actual later native search consumer joins eligible lesson influence to the subsequent candidate/choice; DES-10 measures transfer and GYD-25 separately measures retrieval adequacy.

**Positive.** A useful compatible lesson changes a later candidate/search choice or mismatch is correctly rejected; a useful opportunity survives failure-heavy memory and actual cost/benefit stay separate.

**Distinguishing negative.** Wrong population/unit/jurisdiction/objective/model, revoked rights, fake success, duplicate cohort, holdout leakage, same-hash permission inference or LLM reflection cannot enter evaluated-evidence memory or activate a world/posterior.

**Matched removal.** Disable retrieval, persistence, eligibility/currentness or recipient checks while retaining lesson refs/labels; fresh-process influence or controlled transfer/privacy probe fails.

**Граница контекста.** One memory-to-later-search capability with five contained checkpoints: (1) distinguish executed/evaluated outcomes from unrun alternatives and candidate LLM hypotheses; (2) persist exact scope, units, model/rule, exposure, cost and provenance; (3) apply compatibility, currentness, rights and LIF-07 invalidation before retrieval or provider context; (4) record selected/rejected lesson influence and the resulting candidate/search change, including typed method-warning behavior; (5) prove fresh-process retrieval and memory-on/off transfer at DES-10. GYD-25 remains retrieval adequacy, not transfer utility; neither memory nor candidate hypotheses write O1/O3 world state. Checkpoints share one retrieval adapter and do not transfer numerical evaluation from DES-03.
