# DES-11.frontier-consumer — Прочитать траекторию в свежем поисковом фронте

Группа: [G05 — Совместные расчёты, траектории и исследования](../../groups/G05.md). Родитель: [DES-11](../../parents/DES-11.md). Роль: `consumer`.

Плановая рабочая карточка. Реализация только после E02 acceptance и exact source/lease rebind; эта запись не является execution grant или closure. [Общие правила](../../README.md).

**Проверяемый результат.** A fresh frontier/dossier consumer resolves the actual persisted trajectory, its exact history/method/assumptions, alternatives and limitations without conflating candidate, enacted policy or observed operation.

**Предпочтительное решение.** Join native trajectory output through the existing Scientist frontier/Cycle Board/reviewer dossier, API and authorized Atlas/document projection. Keep actual act, receipt, operation and candidate/external-act status distinct; show omitted alternatives and uncertainty.

**Граница владельца.** Consumes trajectory-run and existing surface owners; DES-03 remains search.py writer, DES-04 owns feedback bridge, GYD-30 owns joint witness/API changes. DES-11 adds no broad search writer or new dashboard/publication owner.

**Входы.** trajectory-run actual persisted path and history-context refs; selected DES-03 frontier/joint outputs only where their native contract requires.; Existing authorized surface projection and currentness evidence; no public/external-act authority is created.

**Выход и consumer.** Fresh reader result linking path, assumptions, observation cutoff, uncertainty, omitted alternatives, residual commitments and candidate/act boundary.

**Что можно готовить независимо.** Consumer contract can be prepared independently against agreed interfaces; no trajectory run is needed to prepare it. A complete path claim still requires actual evaluator output and selected owner inputs; unsupported dimensions remain limited.

**Где результат соединяется с другими.** The actual fresh Scientist frontier/dossier is the final consumer; authorized API/Atlas/doc projections consume only their existing permitted rendition.

**Positive.** A reader can reproduce the selected conditional trajectory and identify where decisions change only after observable histories diverge.

**Distinguishing negative.** A terminal-only artifact, stale currentness projection, candidate label as enactment or history declaration without evaluator output cannot pass.

**Matched removal.** Remove evaluator output/currentness/actual exposure consumption but retain adaptive headings; fresh reader and independent path oracle detect missing support.

**Граница контекста.** This checkpoint is the actual existing reader, not a second simulator or normative selector. Search/evidence/API suppliers retain their own write leases.
