# DES-12.study-authorization — Проверить разрешение на точную операцию

Группа: [G06 — Допустимость, полномочия и квалифицированные решения](../../groups/G06.md). Родитель: [DES-12](../../parents/DES-12.md). Роль: `verification`.

Плановая рабочая карточка. Реализация только после E02 acceptance и exact source/lease rebind; эта запись не является execution grant или closure. [Общие правила](../../README.md).

**Проверяемый результат.** Before protected dispatch/resume, the native authority owner resolves and recomputes coverage of every load-bearing facet required by the actual operation contract; an uncovered/new facet blocks that action without automatically revoking lawful use of already-returned evidence.

**Предпочтительное решение.** Consume the existing applicable commission/protocol/site permits and action-specific data-use grants. Keep permission for actual conduct separate from current-use rights/admission for returned evidence; do not implement a fixed facet checklist or issue a grant from this plan.

**Граница владельца.** DES-12 owns only the study-specific composition witness under write:native-causal-study-design; the existing native authority/rights owner alone resolves grants and protected dispatch. DES-04/CAP-01 provide their actual inputs, not a new authorization writer. Exact actual-operation facets come from the accepted native authorization contract, not this card’s enumerated examples.

**Входы.** study-design exact protocol/method/version, recipient, purpose, site/population/intervention/measurement and other facets required by the native contract.; Actual owner-resolved commission/site/protocol and action-specific data-use grant; the same grant may not cover an unrelated operation by assumption.

**Выход и consumer.** An audited exact-operation authorization resolution from the native authority owner (admit/limit/refuse/not-established) bound to the actual operation and required facet set; no permission is minted by DES-12.

**Что можно готовить независимо.** Map the current owner contract and construct a generic falsifier: preserve a valid grant/markers but change a required facet or introduce a required facet. Actual dispatch remains conditional on current owner resolution.

**Где результат соединяется с другими.** Only an admitted exact operation can reach the existing external conduct owner through its actual dispatch interface. Separate returned-evidence use gets a fresh current-use rights decision.

**Positive.** A valid applicable primary-study order/site permit plus exact analysis-use grant admits only its covered action; a lawful secondary analysis needs its own applicable rights but not an irrelevant commission.

**Distinguishing negative.** A grant for another protocol/site/recipient/population/intervention, a changed/new required facet, revoked permission, descriptive markers, compute permit or declared design cannot admit protected dispatch.

**Matched removal.** Keep the valid grant and all descriptive permission markers but change one native-required operation facet or add a new required facet; if the authority owner still admits, the property gate fails. Separately check returned-evidence current-use rights.

**Граница контекста.** This is an owner-consumption/verification checkpoint, never a permission issuer. P37/P38 require the predicate to be owner-recomputed from the actual required-facet contract, not a fixed list or field-presence proxy.
