# GYD-12.structural-write — Правилом допущенное structural revision

Группа: [G03 — Каузальное обоснование и обучаемая модель мира](../../groups/G03.md). Родитель: [GYD-12](../../parents/GYD-12.md). Роль: `mechanism`.

Плановая рабочая карточка. Реализация только после E02 acceptance и exact source/lease rebind; эта запись не является execution grant или closure. [Общие правила](../../README.md).

**Проверяемый результат.** A content-bound CNT-06/native-method assessment changes the operative graph only when the actual applicable structural write rule permits that exact transition.

**Предпочтительное решение.** Reuse the same existing Runtime/quality WMR/Fabric writer and the native method/CNT-06 assessment path; add no structural world store and no O1-only policy.

**Граница владельца.** The shared WMR/Fabric owner remains the only writer. The method/identification owner supplies its warrant and the actual structural-rule owner supplies the rule. WP-01/02 govern posterior mutation only and are not structural authority. If no rule is admitted, retain a scoped proposal/conditional result.

**Входы.** Selected CNT-06/native-method structural assessment and verifier provenance.; Measurement, rival/identification and scope bindings.; Actual current structural write rule and WMR predecessor.

**Выход и consumer.** Append-only structural WMR/Fabric generation retaining predecessor, uncertainty, rivals and exact scope; fresh later-cycle readback.

**Что можно готовить независимо.** Rebind the native assessment, structural-rule owner and shared writer/lease.; Resolve rule applicability for the requested transition; do not infer it from scientific qualification or a branch flag.; Persist via the same canonical WMR/Fabric owner and read in a fresh later cycle.

**Где результат соединяется с другими.** Join this route to effect-write only for full GYD-12 reconciliation. Structural preparation/result may proceed without O1 posterior when its actual rule permits; the parent still retains the original GYD-09/GYD-11 effect obligations. After both outputs are present, the selected fresh UI-08 world-growth-view is the GYD-12 acceptance readback over the exact O1 artifact and O3 branch/head, checking cause/origin/time/version, O2 candidate_unverified status, absence of unauthorized posterior mutation and as-of provenance. This downstream completion consumer does not gate independent structural preparation or create a start edge.

**Positive.** A supported assessment under an actual applicable rule reaches the same writer and a later cycle resolves the new structural generation with rivals and uncertainty intact.

**Distinguishing negative.** Unsupported identification, changed measurement/selection evidence, missing rule or marker-only activation cannot mutate the graph.

**Matched removal.** Remove content-bound warrant or applicable-rule binding while keeping ref shapes; structural mutation refuses and preserves predecessor/rivals. Missing O1 posterior alone is not its falsifier.

**Граница контекста.** Distinct scientific proposition on one writer. Keep edge exclusion separate from effect estimation and bounds; no effect-card input or lease is duplicated. The source write rule remains unresolved until its owner confirms it.
