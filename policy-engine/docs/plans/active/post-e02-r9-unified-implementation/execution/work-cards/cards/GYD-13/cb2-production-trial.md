# GYD-13.cb2-production-trial — Реальный operator trial через production command

Группа: [G10 — Независимые проверки и качество свидетельств](../../groups/G10.md). Родитель: [GYD-13](../../parents/GYD-13.md). Роль: `consumer`.

Плановая рабочая карточка. Реализация только после E02 acceptance и exact source/lease rebind; эта запись не является execution grant или closure. [Общие правила](../../README.md).

**Проверяемый результат.** A real permitted operator event passes through the discoverable production command, persists a diagnostic receipt, and is recomputed from fresh stored readback.

**Предпочтительное решение.** Extend the existing runtime/quality/operator_comprehension.py instrument and diagnostic event log; reuse its sealed CB1 corpus and synthetic-only research behavior.

**Граница владельца.** The current runtime/quality instrument and diagnostic-store owners remain canonical. The assigned GYD-13 lead locates/rebinds the actual production caller, event producer and exact reader as engineering preparation, then freezes paths/lease at accepted-source rebind; actual E02 acceptance remains the implementation gate. A real operator-session event is external workload evidence; the instrument never produces or asserts human comprehension. Do not create a trial engine.

**Входы.** Task-lead engineering rebind identifying the existing caller, event producer, command path, diagnostic reader and lease; this does not count as a trial.; Real operator-session/trial event with source, tenant, role, context and time provenance.; Discoverable command registration path.; Sealed CB1 corpus/design and canonical diagnostic-event receipt reader.; Sensitive-payload custody and deduplication semantics.

**Выход и consumer.** Persisted diagnostic trial receipt tied to the real event, input and corpus/design refs; fresh command readback recomputes the score.

**Что можно готовить независимо.** The assigned GYD-13 lead traces/rebinds the existing event producer, command path, event identity and diagnostic reader; record canonical lease overlaps before implementation dispatch.; Retain actual E02 acceptance and parent dispatch predicates. Extend the canonical instrument to accept only resolved real production events.; Read back the just-written event and keep sample credit separate from comprehension claims.

**Где результат соединяется с другими.** The actual production command joins event → existing instrument → persisted diagnostic receipt → fresh recomputation. Independent comprehension adjudication remains a different evidence/input boundary.

**Positive.** One authentic operator invocation constructs a trial, persists one receipt and is recomputed from its stored raw event/corpus/design refs.

**Distinguishing negative.** Missing call/event, synthetic tenant, altered payload, absent content binding or unresolved store receives no production trial credit even if markers remain.

**Matched removal.** Remove the production caller while retaining the command registration and receipt markers; the real consumer test fails.

**Граница контекста.** One CB2 production-consumer property (P01/P02/P38). Caller discovery is owned engineering work; actual operator-session workload evidence is separate and cannot be synthesized by the instrument. Synthetic-tenant research stays research-only; never claim human comprehension, legal adjudication or WP-09 closure.
