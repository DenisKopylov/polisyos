# UI-06.value-grammar — Провести DS16 value algebra до DOM и MACHINE

Группа: [G08 — Документы, интерфейсы и понятные человеку результаты](../../groups/G08.md). Родитель: [UI-06](../../parents/UI-06.md). Роль: `consumer`.

Плановая рабочая карточка. Реализация только после E02 acceptance и exact source/lease rebind; эта запись не является execution grant или closure. [Общие правила](../../README.md).

**Проверяемый результат.** Один DS4/AQ1 grammar preserves set/interval/scalar-where-allowed/unknown/incomparable/refusal and full relation set, units/basis/purpose/provenance/rule/time through generated client and DOM/MACHINE.

**Предпочтительное решение.** Reuse DS4 contract, GY-AQ1 algebra, Cycle Board DTO/projection, canonical generated family and C23 refusal; no scalar/metric producer.

**Граница владельца.** UI-06 owns consumer/client projection only; DS4 grammar, AQ1 relation set, GYD-17 actual DS7 values, DEB-07 relation/rule remain native owners.  Parent native canonical leases: write:exact-path/{canonical_repo_path}; write:runtime-api-generated-family if changed; resource:browser/{profile} if executed. Bind exact paths and overlap at P0; unresolved paths are not presumed disjoint before E02 rebind.

**Входы.** Canonical DS4 oneOf and complete owner-derived AQ1 set; conditional GYD-17 DS7 value/basis; DEB-07 relation/source/rule.

**Выход и consumer.** Actual producer→persisted output→API/client→DOM/MACHINE round-trip; unsupported quantity remains unavailable.

**Что можно готовить независимо.** Bind relation/contract, regenerate family, then compose actual DS7 values; independent prep may proceed before positive supplier.

**Где результат соединяется с другими.** Numeric claim only after actual GYD-17 value/basis and applicable DEB-07 semantics; R15/R16 context stays same reader.

**Positive.** Every current relation and mixed case round-trips; real DS7 value retains its basis/time.

**Distinguishing negative.** Unknown/incomparable/refusal/missing license never coerces to scalar/readiness; placeholder is not DS7.

**Matched removal.** Remove semantic composition with schema markers intact: mixed-value witness fails.

**Граница контекста.** One value reader with staged relation/client/data checks; no variant/time/transport split.
