# UI-14.helm-policy-parity — Сверить deployed Helm policy с canonical Rego

Группа: [G09 — Развёртывание, исполнители, хранилища и ресурсы](../../groups/G09.md). Родитель: [UI-14](../../parents/UI-14.md). Роль: `verification`.

Плановая рабочая карточка. Реализация только после E02 acceptance и exact source/lease rebind; эта запись не является execution grant или closure. [Общие правила](../../README.md).

**Проверяемый результат.** Complete path set and raw policy bytes in packaged Helm mirror equal canonical approved source or deterministic generated mirror; mismatch blocks rollout.

**Предпочтительное решение.** Prefer direct package consumption of ops/policy/policies/**; otherwise deterministic manifest via ops/deploy compares complete paths/raw bytes. Helm signature is separate.

**Граница владельца.** Ops/deploy owns mirror generation/rollout; canonical policy owner retains source authority; UI-14 owns parity evidence only.  Parent native canonical leases: write:exact-path/{canonical_repo_path}; write:runtime-api-generated-family if changed; resource:browser/{profile} if executed. Bind exact paths and overlap at P0; unresolved paths are not presumed disjoint before E02 rebind.

**Входы.** Complete canonical Rego set, packaged bytes, source commit, chart identity/version.

**Выход и consumer.** Versioned parity receipt ties complete source set to deployed chart; mismatch gate.

**Что можно готовить независимо.** Bind direct-consumption vs mirror decision, walk complete paths/raw bytes, then check package signature separately.

**Где результат соединяется с другими.** Fresh rollout consumer verifies parity receipt against exact chart/source identity.

**Positive.** All canonical paths and bytes match in deployed package.

**Distinguishing negative.** Missing/extra/stale/hand-edited/wrong-version path blocks despite chart signature.

**Matched removal.** Change mirror bytes with metadata intact: digest witness fails.

**Граница контекста.** One complete-source parity property; keep concise full-set evidence rather than duplicate content dumps.
