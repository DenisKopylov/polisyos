# UI-16.grounded-performance-claim — Оставить DS11 performance claim blocked без evidence

Группа: [G03 — Каузальное обоснование и обучаемая модель мира](../../groups/G03.md). Родитель: [UI-16](../../parents/UI-16.md). Роль: `consumer`.

Плановая рабочая карточка. Реализация только после E02 acceptance и exact source/lease rebind; эта запись не является execution grant или closure. [Общие правила](../../README.md).

**Проверяемый результат.** DS11-GROUNDED-PERFORMANCE stays blocked/not_established unless substantive promoted-design evidence binds exact claim/source/design/measure/epoch/rule/limits/audience.

**Предпочтительное решение.** Reuse DS11 status and Trust/MACHINE readers; publication/authentication is independent. No invented benchmark threshold.

**Граница владельца.** UI-16 owns truthful projection only; DS11 evidence/promotion owners and independent reviewers produce/reconcile facts.  Parent native canonical leases: write:exact-path/{canonical_repo_path}; write:runtime-api-generated-family if changed; resource:browser/{profile} if executed. Bind exact paths and overlap at P0; unresolved paths are not presumed disjoint before E02 rebind.

**Входы.** Existing DS11 status, actual promoted design and substantive claim-specific evidence if present; absence remains explicit.

**Выход и consumer.** Trust and MACHINE show blocked/not_established or recomputed supported status with bound basis.

**Что можно готовить независимо.** Show blocker/gap now; positive requires actual design evidence and qualified review.

**Где результат соединяется с другими.** Same status across approved Trust/docs/MACHINE consumers; no positive claim without binding.

**Positive.** Absent substantive evidence yields no supported performance assertion.

**Distinguishing negative.** Report authentication, placeholder, synthetic fixture, stale/different-design evidence cannot support claim.

**Matched removal.** Remove evidence binding with green marker: fresh reader recomputes and refuses.

**Граница контекста.** One empirical claim and shared status source, not one task per public reader.
