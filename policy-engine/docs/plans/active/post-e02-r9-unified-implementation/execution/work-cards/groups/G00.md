# G00. Вход в программу, интеграция и итоговый допуск

Принятый E02 → сверенный source/obligation scope → freeze/review/replay → решение о допустимом первом применении.

Собирает реальные результаты всех групп; не реализует их механизмы вместо назначенных owners.

Это навигационная группа по способности. Она не владеет кодом и не создаёт общей стартовой зависимости. Каждая карточка ниже имеет один primary home; cross-group результаты потребляются по ссылке.

| Рабочая карточка | Роль | Результат |
|---|---|---|
| [P0-ACCEPT.accepted-boundary](../cards/P0-ACCEPT/accepted-boundary.md) — Read back the competent E02 acceptance | `coordination` | Read-back acceptance record with immutable source/tree, precise admitted scope, inputs, backends, limitations, exclusions and decision provenance. |
| [P0-REBIND.original-set-reconciliation](../cards/P0-REBIND/original-set-reconciliation.md) — Reconcile every original obligation | `coordination` | Append-only per-original-predicate disposition and owner/consumer closure map, with unresolved rows retained and bounded scoped release evidence. |
| [FINAL-FREEZE.immutable-candidate](../cards/FINAL-FREEZE/immutable-candidate.md) — Зафиксировать immutable review candidate | `coordination` | Immutable freeze candidate manifest with source/input/backend identity, internal readiness, open external facts and exact replay matrix. |
| [FINAL-REVIEW.independent-review](../cards/FINAL-REVIEW/independent-review.md) — Провести independent review и delta review | `coordination` | Bound review receipts, classified finding ledger, delta-review result and final immutable review identity. |
| [FINAL-REPLAY.one-wave-replay](../cards/FINAL-REPLAY/one-wave-replay.md) — Координировать один frozen replay wave | `coordination` | One wave journal with per-row source-bound result/status, complete inputs and actual consumer property outcomes; no overwritten historical receipts. |
| [FINAL-USE.scoped-use-dossier](../cards/FINAL-USE/scoped-use-dossier.md) — Подготовить source-qualified first-use dossier | `coordination` | Source-qualified use dossier with every original row, accepted evidence/formal closure, residuals, validity/reissue triggers and explicit human decision record. |
