# G01. Поиск, получение и точная фиксация источников

Запрос/выбор источника → законный capture/query → immutable representation и provenance → допущенный consumer.

Передаёт точные representations и source changes в смысловые, расчётные и custody consumers; capture не выдаёт authority.

Это навигационная группа по способности. Она не владеет кодом и не создаёт общей стартовой зависимости. Каждая карточка ниже имеет один primary home; cross-group результаты потребляются по ссылке.
