# G02. Смысл оснований: право, метрики, ценности и участники

Полученные источники → source-bound смысл/единица/время/назначение → typed основание → конкретный design/use.

Не подменяет методикой расчёта политическое полномочие, фактическим текстом — действующее право, testimony — representativeness.

Это навигационная группа по способности. Она не владеет кодом и не создаёт общей стартовой зависимости. Каждая карточка ниже имеет один primary home; cross-group результаты потребляются по ссылке.
