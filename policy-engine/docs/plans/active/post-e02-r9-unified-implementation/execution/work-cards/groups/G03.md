# G03. Каузальное обоснование и обучаемая модель мира

Точные наблюдения/гипотезы → идентификация и независимая проверка → bounded effect/knowledge → versioned world update.

Confirmatory effects, exploratory candidates, calibration и structural knowledge сохраняют разные основания и consumer rules.

Это навигационная группа по способности. Она не владеет кодом и не создаёт общей стартовой зависимости. Каждая карточка ниже имеет один primary home; cross-group результаты потребляются по ссылке.
