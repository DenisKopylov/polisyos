# G04. Содержательный поиск политик и перенос опыта

Intent/основания → разные mechanisms/hypotheses → feedback/acquisition/search choice → полезный следующий candidate.

LLM formulations и retrieved experience остаются candidates; действующие outcomes и authority приходят от своих owners.

Это навигационная группа по способности. Она не владеет кодом и не создаёт общей стартовой зависимости. Каждая карточка ниже имеет один primary home; cross-group результаты потребляются по ссылке.
