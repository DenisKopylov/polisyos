# G05. Совместные расчёты, траектории и исследования

Выбранные methods/models/assumptions → native execution/composition → scoped результат/uncertainty → design comparison или новый evidence intake.

Не вводит общий внешний solver, второй scheduler или обязательную технологию для каждого профиля.

Это навигационная группа по способности. Она не владеет кодом и не создаёт общей стартовой зависимости. Каждая карточка ниже имеет один primary home; cross-group результаты потребляются по ссылке.
