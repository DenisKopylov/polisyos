# G06. Допустимость, полномочия и квалифицированные решения

Candidate/evidence/mandate → owner-qualified admission → limitation/refusal/decision → разрешённая claim/surface.

Institutional acts поступают как настоящие внешние inputs; механизм проверки не назначает issuer и не выдаёт полномочие.

Это навигационная группа по способности. Она не владеет кодом и не создаёт общей стартовой зависимости. Каждая карточка ниже имеет один primary home; cross-group результаты потребляются по ссылке.
