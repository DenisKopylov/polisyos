# G07. Долгая custody: актуальность, права и переиздание

Enrolled dependency/duty → admitted change/expiry/observation → bounded revalidation/reuse/reissue → честный current/history reader.

Один currentness/influence/rights owner на свой инвариант; нет обещания невидимого continuity или recall неизвестных копий.

Это навигационная группа по способности. Она не владеет кодом и не создаёт общей стартовой зависимости. Каждая карточка ниже имеет один primary home; cross-group результаты потребляются по ссылке.
