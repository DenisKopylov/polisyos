# G08. Документы, интерфейсы и понятные человеку результаты

Admitted native output → exact semantic projection/document → authorized audience → edit/history/feedback readback.

Transport и оформление не создают новой authority. Связанные API/browser/MACHINE consumers проверяют один смысловой контракт.

Это навигационная группа по способности. Она не владеет кодом и не создаёт общей стартовой зависимости. Каждая карточка ниже имеет один primary home; cross-group результаты потребляются по ссылке.
