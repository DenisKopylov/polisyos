# G09. Развёртывание, исполнители, хранилища и ресурсы

Commissioned profile → native worker/store/permit → bounded actual execution → verified recovery/egress/result.

Локальный, cloud/hybrid и offline режимы выбираются по исходным требованиям; tiers не становятся общей цепью ожидания.

Это навигационная группа по способности. Она не владеет кодом и не создаёт общей стартовой зависимости. Каждая карточка ниже имеет один primary home; cross-group результаты потребляются по ссылке.
