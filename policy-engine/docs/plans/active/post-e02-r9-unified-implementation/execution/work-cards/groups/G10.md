# G10. Независимые проверки и качество свидетельств

Полный source-derived scope → independent oracle/negative/removal → exact deciding output → composed acceptance.

Готовность verifier отличается от прогона и от product acceptance. Финальные кампании соединяются в одну объявленную wave.

Это навигационная группа по способности. Она не владеет кодом и не создаёт общей стартовой зависимости. Каждая карточка ниже имеет один primary home; cross-group результаты потребляются по ссылке.
