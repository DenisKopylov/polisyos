## Реальный join

import-isolation emits Deterministic test result proving production module identity is restored or case is process-isolated.; catalog-absence emits Typed missing-catalog refusal from the real loader and a source-qualified test receipt.; value-discriminant emits Resolved producer-bound discriminant receipt and typed refusal for malformed/unresolved bytes.; education-red-provenance emits Source-qualified inherited/owned/not_established attribution receipt; unresolved stays not_established.; gy-def22-owner emits Source-qualified owner acceptance over current bounded-claim denominator, or explicit open status.. Root reconciles these exact outputs at the original parent disposition and sends the composed result to Fresh governed-projection runtime test, production catalog loader/census, runtime value gate, root P41 status consumer and competent GY-N12 owner acceptance consumer.. This join does not create implementation, a second owner, or an extra start gate.

**Outputs:** [DEB-04.import-isolation](../cards/DEB-04/import-isolation.md), [DEB-04.catalog-absence](../cards/DEB-04/catalog-absence.md), [DEB-04.value-discriminant](../cards/DEB-04/value-discriminant.md), [DEB-04.education-red-provenance](../cards/DEB-04/education-red-provenance.md), [DEB-04.gy-def22-owner](../cards/DEB-04/gy-def22-owner.md).
