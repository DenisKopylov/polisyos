## Реальный join

Reconcile the two DES-03 outputs at the fresh Scientist frontier and verify that every claimed Pareto/feasibility/model-sensitive result has actual trial, joint-composition and value suppliers. Keep missing model completions and unrun branches incomplete; the trial card does not imply the consumer has integrated them.

**Outputs:** [DES-03.trial-binding](../cards/DES-03/trial-binding.md), [DES-03.frontier-composition](../cards/DES-03/frontier-composition.md).

**Fresh consumer / ответственный контур:** The existing fresh Scientist frontier/dossier reader, consuming actual DES-03 trial output, GYD-30 CompositionCertificate and GYD-31 ValueOuterSet; optional selected DES-11 trajectory output is consumed only where applicable.

**Review размера:** R25 DES-03 is refined into actual method-bound trials and their fresh frontier consumer. The same DES-03 writer owns all native search lease families; GYD-30/GYD-31 remain named suppliers. DES-11 output is conditional and no cycle is added.
