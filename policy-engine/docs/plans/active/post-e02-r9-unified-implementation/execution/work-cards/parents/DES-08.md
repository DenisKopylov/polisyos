## Реальный join

DES-08 persists and retrieves source-qualified search lessons through the existing memory owner. For the selected formulator path it supplies exact retrieval/sink intent to DES-01, the single formulator wiring owner; DES-02 owns hypothesis binding. Fresh next-cycle consumers discriminate useful transfer from unsupported analogy; DES-03/LIF-07/GYD-25 retain numeric, lineage and adequacy roles. Missing native DES-01 plumbing is assigned there, not implemented twice or treated as an external input.

**Outputs:** [DES-08.memory-transfer](../cards/DES-08/memory-transfer.md).

**Fresh consumer / ответственный контур:** Fresh subsequent Scientist search consumer, plus DES-10’s matched later-task transfer comparison; GYD-25 remains the retrieval-adequacy reader.

**Review размера:** Retain one later-search memory path, but make its staged proof explicit: evaluated-vs-candidate intake; persisted provenance; rights/currentness/invalidation eligibility; recorded influence on a real later search; fresh-process and memory-on/off transfer readback. DES-10 owns transfer-quality measurement, GYD-25 retrieval adequacy, LIF-07 influence invalidation and DES-03 numerical evaluation.

Ниже сохранённые parent-wide clauses, а не разрешение спрятать реализацию. Они должны быть доказаны outputs названных карточек, собственным coordination decision или настоящим external input. Shared constraint сам не является выполненной работой.
