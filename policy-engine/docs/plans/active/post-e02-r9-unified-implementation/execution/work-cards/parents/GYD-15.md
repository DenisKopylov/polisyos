## Реальный join

Join four separately persisted capability outputs—independent runtime-subtree cutoff receipt, exact native-owner receipt-store resolution, verified platform/toolchain profile and purpose/role/source-bound production-data trust result—at the current N8 production consumer. The assigned GYD-15 task lead owns engineering discovery/rebind of each existing writer and reader and its canonical lease before implementation dispatch; freeze exact paths at accepted-source rebind. Actual E02 acceptance and the parent’s stage/conditional/resource predicates remain required for implementation. That discovery cannot supply independent cutoff evidence, institutional grants/signer/labels, or supported-profile/runtime facts. If a native chain is absent, retain absent/unallocated/refusal; if required external evidence is actually absent, preserve the corresponding fail-closed result. FR-AUTH-01 is proposal input, not authority or a blanket start gate.

**Outputs:** [GYD-15.subtree-cutoff](../cards/GYD-15/subtree-cutoff.md), [GYD-15.receipt-resolution](../cards/GYD-15/receipt-resolution.md), [GYD-15.toolchain-admission](../cards/GYD-15/toolchain-admission.md), [GYD-15.data-trust](../cards/GYD-15/data-trust.md).

**Fresh consumer / ответственный контур:** The current production method-catalog/N8 consumer and its audit projection, freshly resolving each of the four source-bound receipts through dependency_authority, Core CAS and snapshot-to-N8 transport.

**Review размера:** R25 split retained into four actual capability homes G09/G07/G09/G06. Each has a distinct predicate and native owner; no generic authority engine, common-writer shortcut or dual owner. The exact paths and leases are unresolved and must be reconciled at E02 before claiming non-overlap. Shared N8 join is composition only.
