## Реальный join

Root joins one C1 joint-result/family receipt with C2 only for a selected temporal/SCC profile and C3 only for an actual Foundry cache read. Stochastic invocation identity remains native DES-03/GYD-30 and LIF-04 recovers the same intent.

**Outputs:** [GYD-30.c1](../cards/GYD-30/c1.md), [GYD-30.c2](../cards/GYD-30/c2.md), [GYD-30.c3](../cards/GYD-30/c3.md).

**Fresh consumer / ответственный контур:** The actual workflow caller’s fresh consumer of the persisted joint result; it resolves C2 recovery only for selected temporal/SCC claims and C3 influence/currentness only for actual cache reuse.

**Review размера:** R25 C1/C2/C3 retained. C1 is sole GYD-30 joint-result writer; C2 consumes DES-11; C3 consumes LIF-07/LIF-02. No new DAG edge, second ledger/lineage/scheduler or blanket simulation mandate.
