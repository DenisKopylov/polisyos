## Реальный join

accepted-boundary emits Read-back acceptance record with immutable source/tree, precise admitted scope, inputs, backends, limitations, exclusions and decision provenance.. Root reconciles these exact outputs at the original parent disposition and sends the composed result to Root P0-REBIND journal consuming the exact read-back decision.. This join does not create implementation, a second owner, or an extra start gate.

**Outputs:** [P0-ACCEPT.accepted-boundary](../cards/P0-ACCEPT/accepted-boundary.md).

**Fresh consumer / ответственный контур:** Root P0-REBIND journal consuming the exact read-back decision.

**Review размера:** Root reads back the actual competent G decision and immutable accepted boundary; no product leaf exists.

Ниже сохранённые parent-wide clauses, а не разрешение спрятать реализацию. Они должны быть доказаны outputs названных карточек, собственным coordination decision или настоящим external input. Shared constraint сам не является выполненной работой.
