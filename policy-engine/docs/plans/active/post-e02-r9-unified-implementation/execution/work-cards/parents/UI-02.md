## Реальный join

Собрать persisted exact-view record/refusal, pre-persistence egress result и per-placement LIF-05 outcomes. Итог проверяет свежие реальные PUBLIC/REVIEWER/EXPERT/MACHINE/browser/API/CLI/audit readers, выбранный egress canary и LIF-05 canary; исходные DS12 criteria/conditionals остаются.

**Outputs:** [UI-02.public-record](../cards/UI-02/public-record.md), [UI-02.private-egress](../cards/UI-02/private-egress.md), [UI-02.placement-rights](../cards/UI-02/placement-rights.md).

**Fresh consumer / ответственный контур:** Built public route и actual authorized audience readers (browser/API/client, MACHINE, CLI, audit) плюс выбранные history/export/cache/restore paths после P0 binding.

**Review размера:** Точный R25 split: exact record/audience, private egress, LIF-05 lifecycle. Accessibility, locale, headers, responsive, performance и human review остаются обязательными companions.
