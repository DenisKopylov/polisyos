## Реальный join

Complete the assigned internal allocation work and retain the genuine competent-architect decision. If no existing Docs owner can be appointed, mark docs-ia absent/unallocated with a re-entry trigger rather than holding indefinitely or inventing a substitute. Then reconcile the fresh DS11 Trust posture and any authorized Docs IA reader; genuine external publication rights remain a separate permission input.

**Outputs:** [UI-15.trust-docs-allocation](../cards/UI-15/trust-docs-allocation.md), [UI-15.trust-posture](../cards/UI-15/trust-posture.md), [UI-15.docs-ia](../cards/UI-15/docs-ia.md).

**Fresh consumer / ответственный контур:** Fresh DS11 MACHINE/Trust projection and appointed Docs landing/article reader; exact paths only after recorded allocation.

**Review размера:** Split by actual architecture decision and owners, not pages; content delivery stays conditional and creates no CMS.
