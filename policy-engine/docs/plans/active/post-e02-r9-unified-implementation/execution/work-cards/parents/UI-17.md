## Реальный join

Join route/right/cutoff, gross VOI value/basis and separate cost/net utility only for the actual consuming claim/action; fresh DS15 projection verifies each claim independently. Reconcile UI-20 semantic lease without inventing DAG edge.

**Outputs:** [UI-17.route-eligibility](../cards/UI-17/route-eligibility.md), [UI-17.gross-voi](../cards/UI-17/gross-voi.md), [UI-17.cost-net](../cards/UI-17/cost-net.md).

**Fresh consumer / ответственный контур:** Fresh existing acquisition route/projection/client reading CAP/LIF route facts, DEB-13 VOI and separate cost/utility outputs.

**Review размера:** Split by three typed claims/owners, never transport. Gross VOI survives unknown cost; net/action composes only its estimand inputs.
