# Dispatch pack

Use [orchestrator](orchestrator.md) in the future execution chat only after actual E02 acceptance. Root supplies the accepted immutable base and the current plan commit. It dispatches [writer](writer.md), [reviewer](reviewer.md), [verification](verification.md) and [foundation supplier](foundation-supplier.md) assignments directly.

Resolve placeholders before dispatch. A worker receives one ready task or a coherent conflict-free subset from `tasks.json`, its detailed workstream document, exact upstream artifacts and the full read/write/resource lease. A planning role does not gain product ownership by title. No worker may create children; requests for extra capacity return to root.

The prompt is an implementation aid, not a replacement for canonical AGENTS/CONTRIBUTING, actual E02 acceptance, original criteria or commissioned authority. Unavailable external evidence stays scoped; implementation research and independent tasks continue.
