Use [orchestrator](orchestrator.md) in the future execution chat only after actual E02 acceptance. Root supplies the accepted immutable base and the current plan commit. It admits [writer](writer.md), [reviewer](reviewer.md), [verification](verification.md) and [foundation supplier](foundation-supplier.md) assignments, directly or through a runtime-permitted [lead grant](lead.md).

Resolve placeholders before dispatch. A worker receives one ready task or a coherent conflict-free subset from `tasks.json`, its detailed workstream document, exact upstream artifacts and the full read/write/resource lease. A planning role does not gain product ownership by title. Only a lead holding an explicit root grant may create one level of children, if the runtime permits it. Leaf prompts never delegate. The global ceiling is100 non-root agents including all leads and descendants, not100 per lead. Runtime direct-only rules take precedence.

The prompt is an implementation aid, not a replacement for canonical AGENTS/CONTRIBUTING, actual E02 acceptance, original criteria or commissioned authority. Unavailable external evidence stays scoped; implementation research and independent tasks continue.
