- **observation**: Static docstring limits class to exact observed DAG adjustment-preservation; GYD-30 names IR/PDC reconciliation.

**decision.**

Low→target approximation within one causal branch is fidelity error; structure change is another branch. Deterministic enclosure is not a confidence interval. A branch pass is local; a set pass over selected required branch×constraint cells needs all cells plus valid simultaneous stochastic coverage. Pointwise bounds do not compose automatically. Repeated/adaptive fidelity looks or postselection need an anytime/alpha-spending or selection-aware rule for the full family; otherwise keep branch results but limit the set claim. Unselected models are not covered. Crossing a floor is limited; only opposite qualified branch outcomes are contested. No model weights; ValueOuterSet stays separate.

**alternatives.**

- **option**: Prune/authorize by MFBO rank
- **tradeoff**: Полезен для scheduling, но regret/rank не сертификат hard floor.

- **option**: Average branches or always max fidelity
- **tradeoff**: Averaging требует justified weights; max fidelity тратит бюджет без решения всех структурных альтернатив.

**contract.**

Bind candidate/objective; required selected branch set and grounds; target/constraints/units/support/horizon/cut; method/backend/executable/profile and validity; actual result; deterministic vs pointwise/simultaneous/anytime guarantee; coverage level and branch×constraint×look family; dependence, selection/stopping rule; value refs, spend, timeouts and omitted denominator.

**flow.**

- CNT-08 supplies source-qualified model-set/basis alternatives; producer records each branch/constraint result and guarantee kind.

- GYD-30 persists runs/looks; LIF-07 binds read/reuse basis.

- DES-03 consumes the family rule; GYD-31 supplies values; OPS-08/LIF-06 meter nested work.

- Fresh reader composes branch and family guarantees; DES-06 projects coverage, costs and limits.

**migration.**

Legacy fidelity score without recoverable target relation stays historical/candidate; no retroactive bound. Re-evaluate affected current uses under actual rights/generations.

**free_grow.**

Profiles/branches use existing registries. New guarantee class needs producer, validity/error semantics, consumer and conformance evidence; no domain whitelist or global threshold.

**resource_behavior.**

Meter repeated fidelity looks; spent alpha is not reset by pruning or a profile switch. Exhaustion leaves unrun family cells visible and the set claim limited.

## R18-D07-Q01. Разная точность внутри спорного множества моделей

Какой вывод о доминировании, допустимости или устойчивости решения остаётся обоснованным, когда конкурирующие модели проверены на разных уровнях fidelity, а их численные error bounds пересекают границу решения при частично исчерпанном бюджете? Как отделить действительное расхождение причинных моделей от различия численной точности, не вводя вероятности моделям или общий порог для всех случаев?

**Выбранное решение.**

Separate fidelity error within a causal branch from model disagreement. A low→target envelope crossing the floor limits that branch; opposite qualified branch results are contested. A robust claim over selected required branches needs every branch×constraint cell to pass and simultaneous stochastic coverage at the declared level. Pointwise intervals do not imply set confidence; adaptive looks/postselection require coverage correction. Deterministic enclosures are distinct. Missing branches stay in the denominator; differing estimands need grounded mapping. No default model weights or ValueOuterSet collapse.

**mechanism_ids.**

- S07-M1

**specific_steps.**

- Freeze selection grounds, required branches, target/constraints, units, support, horizon and cut.

- Bind each error source and validity domain; separate deterministic enclosure from statistical coverage.

- Declare the branch×constraint family and joint error budget; use a valid simultaneous rule. Adaptive looks require anytime validity, alpha spending or selection-aware confirmation.

- Cheap profiles guide search only; hard claims need applicable bounds/target runs under the required family rule.

- Refine only where a permitted run can change the decision; else preserve branch evidence and limit the set result.

**authority_time_status.**

Per-branch result vs selected-family guarantee; shared authority/time binding applies.

**external_inputs.**

- Source-qualified required model set, method guarantees, dependence/coupling and validity domain

- Grounds for required branches and authorized target/population/constraints

- Declared family confidence/error budget; no optimizer-supplied model prior

**unresolved_research.**

No universal joint rule spans methods. Use profile-valid finite-family alpha allocation/union bound or dependence-aware procedure; adaptive looks need time-uniform coverage or correction. Postselected/uncovered cells stay limited.

**Изменения существующих задач и различающие проверки.**

- **task_id**: GYD-30
- **role**: joint-result owner
- **delta**: Persist guarantee kind, branch×constraint family, looks/selection and full timeout denominator; reconcile certificate owners.
- **positive**: All cells clear by deterministic bounds or a declared joint stochastic rule.
- **adversarial**: 20 independent pointwise 95% cells all cover with probability ≈0.95^20=0.36; adaptive peeking or omitted branch also defeats nominal set confidence.
- **removal**: Remove joint/look coverage but keep labels; fresh reader downgrades set pass, retaining branch results.

- **task_id**: DES-03
- **role**: search consumer
- **delta**: Do not prune on pointwise intervals after adaptive selection.
- **positive**: Refinement changes the frontier or leaves an honest limited frontier.
- **adversarial**: Stop at first passing look or postselect best branch.
- **removal**: Drop family-rule consumption but keep scores; small-case oracle rejects set pass.

- **task_id**: OPS-08
- **role**: shared compute owner
- **delta**: Meter nested fidelity calls, retries and looks under aggregate permits.
- **positive**: Budget ends in completion or visible unrun cells/limited result.
- **adversarial**: Per-branch caps fit but repeated looks exceed host budget.
- **removal**: Remove shared admission; concurrent probe exceeds cap despite local markers.

- **task_id**: DES-10
- **role**: existing independent verifier
- **delta**: Test deterministic-vs-stochastic, family coverage and adaptive-look semantics in existing comparison.
- **positive**: Small branch/constraint oracle separates pointwise limitation from joint pass.
- **adversarial**: Keep nominal labels, remove multiplicity/look correction.
- **removal**: Remove actual interval/family consumer; fresh comparator fails.

- **task_id**: CNT-08

## R18-D07-Q02. Объяснение сдвига при одновременном обновлении данных и модели

Когда между двумя редакциями одновременно меняются evidence cut, measurement, model structure, method/backend или fidelity profile, какое объяснение сдвига рекомендации PolicyOS вправе подписать: только перечень новых оснований и результат совместного пересчёта, или атрибуцию отдельных вкладов при взаимодействии изменений? Если один из прежних профилей уже нельзя исполнить, что позволяет отличить установленную причину смены рекомендации от контрфактического сравнения, которого система фактически не проводила?

**Выбранное решение.**

Minimum evidence is basis-delta vector plus actually executed joint recompute. This supports “basis changed; old stored result X, new run Y”, not individual contributions. Optional allocation needs comparable target/metric and actual valid coalitions over frozen baseline/factors/v(S). A complete small game can yield Shapley allocation with sum_i φ_i=v(N)−v(∅); interaction is already allocated across the Shapley values. A separately shown factorial interaction contrast is diagnostic, not a third contribution. If coalitions are invalid/unrun, estimand changed or old executable unavailable, report whole-basis delta and unavailable attribution. Keep value-set rerank separate from empirical effect.

**mechanism_ids.**

- S07-M2

**specific_steps.**

- Bind old/new edition, source cut, estimand, model/scenario, executable/profile, rules/rights and value basis.

- Report only actual changed/common basis, reused/recomputed work, comparability, runs and uncertainty.

- Define valid factor toggles; if target/support differ without mapping, do not subtract.

- Run actual coalitions under same use context/branch; account for timeout and stochastic coupling.

- For a complete valid set show allocations and interaction separately; assert Shapley efficiency against direct delta. Otherwise report direct delta only.

**authority_time_status.**

Old result remains as-known; allocation cannot re-sign. Shared authority/time binding applies.

**external_inputs.**

- Custodian corrections/cuts/retention rights

- Authorized goal/value/mandate basis for ranking

- Lawful availability of historical executable and inputs

**unresolved_research.**

Some hybrid factor subsets are invalid/incomparable and exact cost is 2^k per branch. The chosen game and uncertainty remain case-specific; verify sum_i φ_i=direct delta and never sum a separate interaction contrast as another allocation.

**Изменения существующих задач и различающие проверки.**

- **removal**: Remove basis edge but keep labels; fresh reader refuses reuse/attribution.

## self_attack

- **case**: High fidelity accurately solves a wrong causal model.
- **repair_or_bounded_limit**: Keep bound branch-local; preserve other grounded K_world alternatives and external identification limits.

- **case**: Only survivors of cheap-fidelity pruning calibrate the error bound.
- **repair_or_bounded_limit**: Bind selection exposure and validate scope; otherwise rank candidates only and retain pruned coverage as unknown.

- **case**: Metric/support and method change together, yet delta/Shapley looks precise.
- **repair_or_bounded_limit**: Require common estimand/mapping; else show separate results. Verify Shapley shares sum to delta; never add the interaction contrast.

- **case**: Shapley labels value-schedule change an empirical effect.
- **repair_or_bounded_limit**: Separate authorized ValueOuterSet reranking; allocation cannot sign causal claim.

- **case**: Pointwise stochastic intervals look green after many branches, constraints or adaptive fidelity looks.
- **repair_or_bounded_limit**: Require a selected-family joint rule and anytime/look correction; otherwise retain per-cell evidence with no family-level pass.
