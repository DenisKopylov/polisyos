### S08-M1. Frame-bound branches; retain the open remainder

**native_owner.**

DES-01 intent/frame handoff; DES-02 N4 and hypothesis ledger; DES-04 N6 feedback/frontier; DES-10 bounded assurance.

**reuse_anchors.**

- **path**: src/polisyos/scientist/policy_design/search.py
- **symbol**: HierarchicalSearchCoordinator.generate_structure_candidates, build_parameter_search_spec, run_parameter_search
- **observation**: Static only: structural/parameter search exists; per-frame scope is not established here.

- **symbol**: RunHierarchicalPolicySearchNode, persist_policy_frontier_report
- **observation**: Static only: existing node persists candidate/evaluation frontier.

**decision.**

Bind each candidate/trial to exact request frame and invocation. Unselected framings remain retained, unrun hypotheses, outside selected-frame coverage; explore only as separate bounded branches and report frontiers side by side. User selection routes work but is not a political mandate.

**alternatives.**

- **option**: Union every framing into one frontier
- **tradeoff**: Hides the problem/objective each option answers.

- **option**: Discard unselected framings
- **tradeoff**: Turns a bounded search into a false claim about the original request.

**contract.**

**flow.**

- DES-04 consumes actual results and retains rejected/unexecuted/truncated branches.

- Fresh frontier reader resolves exact frame and denominator.

- Reviewer surface shows selected frame, retained frames, actual coverage and limits.

**migration.**

Do not infer missing historical frame provenance from candidate IDs; legacy scope stays not established.

**free_grow.**

New framings and mechanisms remain open-ended; no fixed frame catalog.

**resource_behavior.**

Run selected frame by default; additional frames receive separate bounded permits only when requested/useful.

### S08-M4. Separate method stop, scoped decision completion and search exhaustion

**native_owner.**

DES-03 optimizer; DES-04 N6/N7 terminal/next action; DES-10 positive controls; DES-11 policy trajectories; LIF-06/OPS-08 actual resource caps.

**reuse_anchors.**

- **path**: src/polisyos/runtime/quality/workspace/loop.py
- **symbol**: SearchExitDecisionInputs, select_search_terminal
- **observation**: Static only: typed source-gap, untried-work, acquisition, budget and stable terminals; Slice-0 only.

- **path**: src/polisyos/runtime/quality/generation_cycle.py
- **symbol**: _select_terminal_kind, _refinement_decision, _derive_fronts
- **observation**: Static only: N6 fronts/terminals exist; fallback sets stable=true and high_voi_untried=false.

- **path**: src/polisyos/scientist/methods/search/strategies/multi_objective.py
- **symbol**: MOBayesianOptimizer.suggest, get_pareto_front
- **observation**: Static only: multiobjective front and fallback exist; absent axes remain invisible.

**decision.**

Represent separately (1) optimizer method terminal, (2) result for the declared need within exact scope, and (3) exhaustion of a finite enumerated branch set. A plateau, cap, provider failure or no current high score means at most limited/incomplete plus actual omissions/next action. Scoped completion can precede global exhaustion only when the declared need is answered by actual admissible support. Exhaustion requires a finite versioned set and a complete evaluated denominator. Current-scope abstention is not a claim that no useful mechanism exists.

**alternatives.**

- **option**: Treat stagnation as policy-space exhaustion
- **tradeoff**: Confuses method limits with absent mechanisms.

- **option**: Require exhaustive search before any scoped completion
- **tradeoff**: Imposes impossible global proof and holds useful decisions open.

- **option**: Allow any empty result as successful abstention
- **tradeoff**: Fails DES-10 known-solvable productivity controls.

**contract.**

Existing terminal and frontier artifacts retain frame, source/model cutoff, method/rule version, actual resource receipt, branch denominator (visited/evaluated/rejected/unexecuted/truncated), decision result and next action/unavailable reason. No new exhaustion enum.

**flow.**

- Optimizer/acquisition route emits actual method terminal/cost.

- N6 persists terminal with frame, basis and incomplete branches.

- DES-04 checks real untried routes; resource owners enforce physical limit.

- DES-10/fresh frontier distinguish supported scoped result from empty search or false exhaustion.

- Cycle Board reports scope, omissions, terminal and next action.

**migration.**

Never reinterpret historical frontier-stable or abstention as exhaustive.

**free_grow.**

Method-specific stopping profiles can grow through native owner; decision closure remains case-scoped.

**resource_behavior.**

Retain useful partial artifacts; cap retries; release/defer measured resources and preserve terminal reserve.

**source_ids.**

### S08-M5. Matched search-path sensitivity under a frozen basis

**native_owner.**

DES-02 proposal lineage; DES-03 numeric search; DES-04 feedback; DES-08 memory; LIF-07 influence/reuse; DES-10 matched assurance. DES-11 remains policy-trajectory owner.

**reuse_anchors.**

- **path**: src/polisyos/scientist/methods/search/strategies/space.py
- **symbol**: SearchSpace.sample_sobol, sobol_space_fingerprint, validate_sobol_sampler
- **observation**: Static only: sampler version, seed and space fingerprint are tracked.

- **path**: src/polisyos/scientist/methods/search/lessons.py
- **symbol**: LessonRegistry.record_local, query, query_with_transfer
- **observation**: Static only: CAS lessons and scoped transfer lookup.

- **path**: src/polisyos/runtime/quality/hypothesis_ledger.py
- **symbol**: HypothesisLedgerEntry
- **observation**: Static only: candidate status is separate from authority.

**decision.**

Freeze frame, evidence/model/value/rule basis, method/provider profile, rights and ceilings. Use seed repetitions and OFAT as main-effect/stochastic screens. Before outcomes, predeclare a small paired/factorial/covering subset only for plausible case-specific couplings (e.g. memory×provider or feedback×order); share baselines, equalize ceilings and record combinations, aliases and untested pairs. No full world matrix or default run quota. If a relevant interaction is untested/unaffordable, report main-effects-only sensitivity and broader robustness not established. Compare numeric fronts, independent semantic families, missed branches, false abstention and costs; distinguish fresh runs from replay and policy trajectories.

**alternatives.**

- **option**: Use one deterministic replay as robustness proof
- **tradeoff**: Replay checks interpretation, not alternative search paths.

- **option**: Pool seeds/candidates as independent cases
- **tradeoff**: Inflates support; cases are units and seeds are nested.

- **option**: Call every path difference evidence change
- **tradeoff**: Confuses method/history with empirical source change.

**contract.**

Bind exact frame/basis, method/provider, seed/order, feedback/memory influence, costs and branch denominator. Also bind any predeclared factor/pair design, shared baseline, tested combinations, aliases and untested settings. LIF-07 qualifies reuse; DES-10 reads full arms. Claims cover only tested settings under the frozen basis.

**flow.**

- DES-02/03 record candidates, trials and ancestry; DES-04 feedback/order; DES-08 eligible memory.

- Existing artifacts retain arm settings and denominators.

- DES-10 compares OFAT and predeclared relevant interaction arms at equal ceilings; LIF-07 invalidates changed-basis reuse.

- Fresh report states tested/untested scope, aliases, semantic and numeric variation, and cost.

**migration.**

Do not synthesize missing seed/provider/memory provenance for old runs.

**free_grow.**

New method profiles join existing matched comparison; no universal robustness engine.

**resource_behavior.**

Use shared baselines and only case-plausible predeclared interactions. No full factorial/world matrix or default quota. If budget prevents a relevant pair screen, narrow the claim to observed main effects.

## R18-D08-Q01. Граница поиска при конкурирующих постановках

**authority_time_status.**

Bind frame, invocation, cutoff, rule/profile and time; frame selection is routing, not mandate.

**external_inputs.**

- Exact request/selection; mandate or common values only for claims that require them.

**unresolved_research.**

## R18-D08-Q04. Остановка поиска без ложного вывода об отсутствии меры

Если найденные кандидаты не отвечают decision need, но пространство не исчерпано, какое основание позволяет завершить текущее сравнение, а какое требует оставить его incomplete/limited с next action? Как отличить честное воздержание в текущей области от вывода, что полезного механизма нет?

**Выбранное решение.**

A method may stop under its progress rule or actual cap, including an approved candidate budget; this is only a method terminal. A scoped comparison completes only when admissible support answers its need and required routes are resolved. Exhaustion requires a finite versioned set and complete evaluated denominator. Otherwise preserve a limited frontier, omissions and next action. Budget completion does not require principal input for each compute choice and never proves no useful mechanism exists.

**mechanism_ids.**

- S08-M4

- S08-M3

**specific_steps.**

- Keep method terminal, decision result and branch coverage separate in existing artifacts.

- Use DES-10 known-solvable positive controls to reject all-abstain capability; retain honest no-op for constrained/no-known-alternative cases.

- At cap/profile completion, preserve partial candidates, unvisited branches, budget receipt and next action; do not infer exhaustion or solicit a policy preference for internal compute.

- Rebind N6 terminal call sites to actual untried-route/coverage facts before FRONTIER_STABLE or abstention is read as complete.

**authority_time_status.**

Terminal binds run/frame/basis/time/rule and real resource outcome; it reports this invocation only.

**external_inputs.**

- Need/no-op basis or authorized threshold only if required; candidate profile/budget if used; provider rights only for dependent routes.

**unresolved_research.**

Stopping thresholds are case/method-specific; test them on frozen cases and claim only that protocol, not universal exhaustion.

**Изменения существующих задач и различающие проверки.**

- **role**: primary writer
- **delta**: Bind terminal to untried routes, denominator, profile/budget and next action.

- **adversarial**: Hide route under stable/abstention or label cap exhaustive.
- **removal**: Drop route/profile facts; completion projection fails.

- **task_id**: DES-10
- **role**: assurance
- **delta**: Keep positive controls distinct from constrained/no-alternative cases.
- **positive**: Solvable case gives support; constrained case may no-op.
- **adversarial**: All-abstain passes safety but fails positive control.

- **task_id**: DES-11
- **role**: consumer

## R18-D08-Q05. Зависимость frontier от порядка и истории поиска
