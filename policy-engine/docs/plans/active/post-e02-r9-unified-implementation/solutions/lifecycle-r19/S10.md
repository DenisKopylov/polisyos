### S10-M1. Область наблюдаемости и method-qualified sensitivity для O2/O1

**native_owner.**

GYD-10: DDM `OnlineFDRController` + sole `HypothesisLedger`; GYD-09: existing Scientist feedback/activation consumer. LIF-02 owns source currentness; DES-11/12 own exposure/study. No parallel monitor, ledger, coverage index or updater.

**reuse_anchors.**

- **path**: policy-engine/src/polisyos/ddm/calibration/multiple_testing.py
- **symbol**: OnlineFDRController.test; OnlineFDRDecision
- **observation**: Static: consumes test_id/p_value and tracks alpha wealth/tests/discoveries; does not prove denominator, input validity, coverage or sensitivity. Not runtime proof.

- **path**: policy-engine/src/polisyos/runtime/quality/hypothesis_ledger.py
- **symbol**: HypothesisLedgerEntry
- **observation**: Static: candidate_unverified, authority envelope, targets, content/provenance exist; entry does not verify coverage assertion. Not runtime proof.

- **path**: policy-engine/src/polisyos/scientist/feedback/core.py
- **symbol**: DecisionFeedbackService.evaluate_packet
- **observation**: Static: actuals plus min-observation/confirm/refute ranges; insufficient actuals are explicit. Monitoring/reissue anchor, not exploratory detector or posterior authority. Not runtime proof.

**decision.**

Quiet = отсутствие discovery только в фактически проверенной family/stream/window/source cut. Bind target, measurement/channel, exposure/regime, enrolled cut, denominator/look/selection и missing outcomes; LIF-02 owns source coverage, S10 adds sensitivity beyond R17. Для O2 назвать alternatives/effect sizes, sample/window и assumptions; sensitivity/delay ограничены ими. FDR-controlled допускается, только если fresh reader потребил GYD-10 accepted-plan checks: valid p/e без неучтенного outcome-adaptive выбора, family/dependence, полный denominator/look/selection history, wealth/state continuity through restart/replay. Без witness остается scoped diagnostic/candidate без guarantee/promotion; FDR не bound false negatives. При неизвестном MNAR — bounds/limitation. O2 routes to DES-04/12; O1 requires qualified evidence and GYD-09 activation.

**alternatives.**

- **option**: No alert значит no harm.
- **tradeoff**: Отвергнуть: heartbeat/FDR не покрывают скрытые outcomes или ненаблюдаемый мир (P37/P38).

- **option**: Один detector/sensitivity threshold для всех outcomes.
- **tradeoff**: Отвергнуть: target, dependence, channel и delay различаются; выбирать профиль либо state not_established.

- **option**: Второй глобальный монитор/полный список переменных.
- **tradeoff**: Отвергнуть без новой семантики: дублирует DDM/LIF/DES и не закрывает unknown unknowns.

**contract.**

Bind target/proposition, exposure/regime, measurement/channel, source partition/cut, window, actual denominator/look/selection/stopping, gaps/missingness, method/rule/schema version + assumptions; for any FDR status bind accepted plan, actual p/e construction/selection, family/dependence, full look history and controller state/replay/restart continuity, with fresh-consumer validity discrimination; result/uncertainty, purpose/authority, provenance, observed/as-known time, audience. Evidence is resolved/content-bound, not label-asserted. Reuse existing O2 candidate/may_not_use_for and O1 activation; no new enum.

**flow.**

- GYD-10 checks its accepted plan and p/e, dependence, look/selection and state continuity; LIF-02/CAP supply enrolled cuts; DES-11 supplies exposure/regime.

- Persist test/look/spend/profile/gaps and validity witnesses as one HypothesisLedger candidate; missing validity permits diagnostics only, not FDR guarantee/promotion.

- DES-04 changes search; DES-12 proposes a discriminating study; fresh claim reader carries the scoped limitation.

- Only qualified, activated GYD-09 O1 evidence can change the scoped estimate; existing API/dossier shows tested scope and gaps.

**migration.**

Legacy no-alert is not retroactive sensitivity evidence. Recompute only from retained stream/denominator/measurement/method; otherwise preserve as-known limitation. Later events create new cut/currentness reaction via LIF-02/07.

**free_grow.**

Data within existing protocols needs no domain list. New detector in-class brings its own validity/denominator/sensitivity witnesses; new inference semantics need typed owner extension and consumer proof.

**resource_behavior.**

Bound windows; retain cut/look/gaps/processed denominator. Resource exhaustion or channel loss yields existing partial/insufficient/limited state. Test sensitivity only on a small decision-relevant alternative set.

### S10-M2. Семантически квалифицированное отрицательное знание и условный перенос между контекстами

**native_owner.**

DES-08 LessonRegistry/balanced retrieval stores and applies memory; DES-04 drives next choice; DES-10 assures usefulness; LIF-07 owns influence/retraction; GYD-09/10 are authority consumers. No second memory store or lineage graph.

**reuse_anchors.**

- **path**: policy-engine/src/polisyos/scientist/methods/search/lessons.py
- **symbol**: LessonCard; LessonRegistry.record_local/retrieve
- **observation**: Static: failure/success/opportunity, trust/context/provenance/trace/transfer fields and CAS index exist; facets do not prove causal transport. Not runtime proof.

- **path**: policy-engine/src/polisyos/ir/artifacts/lineage.py
- **symbol**: ArtifactLineageGraph.derived_from/consumed_by/invalidated_by
- **observation**: Static: records artifact relationships/invalidation; topology cannot prove independence, method correctness or transportability. Not runtime proof.

**decision.**

Различать search-performance hint; method/applicability warning; implementation warning; substantive empirical negative. Method warning transfers on bound method/version and verified named applicability preconditions, despite irrelevant profile differences; implementation warning also binds relevant build/runtime conditions. Empirical negative binds scoped estimand/target/support/time/regime, valid design, actual exposure/measurement/selection, method and uncertainty. Transfer requires identifiable source-target relation (e.g. selection diagram/formula + needed measurements; invariant prediction only under its assumptions). Otherwise keep local outcome/search hint; DES-12 can design a study. Operational/unobserved/unexecuted and underpowered/null states are not causal prohibitions. Preserve successes/opportunities; LIF-07 owns correction, GYD-09 authority.

**alternatives.**

- **option**: Любой failure/null запрещает похожие cases.
- **tradeoff**: Отвергнуть: domain/fingerprint сходство не доказывает общий mechanism, support, measurement или assumptions.

- **option**: Разрешить только exact same case; обнулить transfer.
- **tradeoff**: Сохранить для authority, но не запрещать низкоавторитетный DES-08 search hint.

- **option**: LLM summary/repetition/lineage доказывают перенос или independence.
- **tradeoff**: Отвергнуть: descendants не независимы (P14/P15); граф не доказывает causal transport.

**contract.**

Bind exact run/evaluated status, outcome, method/version/assumptions, source/target, mechanism/intervention/estimand/support, exposure/selection/stopping, measurement, uncertainty/power, dependence parents, right/purpose/audience, provenance and knowledge cut. Distinguish hint, formal applicability warning, implementation-specific warning and empirical result by content. A method warning binds the implicated method/version and named precondition evidence, not irrelevant task/profile identity; an implementation warning also binds relevant build/runtime conditions. Unknown relevant conditions keep it a lower-authority hint. Causal transfer binds selection/invariance premise, needed target/source observations and method/formula; reuse exact influence refs. No generic enum/taxonomy.

**flow.**

- DES-04/08 records evaluated outcomes and explicit not-run/opportunity; LIF-07 binds parents, selection, rights and correction.

- Existing LessonRegistry persists memory; card alone is a hint until evidence consumer resolves stronger grounds.

- DES-08 alters later candidate/study within scope; DES-10 compares memory/no-memory and false exclusions.

- GYD-09 rejects memory as posterior update; GYD-10 keeps descendant discoveries exploratory; fresh readers resolve source/transport rationale.

**migration.**

Legacy cards missing method/version or relevant-precondition evidence remain local hints; do not require irrelevant profile identity when the method/version and verified applicability condition are bound. Never infer transport from similar domain strings. Re-evaluate from source if possible; corrections follow exact LIF-07 lineage and do not restore stale authority.

**free_grow.**

Add outcomes/context inside current LessonRegistry classes. New transport class needs reviewed typed method, assumptions and consumer witness; no new store/facet catalog.

**resource_behavior.**

Use bounded/context-filtered balanced retrieval; never count paraphrase/descendants as independent outcomes. If exact basis/right unavailable, keep lower-scope search hint and do not block unrelated candidates.

## R18-D10-Q01. Граница видимости мониторинга

Какую область наблюдения и чувствительность вправе заявить exploratory monitor, если переменные, измерительные каналы и выборки ограничены известной схемой, а политика или сам процесс PolicyOS может изменить регистрацию, отчетность, состав наблюдаемой группы или доступность исхода? Какой статус получает «тихий» монитор, когда целевой вред перестал быть наблюдаемым, и как эта граница доходит до текущего вывода?

**Выбранное решение.**

Чувствительность утверждается только для доказанной области/profile; quiet = нет discovery в охваченном test family/stream/cut, не отсутствие вреда. FDR-controlled требует, чтобы fresh reader потребил GYD-10 accepted-plan validity evidence; иначе O2 остается полезным scoped diagnostic/candidate без гарантии или promotion. FDR не bounds false negatives. Sensitivity ограничена заявленными alternatives/window/delay. Изменение eligibility/reporting меняет наблюдаемость; без модели пропусков вывод limited/insufficient/not_established.

**mechanism_ids.**

- S10-M1

**specific_steps.**

- Resolve actual source/event, measurement, DES-11 target/exposure/regime, channel, partitions/cut and missing outcomes; separate source completeness from detector sensitivity.

- Выбрать O2 alternatives/effect sizes, sample/window и assumptions; оценивать power/delay только для них. Для FDR отдельно потребить GYD-10 checks: валидные p/e и selection, family/dependence, полный denominator/look history, непрерывное wealth/state при restart/replay. Без любого witness — diagnostic/candidate, не гарантия/promotion; unknown MNAR — bounds или limitation.

- For policy-induced channel changes, reconcile actual eligibility/receipt/reporting; DES-12 proposes a feasible discriminator when useful.

- Fresh reader states `no discovery within scope`; O2 remains candidate, O1 needs qualified design/evidence and actual activation.

**authority_time_status.**

O2 quiet scoped to bound method/family/look/window/source/measurement cut; gaps use existing limited/insufficient. O1 requires qualified evidence and actual activation.

**external_inputs.**

- Actual outcome labels, eligibility/reporting, source receipts and rollout facts come from custodians; PolicyOS admits/reconciles, not invents.

- An external study needs protocol-specific permission, conduct and returned evidence; synthetic scenarios witness mechanism only.

**unresolved_research.**

No finite monitor establishes sensitivity to an open-ended universe of unregistered variables/mechanisms from its own stream. Select a decision-relevant alternative set and method-specific analysis; unresolved cases remain limitations. No universal threshold.

**Изменения существующих задач и различающие проверки.**

- **task_id**: GYD-10
- **role**: primary writer
- **delta**: Связать O2 с фактическим denominator/look и потребить accepted-plan validity checks (p/e, dependence, selection и state continuity) до FDR-controlled label.
- **positive**: При bound validity witnesses discovery остается scoped candidate; без них diagnostic полезен, но без FDR label.
- **adversarial**: Оставить denominator/look markers, но адаптивно выбрать p-values, скрыть look либо сбросить wealth при restart: fresh reader снимает гарантию; source silence не no-harm.
- **removal**: Удалить один validity/state witness при сохранении FDR label: гарантия исчезает; удалить denominator/regime — исчезает scoped quiet.

- **task_id**: GYD-09
- **role**: consumer / authority firewall
- **delta**: Для cited FDR status потребить GYD-10 procedure/state witnesses; отдельно сохранить qualified O1 evidence и activation.
- **positive**: O2 остается candidate; estimate меняется лишь после qualified O1 activation.
- **adversarial**: Reset/invalid p-value не дает FDR warrant; missing labels/exposure shift не prediction_error.
- **removal**: Удалить validity или activation binding — fresh consumer отклоняет соответствующую гарантию/estimate.

- **task_id**: LIF-02
- **role**: input owner; consume R17
- **delta**: Consume enrolled cuts only; do not redo source currentness.
- **positive**: New enrolled event invalidates affected basis.
- **adversarial**: Heartbeat with stalled labels is not no-change.
- **removal**: Remove cut/replay; missed event reaches fresh reader.

- **task_id**: DES-11
- **role**: exposure/regime input
- **delta**: Bind actual receipt, target and observation regime.
- **positive**: Partial rollout/reporting change limits correct subgroup comparison.
- **adversarial**: Same version hides changed receipt/reporting.
- **removal**: Remove actual history; independent exposure oracle catches error.

- **task_id**: DES-12
- **role**: study-design consumer
- **delta**: Propose study distinguishing harm from reporting shift.
- **positive**: Blind spot yields target-aligned candidate/result path.
- **adversarial**: Study repeats missing channel or fabricates result.
- **removal**: Remove discrimination/result binding; oracle finds no resolution.

## R18-D10-Q02. Перенос отрицательного знания

При каких условиях outcome-backed неуспех или нулевой результат становится переносимым отрицательным знанием, которое ограничивает будущий candidate или применимость метода, а когда он остаётся лишь scoped memory о поисковой эффективности? Как меняют этот вывод различия в механизме, target, support, measurement и regime, если исходный сигнал также мог быть underpowered, пропущенным, implementation failure, недоступными данными, отказом в разрешении или budget exhaustion?

**Выбранное решение.**

Эмпирический null переносится лишь для scoped estimand при идентифицируемом source→target transport (например selection diagram/formula с target data; invariant prediction при своих assumptions); иначе остается local и search-useful. Formal applicability warning переносится через нерелевантные profile differences, если bound method/version и конкретная нарушенная precondition подтверждены; implementation warning дополнительно связывает релевантные build/runtime conditions. Неизвестные условия дают hint, не исключение. Not-run, operational failure, missingness и low power не causal prohibitions.

**mechanism_ids.**

- S10-M2

**specific_steps.**

- Resolve evaluated run/outcome; separate method/implementation failure, permission/data/budget/not-run, insufficient power/measurement and substantive result.

- Bind result to mechanism, estimand/support/target, exposure, measurement, selection/stopping, method/uncertainty and dependence; power/Type S-M needs explicit plausible effects.

- Search-performance remains a hint. Transfer method warning on bound method/version + verified relevant applicability preconditions (and relevant build/runtime conditions for implementation defects); unrelated profile differences may vary. Empirical negatives stay local absent identified transport and target support.

- Otherwise keep local memory and alternatives; DES-12 studies unresolved decision-relevant rival. Retraction updates influenced uses through LIF-07.

**authority_time_status.**

Memory labels never raise authority. Method warning follows bound version and verified relevant preconditions; empirical negative needs transport, target data and GYD-09 activation. Retractions affect current uses; preserve as-known history.

**external_inputs.**

- Executed outcomes, source/target measures, exposure/selection and reuse rights come from actual owners; memory cannot manufacture them.

- Causal graph/selection assumptions need claim-specific judgment. Without defensible transport/invariance, keep result local and search-useful.

**unresolved_research.**

No universal criterion transports negative mechanism knowledge across domains. Choose method per causal structure; source-only null cannot settle unmeasured target mechanisms. Preserve the local result and route a distinguishing study without blocking unrelated candidates.

**Изменения существующих задач и различающие проверки.**

- **task_id**: DES-08
- **role**: primary writer
- **delta**: Bind method warning to implicated version and verified named preconditions, not unrelated profile facets; keep empirical outcome separate from hint and transport.
- **positive**: A later choice avoids a method across irrelevant profile differences when same version/precondition establishes inapplicability; null remains local without transport.
- **adversarial**: Changed/unknown relevant version/precondition or low-power/operational failure cannot transfer as prohibition; similar profiles do not transport null.
- **removal**: Remove version/precondition resolution and invalid method is retried; remove transport check and empirical exclusion reverts to local hint.

- **task_id**: DES-04
- **role**: next-choice bridge
- **delta**: Ensure a scoped method warning can change a later choice without becoming a transported causal finding.
- **positive**: Same method/version and violated precondition changes next choice despite irrelevant profile differences.
- **adversarial**: Operational failure, version/precondition mismatch or untransported null cannot blacklist a candidate.
- **removal**: Remove retrieval bridge and next choice loses memory effect; remove transport witness and causal exclusion becomes local hint.

- **task_id**: DES-10
- **role**: assurance
- **delta**: Compare memory on/off for relevant-precondition matches/mismatches, irrelevant profile changes and empirical-negative transfer/non-transfer.
- **positive**: Scoped warning reduces invalid-method repeats without false exclusions; transported null helps only with target support.
- **adversarial**: Stale version, unknown precondition, holdout leakage, descendants or false exclusion; measure both repeats and exclusions.
- **removal**: Remove retrieval/evidence/version/precondition/transport binding and corresponding usefulness/false-exclusion oracle fails.

- **task_id**: DES-12
- **role**: study-design consumer
- **delta**: Design feasible discriminator for decision-relevant transport rival.
- **positive**: Returned evidence changes only supported scope.
- **adversarial**: Study repeats bias or fabricates permission/result.
- **removal**: Remove result bridge; no transport question resolves.

- **task_id**: LIF-07
- **role**: influence/current-use owner
- **delta**: Reuse exact parents, selection, rights and correction path.
- **positive**: Correction changes affected current use and preserves history.
- **adversarial**: Missing parent/right or descendants masquerade as basis.
- **removal**: Remove live influence check; stale lesson affects reader.

- **task_id**: GYD-09
- **role**: authority consumer
- **delta**: Reject untransported memory as O1 update; retain activation.
- **positive**: Qualified independent target result updates only after activation.
- **adversarial**: Shared cohort/local null relabeled confirmation.
- **removal**: Remove method/activation binding; consumer refuses.

- **task_id**: GYD-10
- **role**: candidate firewall
- **delta**: Memory can prioritize study, not promote or erase looks.
- **positive**: Hint proposes target-specific study with denominator.
- **adversarial**: Descendants count independent or O2 self-confirms.
- **removal**: Remove candidate wall; authority reader rejects.

## self_attack

- **case**: Complete/quiet marker remains while policy hides an adverse subgroup or stops a label channel before source emission.
- **repair_or_bounded_limit**: Falsify contents with actual enrollment/cut and independent eligibility/receipt evidence; remove channel with markers intact and limit current claim. Without witness, unregistered mechanism is unknowable.

- **case**: A low-power source null transfers to a same-domain target with changed mechanism/support/measurement, suppressing a valid candidate.
- **repair_or_bounded_limit**: Separate heuristic ranking from causal exclusion; require exact preconditions or identified transport/invariance plus target data; preserve DES-12 discriminator.

- **case**: One model reflection is copied into lesson descendants and counted as independent evidence.
- **repair_or_bounded_limit**: Bind model/training/selection lineage and GYD look dependence; descendants may inform search but add no empirical independence.

## limits

- Shared rule: bind actual evidence, method/rule/schema, provenance, purpose/audience and observation/knowledge cut. O2 stays candidate_unverified/may_not_use_for authority; O1 mutates only after GYD-09 qualified evidence and actual WP-01/WP-02 activation. Later evidence creates a new current basis; preserve as-known history.

- Pre-E02 planning only; verification is UNRUN. Source anchors are static, not proof of producer→artifact→bridge→consumer→surface capability.

- S10 consumes R17 source/replay/currentness/exposure and LIF-07 influence/retraction; it does not duplicate archive, capture, rights or lineage.

- No universal sensitivity threshold, missingness assumption, transport rule or negative-knowledge enum. Choose a method per claim; unsupported transfer stays useful local/search memory.

- Pattern pass: P11 preserve success/opportunity; P14/P15 prevent dependent/model descendants inflating evidence; P24 keep policy shifts investigable; P29/P32 require substantive evidence; P37/P38 test grounded observability/transport properties, not labels.
