# Causal source formatting and test declarations

This forward correction normalizes nine F-owned files with the repository's
Ruff formatter. All production modules keep their full executable AST, literal
values and docstrings. The import block in the CausalEngine test only gains its
required separation. One pytest declaration uses an explicit two-name tuple
instead of its equivalent comma-separated parameter-name string; the names,
order and cases stay the same.

The immutable before/after byte bindings and AST comparisons belong to the
source-quality receipt. Formatting changes source hashes, so the canonical
public inventory must be rendered again before an installed consumer replay.
An archive built before that correction remains evidence for its own SHA.

The complete 92-path quality run retains its original lint/format failures.
Three other formatting targets belong to the A/G runtime scope and are left
with their exact failure outputs. This correction does not claim inherited-red
attribution under P41, a global green check, numerical method changes or causal
authority. Existing DiD/RDD numerical proofs remain bound to their own sources.
