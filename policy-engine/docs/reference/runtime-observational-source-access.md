# Observational candidate source access

Owner: Runtime HTTP and Core artifact owners.
Source of truth: `src/polisyos/runtime/http/services/control/observational_source_access.py`, `src/polisyos/runtime/http/services/control/run_lifecycle.py`, and the observational source-access tests under `tests/unit/runtime/http/`.

An ordinary observational run may consume a public-classified tenant-bound source only when Runtime's expected owner matches the effective owner of its enforcing Core filesystem CAS. The expected owner comes from the typed request principal reconciled with execution policy, the current lease-fenced ControlPlane job admission, or the already-authorized fresh-reader scope. A configured `for_tenant(A)` handle cannot stand in for request/job B. Disabled ownership enforcement and unsupported owner carriers fail closed for this path.

The in-process source-read scope is not a persisted grant. Runtime checks it before selected reads, after live job admission, before content-admitted persistence and again at fresh selection readers. The original configured read handle remains in use, including dependency guards; adapter inspection does not bypass guarded IO. Core continues to check current blob-reader and exact selected manifest-view ownership and content integrity. Selected ArtifactRef subclasses retain their selected profile. Runtime builds its default store using the existing ambient-enforcement adapter; explicitly injected unsafe stores are refused rather than silently repaired.

Restricted outer classifications remain unsupported by this candidate profile; PII suitability is not established by byte ownership. Public unscoped legacy work retains its limited behavior under a matching enforcing owner or genuinely unclaimed Core read. An ambient legacy tenant context is insufficient to admit tenant-bound source metadata. Source tenant context is provenance. A genuine shared read grant from source A to job B does not make A the writer: Runtime derives new resource-policy, requested/admitted intent, materialization, selected-row scope, result and evidence headers from B’s actual admitted scope. Exact source refs and source-origin A remain in payload provenance and lineage. Worker-local admission/preparation DTOs carry this typed derived context; existing direct producers preserve their default behavior when the optional preparation context is absent.

Persisted requested/admitted intent, selection, result, digest and serializer shapes are unchanged; historical unscoped headers remain readable with their existing limitations. `source_access_revalidation_status` remains `not_established`. Successful owned-byte access does not establish external institutional permission, online IAM revocation, production-world currentness, purpose completeness, calibration, legal adequacy or publication authority. C38 protected TC authority and cache-promotion refusals remain effective.

Regression tests use actual HTTP authorization, Core CAS and durable ControlPlane admission. A controlled signed ownership-generation fixture tests current owner-policy withdrawal; it is not a production institutional revocation API. The ordinary native HTE first-assessment test retains all seven source modes and its original source/request/row/unit/native-output/fresh-consumer assertions. Native execution, removal controls and composed compatibility acceptance must be measured separately from source review.
