Related reference: [Scientist](index.md).

> Repo-tracked Gate 0 matrix for `SCIENTIST_AUDIT_REMEDIATION_PLAN.md`.
> This page is intentionally conservative: workstreams stay open until their own
> exit criteria are backed by code, regression tests, docs, observable evidence,
> and CI gates.

## Policy

- A workstream is not considered done because some code landed.
- Partial implementations are reopened when the documented exit gate is not yet evidenced.
- The machine-readable source of truth lives in `polisyos.scientist.remediation_status`.
- This page is a human-readable view of the same strict closure posture.
