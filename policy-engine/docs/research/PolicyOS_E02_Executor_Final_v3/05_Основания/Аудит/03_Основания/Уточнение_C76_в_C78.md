# Уточнение C76 в текущем выпуске C78

В запечатанном `C76_CAS03/run04/signature_selected_ranges.json` причина исключения generic `_run_in_context[T]` сформулирована неверно: «PEP695 generic not parsed on Python3.12». Python 3.12 поддерживает этот синтаксис. В C76 функция была исключена выбором внешнего extraction harness; её заменял явно раскрытый one-line `context.run` trampoline. Это не особенность product parser и не основание считать PEP695 несовместимым с текущим runtime.

Прежние файлы C76 оставлены неизменными. Текущее дополнение заново исполнило целый actual `_signature_ops.py` (489 строк), включая исходный generic trampoline, с прежними явными fixture owner/index/CAS seams. Результат: exit 0, 7 MATCH, 23 неизменённых cases PASS. Это новые данные C78, не задним числом новый native результат C76. Main store по-прежнему блокирован отдельным Python 3.14 `except` syntax в текущем Python 3.12; полный native custody/batch/pytest не объявлен проверенным.

Скрипт, command/exit/logs, source identities и результаты: `04_Проверки/C78_CAN01/C76_уточнение/`. Эти 23 cases не прибавляются к 127 CAN cases. Подтверждённые C76 bounded residuals и ограничения прежнего отчёта не отменяются.
