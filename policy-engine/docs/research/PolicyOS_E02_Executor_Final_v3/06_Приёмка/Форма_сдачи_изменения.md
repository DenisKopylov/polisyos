# Свидетельство сдачи изменения

Эта форма заполняется после реализации; сейчас результаты не установлены.

1. Packet/lane и покрытые REQ/общие сценарии
2. Base/head SHA и фактически изменённые owners
3. Воспроизведение исходного расхождения: входы, observed/expected, уровень проверки
4. Техническое изменение и почему оно решает причину, а не только пример
5. Положительные, негативные, граничные и метаморфные результаты: exact commands, runtime/backend, exit, logs, numerical oracle/tolerance
6. Реальный producer→handoff/persistence→fresh consumer и отдельно перечисленные doubles
7. Preservation: исторические bytes, public contracts, error semantics, полезные partial paths, LK
8. Общие consumers/интеграция: какие свидетельства переиспользованы, почему inputs/profile не изменились
9. Неисполненные/заблокированные проверки, оставшиеся решения, научные/внешние ограничения
10. Reviewer decision по каждому REQ: accepted / changes required / blocked with exact cause. Не заменять этим документом существующий runtime registry

Источник ошибки среды не объявлять дефектом продукта без доказательства. Исправление не повышает полномочия, качество данных или независимость экспериментов автоматически.
