Bounded сохраняет реальные профили/DEC, не означает выполненную квалификацию. Отсутствие unresolved в этой классификации не означает, что у будущей реализации закрыты все решения.

Продукт и исходная v2 не изменены. Product/native tests NOT_RUN. Это отдельное дополнение-аудит, не новый полный нормативный v3. Точечные тексты предлагаются для синхронного включения в следующую редакцию, поэтому baseline намеренно сохраняет найденные формулировки.

Для проверки структуры и идентичности исходных входов: python validate_audit_coverage.py. Этот скрипт не импортирует продукт и не доказывает истинность инженерных выводов. SHA256SUMS.json и архивная проверка подтверждают целостность файлов выпуска.

Остальные .py сохранены как история сборки исследовательских материалов, а не как инструкции исполнителю продукта. Не запускать их для «обновления» принятого выпуска: отдельные правки после QA могли быть внесены непосредственно в результаты. Для проверки текущего снимка использовать checksum manifest и validate_audit_coverage.py.
