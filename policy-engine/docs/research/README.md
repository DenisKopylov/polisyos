# Research Notes

This directory contains research inputs that inform PolicyOS architecture and
implementation plans. Research notes are not runtime authority by themselves;
they must be translated into governed contracts, manifests, validators, or ADRs
before code can rely on them.

- [E02 documentation snapshot](../reference/e02-documentation-snapshot.md) separates
  the historical cloud-test baseline, numbered integration checkpoint, and later
  Source41 author-candidate evidence. It also maps the current owner receipts,
  unresolved integration mechanisms, and the evidence that still needs recensus.

  package. Start with its transferred results and limitations (`policy-engine/docs/research/e02-cloud-test-plan/results/README.md@sha256:2f91e5a04610ef877dce4ed9121a045aefac01540662a85c12c340a5ed32b8e7`),
  owner routing (`policy-engine/docs/research/e02-cloud-test-plan/execution-organization/README.md@sha256:ab45ac1dc98969df9149e56e7afd19843c777854a7bff4bacb4bcc2e37f1933e`), and
  integration record (`policy-engine/docs/research/e02-cloud-test-plan/integration/README.md@sha256:9cb5cfb8d5b238126a759dce39a63ca0c9340db64be2359256fc83a7d558666c`); use the snapshot
  before treating any older status statement as current.
