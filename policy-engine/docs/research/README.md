# Research Notes

This directory contains research inputs that inform PolicyOS architecture and
implementation plans. Research notes are not runtime authority by themselves;
they must be translated into governed contracts, manifests, validators, or ADRs
before code can rely on them.

- [Parallel Deep Research Backlog](remaining-deep-research-backlog.md) collects
  the not-yet-researched Cross-Cutting Public Authority, Scientist, Fabric, and
  Foundry Phase 6+ tasks as standalone prompts for a fully parallel
  deep-research batch.
