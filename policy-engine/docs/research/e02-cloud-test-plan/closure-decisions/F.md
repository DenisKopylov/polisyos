## Method correctness (property vs proxy)

**DiD standard B204–206.** Zero-pre requirement belongs in standard estimator, not common panel input. Returning passed when t0<3 is a proxy gate: no test was possible. A non-significant pretrend p does not prove parallel trends. HC1/CR0 matching is covariance algebra only, not finite-cluster coverage. Store effective procedure, cluster count and limitation.

**Staggered B207–209.** Keep the current safe refusal until one declared profile is implemented. The selected scalar target is the Callaway–Sant’Anna overall-participation ATT: θ=Σ_g q_g τ̄_g, where q_g=P(G=g|ever-treated), τ̄_g=K_g⁻¹Σ_{t∈E_g}ATT(g,t), and E_g/K_g are frozen eligible cells/horizon under declared controls and anticipation. This averages within cohort over post periods, then weights cohorts by estimated ever-treated share; it avoids the current per-cell n_g normalization that gives long-treated cohorts extra weight. Include both ATT-cell influence and q_g ratio-share influence. Use one iid Mammen mean-zero/unit-variance multiplier per panel unit, shared over every cohort-time cell; studentize the centered scalar aggregate Z_b=√n(θ*_b−θ̂)/σ̂. The two-sided H0 test compares |√n(θ̂−θ₀)/σ̂| to the centered |Z_b| law; invert the same test for a pointwise scalar 95% interval. If target cells lose support, report/refuse the exact subset target rather than silently dropping or renormalizing cells. Null/alternative simulations need binomial Monte Carlo bounds, unbalanced cohorts and shared controls. This is an iid/large-independent-unit asymptotic profile, not finite-small-cluster inference; simultaneous bands require a separately specified max-statistic profile.
