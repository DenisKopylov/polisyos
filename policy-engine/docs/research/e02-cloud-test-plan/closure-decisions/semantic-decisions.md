## Separate A B31 boundary from E B201/B202 decisions

**A B31 source criterion.** Preserve identification bounds separately from native statistical/model uncertainty for the same estimand and unit. A zero-width identification set does not establish zero total uncertainty; do not invent proxy width or force a point estimate into the interval. First check whether the existing versioned `UncertaintyEnvelope`/`DistributionCarrier` and typed ref carry both channels with estimand/unit/provenance. Reuse that carrier if adequate. B31 does not require new point/quantile semantics, joint-law storage, a new schema/API, or the E B201/B202 decisions. If the existing carrier cannot express the source property, define only the smallest necessary contract change with the already responsible semantic owner. Keep B31 held until the source-specific meaning and consumer property are tested.

**E B202 storage recommendation, separate from B31.** Use one persistence boundary for a new uncertainty output only if the E-owned B202 contract requires a new law-bearing representation: existing `persist_uncertainty_envelope` / `load_uncertainty_envelope` in `ir/analytics/uncertainty.py`, returning/resolving the existing `UncertaintyEnvelopeRef`. `ValueEvidence` composes the identification carrier with this typed summary ref; when a new law-dependent computation or authority-bearing result needs the posterior law, the summary carries an `ArtifactRefModel` to the immutable typed law stored in the existing CAS. The proposed v2 implementation of these same helpers is the only envelope/law write-and-read path: the writer externalizes the input carrier through the existing artifact-store CAS, and the loader resolves and content-binds the typed ref. Preserve named axes, shared ordered draw identity across coordinates, weights, and source/calibration lineage; marginals with equal values but different pairings must remain distinguishable. **Proposed B202 default, pending owner ratification:** new v2 joint-law outputs are CAS-only rather than embedded draws. Existing inline `PosteriorSamplesCarrier` remains supported as a compatibility/v1.1 representation and producer input. A display-only summary may omit the law ref, but must remain explicitly non-compositional; before law-dependent computation, resolve, content-bind, and verify the CAS law ref or refuse that computation—never fall back silently to summary moments.

**E B201/B202 wire decision only for an actual contract change.** If the E-owned functional/storage choices change wire meaning, make that change a **new 2.0 wire schema with a distinct `$id`**, proposed `urn:policyos:ir:uncertainty-envelope:2`. Keep the v1.1 reader and replay meaning unchanged; do not issue new semantics under its version or `$id`, and do not rewrite historical artifacts. New writers emit v2 only after the semantic owner ratifies it; legacy reads remain v1.1. Until then, unsupported mixtures stay candidate/limited and cannot pass a law-dependent or authority gate; this held E wire choice does not block B31 when the existing carrier preserves its separate-channel property.

**Ownership route.** A owns B31 composition against the existing carrier and verifies same-estimand/unit separation; it does not author a new schema if the current contract suffices. E owns B201/B202 functionals, joint-law writer and calibration adapter. C and F consume admitted versioned refs as their contracts require. Appoint the canonical IR semantic owner only for a genuinely changed shared contract; G/A/E/C/F do not imply that authority. No new signing or approval workflow is introduced.
