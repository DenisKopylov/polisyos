## Основные функциональные решения

1. **Served N4→N5→N8.** Доведи ordinary HTTP POST через admitted profile/context после `DesignProblem`, typed N5 request, numeric CAS persist, fresh-process content-bound readback, реальный N8 `K_sim` conditional consumer и ordinary GET. Свяжи candidate/atoms, один EngineDecision, receipt/trajectory, WMR, method/objective, run/job/tenant, profile и hashes. Проверь fallback `atom` без N8 `intervention_atoms`, CAS-less sibling с произвольным digest, foreign/tampered refs, denied rights и unknown outcome. Conditional simulation value не является causal assignment, held-out calibration, N9 currentness или publication authority. Для B05 вызови реальный N9 gate; ранний `not_promoted` без вызова его не доказывает. Старый 32-PASS list-candidate receipt не закрывает обычный route.
2. **Basis, acquisition и сохранение истории.** B09 требует узкую C/F owner ratification: версионированный `ObservationToWMRRule` связывает admitted source/profile, observation→slot, population/geography/denominator, measure/unit/transform, selected rows/coverage, quality, provenance и допустимый update. Разделяй valid/as-of time от transaction/ingestion time. Semantic hash строится из rule + admitted row content; UUID/order/time-only меняют occurrence metadata, не basis. Настоящее admitted изменение создаёт новую basis и повторный N5 для того же candidate, сохраняя старую occurrence для replay. Не выдумывай правило. LA-046/CYC acquisition проходит canonical compiler→rights/purpose/budget admission→N7 artifact/readback→новый WMR; explicit empty/`any_of` сохраняются, пустой или выдуманный scope не принимается.
3. **Выбор и симуляция.** Проверяй hard feasibility до VOI/top-k; canonical owner измеряет и списывает cost ровно раз. Полный registry и modality/value filtering идут до top-k; singleton требует digest/hidden-member negative, transform — typed producer. Simulation binds output/unit/time grid: zero валиден, missing нельзя подменять нулём/последним значением; конфликтующие atoms отказывают, совместимые unordered дают permutation-invariant result. Проверь 2-child recursion, partial/budget stop, статусы API и раздельность occurrence/history от N9 currentness. Cache invocation-local и включает semantic inputs. Отделяй `EvidenceStateRef` от baseline; `s/√n` допустимо только для независимых IID draws, QMC error — через независимые scrambles. Сохрани точный B25 regression; B26 oracle — `x1*x2*x3` с нулевыми pairwise terms.
4. **A/E predictive S10.** Перед causal terminal refusal подключи отдельную predictive ветвь через один существующий default `RealValueOwnerGateway`. Запрос использует C-admitted `DataSnapshotRef/profile`, явный disjoint train/holdout split и horizon, metric/unit/scope, поддержанный ETS FQN+params, report id, E typed `CalibrationRuleBinding`, model/policy refs, seed и точные manifest roles. E остаётся единственным forecast/calibration producer и CAS writer. A на тех же resolved bytes независимо reruns ETS только на train, повторно связывает predictions с реальными holdout outcomes, пересчитывает count/rate/threshold, scope/lineage и **шесть timezone-aware temporal roles**: data-valid, calibration-window start/end, policy-effective, prediction, observation. E receipt/hash/role/`credible` marker не доказывает verifier identity; trusted in-process A verifier задан production composition, а fresh GET выполняет readback/recompute заново. Верни отдельный `ForecastSupport`/`ForecastCalibrationRecord` с ограниченным predictive-only статусом и оставь `treatment_assignment_not_owner_derived` для causal/value. Изменённый holdout должен менять результат; forged content-valid false counts, leakage или чужой scope должны отказать. Без admitted series — limited/unavailable.
5. **Public IR и replay.** `ValueOuterSet` остаётся identification-only, статистическая/model uncertainty и point functional типизируются отдельно; 99 нулей + 1×100 дают mean=1 и 95% equal-tail interval `[0,0]`. B31 остаётся held до решения владельца по четырём ratifications; A не подписывает научную семантику. Сохраняй byte-exact v1.1 replay при новом versioned v2 identity. Для LA-033 сохраняй точную 20-symbol compatibility ABI и докажи настоящий Foundry execution/readback + wheel import; для LA-045 не удаляй active compiler/resolver в погоне за retired private names.
