## Выбранные решения и границы

- **CAL:** переиспользуй JAX autodiff и NumPy спектральную проверку. Hessian generic/Huber loss — curvature diagnostic, не inferential covariance. Не превращай saddle/flat/negative/singular/ill-conditioned направления в valid covariance клиппингом eigenvalues или float64 post-cast. Gaussian NLL `.5*((θ1−1)^2/4+(θ2−2)^2/9)` — независимый oracle: MLE `(1,2)`, Hessian `diag(1/4,1/9)`, inverse `diag(4,9)`, SE `(2,3)`. Учитывай точную objective/cache identity. CAL-05 `lax.map` — механизм, пока не batch-путь реального calibrator; сохраняй per-row state/time/key, включая независимые keys. `vmap(cond)` не эквивалентен. Для B197 доведи configured `CalibratorInputs` через реального producer, `CalibrationReport v2`, persist/readback и welfare consumer, проверяющий CAS kind/schema/payload; не смешивай Foundry `CalibrationReport` с `FunnelCalibrationReport`. B198 оставь закрытым.
- **BKT/PCL/DDM:** сохраняй requested/eligible/observed denominator, source/split/horizon и разные time roles. Пустые сравнения — `not_evaluated`; micro и macro — разные estimands. BKT-03: `[-.01,0,.01] → t=0, df=2, p=1`; `[.5,1.5,2.5] → t=2.59807621135, df=2, p≈.1216899343`; unavailable SciPy означает degraded inference, не «нет смещения». `p>α` не доказывает equivalence или Grade A neutrality: B172/B173 остаются partial без versioned trust-grade purpose/profile и, где требуется, owner-declared meaningful-bias margin и equivalence interval. Не выдумывай threshold/assumptions. Bootstrap допускает только определённый statistic; `__name__` не provenance. PCL сверяет receipt с persisted pairs; DDM проводит report/model/rule/time/invalidation refs через consumer, не смешивая pass, validity и signoff.
- **UQP/UQS:** отсутствующая dependency/covariance не означает независимость. Требуй проверенный product law либо content-bound совместные draws с точным порядком и row identity; иначе unknown/non-gating. Для `(a,b)=(g,g)`, `Var(g)=.0025`, `Var(a−b)=0`, тогда как independent marginals дают `.005`. Сохраняй singular covariance. Закрой float64→float32 range escape общим pre-draw механизмом: `[[1e40]]` либо представимо end-to-end, либо отклонено до любого callback (random/Sobol/Halton); последующий счёт finite draws запоздал. Отдельно сохраняй все draw outcomes: success-only среднее при `X~Uniform[-1,1]` и evaluator, неопределённом для `X<0`, условно равно примерно `.5`, не unconditional result.
- **MC/RQMC:** predictive spread не является ошибкой оценки среднего. Для ограниченного IID mean используй independent pilot и замороженный fixed `N`, pilot не включай в main estimate; этот сертификат не переносится на quantile/interval/CDF. При `Bernoulli(.001)`, `ε=.05`, `m=256`, `δpilot=δmain=.025`, `a=√(log(4/δpilot)/(2m))`, `U=min(1/4,max(0,q̄+a−max(0,x̄−a)^2))`, `N=ceil((2U+2ε/3)log(2/δmain)/ε²)`: all-zero pilot даёт `U≈.09956128`, `N=408`. Это требует одного IID `[0,1]` закона для независимых pilot/main; без него нет сертификата. Не делай optional stopping по fixed-N intervals. Для Sobol используй полные `2^m` точки на каждый independent scramble и estimator-specific ошибку по значениям реплик, не pooled output spread.
- **DoE:** используй SALib canonical sampler/analyzer; устрани дублирующий seedless/deprecated sensitivity bridge через существующий producer. Привязывай distribution, seed, scale/units, порядок/траекторию, denominator и analyzer. Morris валидирует целую trajectory. Sobol требует объявленный independent input law. B102 geometry — ограниченное доказательство геометрии, не provenance всего design/served consumer.
- **FRC:** E владеет `ForecastOwner`/ETS и `calibration.forecast_bridge` evidence writer/loader. A владеет `generation_cycle.py`, HTTP/run lifecycle, default gateway, S10 verifier и surface. Реализуй E producer на строгом admitted `ForecastOwnerRequest` (source, train/holdout/horizon, metric/method, report/rule, temporal roles, inputs, seed); сохраняй отдельные content-bound candidate receipt и empirical evidence через тот же configured CAS/store. Не пиши A paths, не добавляй второй API и не cast-уй `ForecastOwnerResult` в empirical evidence. CYC-01 A→FRC-01 и EMP-01 A→FRC-02 — declared dependencies. Hand off typed contract и exact refs A; проверяй его consumer после изменения upstream. Hash/role/schema и `credible=True` не доказывают verifier provenance. A должен resolve-нуть CAS, независимо пересчитать scope/split/pairs/counts/threshold/time/purpose и повторить проверку на fresh served read. Predictive sibling проходит до terminal causal refusal, не снимая её. Разрешённая цель — predictive calibration; causal/treatment/policy authority остаётся denied. Если default bridge ещё не подключён, называй `bridge_missing`/`consumer_missing` и владельца. Синтетики достаточно для математики; production history, если она строго нужна критерию, проверяется локально read-only на exact candidate, никогда не переносится в cloud.

B201/B202: держи point и interval functionals раздельно (`99×0+1×100`: mean `1`, q05/q95 `[0,0]`), сохраняй v1.1 replay; новую семантику помещай только в distinct v2 `$id`. Назначенный IR semantic owner должен выбрать CAS-only v2 (рекомендация) или inline carrier + persisted ref. Запиши четыре конечных решения из `semantic-decisions.md`; до ratification держи зависимые утверждения limited/held и не меняй wire contract молча.

## Параллельная работа и передача

Заполни до 20 **прямых** helper слотов независимыми owners, oracles, tests, consumer checks и review; helpers не создают детей и не пишут integration branch. Автор не рецензирует свой код; один writer на mechanism/schema. Cloud checks запускай без искусственных process/worker/CPU caps; сериализуй только shared mutable fixture/DB/cache/port. Используй repo-declared extras без ожидания human approval; backend unavailable = `UNRUN`/`SKIP`, не PASS.

Для каждого slice проверь реальный caller/consumer, независимый oracle, present-but-fake/property-removal negative и divergence старого proxy. Pattern pass: P01/P02, P05/P08/P09/P10/P14, P27/P29/P31–P33, P35–P38, P40/P41. Заморозь P37 basis; на втором escape класса примени P40. Код и closure решай отдельно. После implementation коммить handoff JSON в `implementation-handoffs/E/`: exact base/candidate/tree SHA, diff paths, commands/output/environment/input, property path/oracle/negative, predicate basis, capability state, limitations/owner. Push только E topics/PR для G; `main`, force-push, rebase и reset запрещены.

После independent reviews заморозь один E candidate и выполни общую дорогую wave один раз на этом SHA. Итог по всем 22 bundles: accepted commits; для каждого finding укажи сохранённый ledger status и отдельный verdict `closed | limited | held | open`. Не переклассифицируй исторический `partial` автоматически до решения владельца; `UNRUN/SKIP` — исход отдельной проверки, не finding verdict. Приведи deciding evidence, missing inputs/backends, remaining checks и конкретного следующего owner. Старая красная без exact P41 replay — `not_established`; отказ вместо требуемого метода, plan или большое число PASS не закрывают finding.
