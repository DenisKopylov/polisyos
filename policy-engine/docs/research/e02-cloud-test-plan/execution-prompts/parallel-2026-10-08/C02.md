## Работа и границы

Выбери с G exact compatible CAS owner blobs, сохрани complete ownership/manifest/input identity на store/import/view/transfer. Ты единственный writer Core artifacts facade и raw byte admission; CAN reader adapter — C06. Защищённый positive интегрируй с реальным существующим issuer/verifier, не caller bool или имя tenant.

Only named mirrored tests of own mechanism after actual file lease; existing shared tests stay with canonical mechanism owner; otherwise submit a patch. Test-start paths are discovery/check selectors, not blanket write leases.

## Проверяемое свойство

Свежий CAS reader на том же committed candidate; valid same-owner positive и fake/foreign/stale/revoked/mismatched inputs без эффектов, включая commit-time mutation. Подлинное разрешение tenant reuse B131 и revalidation B137 — отдельные фактические packets L01; без них generic guards завершить, positive честно UNRUN.
