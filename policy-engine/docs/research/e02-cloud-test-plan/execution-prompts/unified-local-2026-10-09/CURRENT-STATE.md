Остановки относятся к разным классам. Executor `offline/failed`, exit 137/-9 или потерянный capture без измерения причины — **ERROR/incomplete**, не доказанный runtime defect. Отказ native hook — отдельный publication gate. Невыполненный numerical backend — SKIP/UNRUN. Необходимость совместить два существующих producer/consumer API — исполнимая инженерная работа нового root. Наконец, чужая law/issuer/release/currentness — проверяемый внешний факт, который нельзя создать самодекларацией.

У C05 «14 отсутствующих suppliers» не означает потерю 14 файлов: 13 существуют с различными G/C05 blobs, один `_resources.py` есть только в G. Это source selection и compatibility, а не основание вновь просить каждого прежнего автора прислать файл. У C12 существующие producer symbols надо выбрать из точного source DAG и соединить с текущими callers. Такие задачи разрешено закрывать внутри нового root.

Полный ORCH04 coordinator carrier не включён: он дублирует 59 документов текущего G. Уникальные handoffs доступны по immutable Git refs; C10/C11 приняты отдельно. Их usable source не зависит от локальной доступности 731,8 MB workspace export или четырёх старых unpublished refs.

Числа full set: 127 bundles, 282 IDs, 291 исходных occurrences. Предложения авторов 198/54/23/7; исторический ledger отдельно содержит 9 closed / 260 partial / 12 held / 1 open. Все 282 строки новой sweep-карты пока `not_adjudicated`. Ни этот ноль, ни новый source merge не отменяют исторические решения и не делают авторские proposals formal closure.

Changed-file Ruff check PASS. Format debt остаётся на bayesian.py, C10 consumer test и неизменённом DFK02 companion; P41 attribution `not_established`: immediate-parent replay не доказывает отсутствие долга во всём slice.
