# Исследование решений для G

Не все остатки требуют нового архитектурного решения. Ошибка Mapping, потерянный typed refusal, несовместимый caller или недоставленный package input исправляются в существующем owner. Отдельное решение нужно там, где несколько допустимых semantics меняют custody, compatibility или область научного утверждения. G получает варианты, которые можно проверить, а не просьбу «дайте архитектуру».

| Область | Исследовать/реализовать сейчас | Что нельзя подставить самостоятельно |
|---|---|---|
| CAN/Core | Какие encoding/profile законы реально обещаны каждому reader; сохранение typed write options; raw-sidecar content conformance; caller census; versioned migration/explicit legacy selection. | Единую Core/IR law лишь из равного номера canon версии; профиль producer из reader defaults; silently admitted profileless artifact. |
| C05/C12 | Материальный basis, currentness/cache invalidation, existing resource/producer APIs; immutable query intent; canonical encoder/member/generation; request→fresh reader. | Production generation/currentness из size/mtime; чужой encoder из caller self-label; замена resource contracts whole-branch import. |
| L6/served | Selected source-backed root/profile/context, descriptor domain, controlled local serving run; возможный existing/versioned replacement с custody. | September normalized JSON match как raw-byte manifest match, общий release или разрешение назвать production current. |
| Subject B31 | Recomputed estimand/subject/unit binding, существующие identification/native uncertainty refs и consumer join. | Same-estimand/law потому, что names похожи; настоящий interval из ручного fixture range. |
| Refinement B161 | Реальная subject projection/discriminator, обоснованный partial/refusal, заданный upstream refinement law. | Новый универсальный law из одной positive fixture или внешний authority grant. |
| Partial graph B214 | Query-specific supported DAG/ADMG/PAG operations и persisted limitation; reader сохранность после refusal. | Полное PAG reconciliation из bounded supported query; widening mathematical promise сверх original criterion. |
| Empirical/B194/B197 | Existing evaluator/calibration/draw record, attempted denominator, covariance/axis/subject; producer→CAS→grade. | Predictive interval coverage как causal calibration; synthetic draw как реальная law/evaluator authority. |
| B56 | Qualifying configured shared workload с shared cap/roster/folds; existing Runtime permit и concurrent witness. | Неназванный production workload из одного synthetic PASS. Declared portable witness допустим в своей границе. |
| Native DevX | Canonical config-root behavior, actual archive input chain, current native SOTA rows; удалить debt только после фактического устранения. | Blanket exception renewal/expiry shift, смена clock, отключение hooks/gates либо признание новой архитектурной policy без issuer. |
| Lifecycle/authority | Разделить readonly diagnostic completion, candidate result и защищённую publication/promotion; проверить actual protected writer. | Raw dictionary `decision=complete` как доказательство promotion либо автоматическое заявление о bypass без reached protected effect. |

Для каждого спорного случая сохранить короткую отдельную decision record:

```text
Decision ID / affected original finding IDs and criterion pointers
Exact base/candidate/tree, named production caller and runnable terminus
Current contract and source behavior; one divergent case
Plane: internal mechanism / imported evidence / our claim reaction / external act
Existing reuse candidates and why the nearest one suffices or does not
Options: reuse -> extend -> consolidate -> build (omit irrelevant options)
Recommended narrow option; changed APIs/consumers/compatibility/migrations
Prototype or adversarial discriminator and complete deciding outputs
Authority/time/provenance/status effects; explicit negative and rollback by forward commit
External facts still required, exact minimum supplier packet, unavailable attempts
Concrete G question: choose between specified semantics, not "approve all work"
Ready independent work while decision is pending
```

Pattern pass обязателен: relevant IDs, существующий anti-pattern, smallest correct pattern, missing capability label и acceptance signal. Не превращать неизвестное исследовательское правило в новый enum/gate. На втором escape того же класса применить P40: расширить mechanism до нужного свойства либо объявить конкретную bounded residual и выполнить её falsifier. Принимать ещё один пример уже объявленного класса как новую задачу бессмысленно.
