## Minimum coordinated contract

Keep `params.pii_scan_results` in `state_reads`; derive the checkpoint-required subset as `state_reads - optional_state_reads`. Resume must continue failing closed for missing/null required reads and unavailable required ArtifactRefs.

Preserve the complete `state_reads` set for dependency semantics: idempotency hashing, concurrency/conflict checks, and declared consumption continue to include optional reads. In the Scientist-node adapter, keep the optional path as a consume port but represent it as optional (`min=0`); do not create a hard required-input precondition or `required_inputs` entry for it. Other reads retain their current required contract. Do not globally treat null as present.

**C: keep producer evidence truthful.** Preserve the current distinction between an actual `PIIScanSummary` and absent/null scan evidence. If the real scanner ran, propagate its summary with its existing provenance. If it did not run, leave the optional state absent/null; do not synthesize a no-findings value.
