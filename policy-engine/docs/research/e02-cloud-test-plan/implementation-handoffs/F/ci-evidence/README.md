# Complete CI evidence transfer

The [manifest](transfer-manifest.json) binds every committed evidence file to its original complete bytes, source/run/job identity and selection. Logs are lossless JSON content; decode `content` as UTF-8 to recover original bytes. Original local paths are historical locators, not claims of cross-host custody.

The five clusters preserve actual red/unrun/skip outcomes, full measured denominators and explicit limits. No CI baseline, exception, workflow, backend marker, credential or production dataset is changed. G-observed preserves the exact earlier bounded API acceptance. New documentation heads and this delivery branch require their own CI.
