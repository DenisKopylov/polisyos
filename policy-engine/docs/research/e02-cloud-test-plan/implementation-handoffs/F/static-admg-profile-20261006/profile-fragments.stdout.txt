## [unreleased-f-static-profile] - 2026-10-06

### Fixed
- `ir`: Isolate causal graph export rows from caller mutations: Cache immutable row preparations and return detached ordinary node and edge dictionaries so caller mutation cannot corrupt later graph exports.
- `foundry`: Refuse unsupported original graph profiles before static inference: Share original-graph admission across static ADMG separation, surgery, rewriting and inference builders, and normalize known reverse-stored arrows.

## Compatibility Notes
- Existing tuple-of-dictionaries consumer values and graph schema 1.0 are unchanged. Row mutations affect only the caller's detached values; this fragment does not promote the provider to a public facade.
- Resolved contemporaneous directed and bidirected relations remain supported; unresolved endpoints and compact lagged relations now raise ValueError before transformations or no-op returns. No IR schema or graph row value ABI changes.

## Migration Notes
- Keep mutations in the returned row values; use model_copy(update=...) to create a new published graph version.
- Handle the unsupported-profile refusal and supply a supported graph; do not delete uncertain or temporal relations to bypass admission.

## Known Limitations
- Finite graph and consumer properties do not establish general ID/PAG/transport completeness or real-data causal authority.
