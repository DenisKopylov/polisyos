# R3 fixture ownership discriminator

The thirteen retained R3 failures stop before their N5/B10/N8 property because the shared test fixture treats `manifest.tenant_context` as local CAS ownership. Core's existing contract keeps these separate: producer context is optional write metadata, while publication records local ownership and exact-view reads enforce the owner index. `_ManifestLifecycle.build` copies the supplied optional context, and `_require_bound_context_for_owner` admits an absent context on ordinary writes. Existing import admission tests deliberately preserve unbound producer manifests while recording a local owner.

The fixture now uses one shared discriminator: a fresh owner-scoped CAS reader must reopen the exact selected profile and content digest, while both foreign tenant and foreign cell readers must refuse manifest and payload reads.
