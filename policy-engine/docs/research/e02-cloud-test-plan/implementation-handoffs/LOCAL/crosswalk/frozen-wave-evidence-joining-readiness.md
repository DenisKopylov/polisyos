## Join one actual wave result to exact rows

1. Take root’s explicit frozen candidate `{commit, tree}` and the recomputed complete `/source_boundary/source_freeze/source_change_census` plus its canonical digest. Do not use an earlier source-code commit or stale report checkpoint. A command result is eligible only if its command, selected-input denominator, backend/profile, configuration/lock basis, actual consumer, and receipt bind to this frozen candidate.
2. For each executed slice, commit one direct-child `LOCAL/<slice-id>.json` handoff (`policyos.e02.local_slice_handoff.v2`) as a report-only descendant of the freeze. Keep the receipt’s `candidate_source` equal to the frozen commit/tree, record its actual slice base and ordered Git parents, and describe the complete affected source footprint. The required handoff fields are `slice_id`, `slice_base`, `candidate_source`, `parents`, `source_footprint`, `selected_inputs`, `backend_profile`, `commands`, `chain`, `controls`, `consumer_surface`, `limitations`, `decision_refs`, `proposal_ids`, `proposal_occurrences`, and `formal_closure_ids: []`.
3. Bind each covered original row in `proposal_occurrences` as exactly `{finding_id, occurrence_pointer, criterion_sha256}`. `proposal_ids` must equal those bound IDs. Each occurrence needs one or more distinct source-qualified decision refs whose `source_ref.covers` names exactly its pointer and criterion hash; a choice for one row cannot justify a sibling. This is decision research, never a G closure. Record real commands with exact argv/command, cwd, status, and hash-validated stdout/stderr refs; keep `FAIL`, `ERROR`, `SKIP`, and `UNRUN` distinct. `backend_profile` has exactly `backend_id`, `profile_id`, `environment_sha256`, and `environment_manifest_ref`. The manifest is `policyos.e02.execution_environment_manifest.v1` and binds `candidate_source`, backend/profile, source refs, runtime, platform, loaded import origins, nonsecret environment settings, every command run, the complete selected-input list, and its recomputed denominator SHA. Capture the actual producer → persisted artifact → bridge → consumer plus the real consumer selector. The strict validator reads the committed receipt with `git show` and recomputes its Git/source, outputs, raw-manifest digest, backend/profile, source refs, command rows, and selected-input denominator; an author-created JSON object or a passing helper test is not that receipt.
4. Create only explicit rows for occurrences supported by actual source-bound outputs. The registered v4 importer is `LOCAL/crosswalk/occurrence-evaluations.json`, schema `policyos.e02.occurrence_evaluations.v4`; its top-level keys are exactly `schema`, `frozen_context`, `evaluations`. `frozen_context` must name the frozen commit/tree, `/source_boundary/source_freeze/source_change_census`, and the canonical census SHA-256. Each row is keyed by exact `{occurrence_pointer, sha256}` and must carry the same candidate source, `state`, `result_summary`, nonempty typed `boundary`, `execution_context`, `evidence_refs`, `attempts`, `next_check`, and P40 `review_escape`. Evidence refs pin immutable source path/commit/blob/hash and the exact occurrence; the backend ref has role `backend_profile` and pointer `#/backend_profile`. The execution context must index the exact census, config/lock or source-bound scope, input state and refs, at least one current consumer surface, the v2 receipt, and occurrence-specific decision research.
5. For `VERIFIED`, bind all three occurrence-specific evidence roles: `property_positive`, `actual_consumer`, and `negative`. A closed *candidate proposal* additionally requires `proposal_disposition: "closed"` for every occurrence of that finding; one omitted or nonclosed occurrence prevents a finding-level closed proposal. `BOUNDED_LIMITATION` needs its named scope and an executed source-bound falsifier. `UNAVAILABLE_INPUT` needs the exact missing input and source/authority/permission/context/verification basis; malformed-present is not absent. `OPEN_ACTION` records completed attempts as exact `PASS`/`FAIL`/`ERROR`/`SKIP` with source-bound result refs and a runnable next check. Omitted occurrences remain `UNRUN`; do not generate 291 empty placeholder evaluations or let another occurrence inherit this one’s outcome.
