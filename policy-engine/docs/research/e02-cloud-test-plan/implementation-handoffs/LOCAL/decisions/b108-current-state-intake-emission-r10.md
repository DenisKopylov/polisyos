# B108 R10: direct current-state intake and emission

Status: author candidate for independent review. `closure_ids` is empty; B108 remains a proposal for G. The change does not establish an issuer, protected owner receipt, promotion permission, or production currentness.

The R9 review found one repeated B108 class at direct intake and current-state emission: caller promotion, judge, or readiness fields could survive cache return, Phase 5 intake, or a later DecisionPacket read. R10 reuses the existing policy-state projection as a single boundary. Policy-mode nodes project the state before reading current promotion fields or refs. The output-bundle node clears its old output refs before its cache branch, so it rebuilds through the existing builder and gives Phase 5 the same projected state. DecisionPacket, translation, compliance, governance, and verified-report consumers use that projection before loading readiness, judge, or output refs. Prior fields and refs remain in report-only history; CAS artifacts are retained.

For direct consumers that may reuse a candidate-only output bundle, R10 preserves it only when the persisted replayable audit snapshot recomputes an exact match for candidate content and ref, evaluation ref, run, workflow, execution profile, all runtime parameters, inputs, artifacts, and reports. It also rejects a bundle that contains readiness or judge decision content. A candidate ID or self-described audit label alone is insufficient. If the snapshot does not match, the projection removes the current bundle ref and the packet proceeds without it. This keeps candidate analysis available while preventing a candidate artifact from acting as a protected promotion receipt.

Alternatives considered: (1) retain the fast cache path based on presence/current candidate ID; rejected because it admits stale snapshots. (2) clear every candidate output permanently; rejected because it discards fully source-bound candidate work. (3) recompute persisted source binding and otherwise rebuild or omit; selected because it reuses the existing audit bundle and branch-state mechanism without adding authority semantics.

Migration: old cached bundles with missing or stale source bindings are rebuilt by the bundle node and omitted by direct packet-style readers. Existing CAS objects and raw prior state are preserved as historical evidence. No schema migration or new issuer contract is introduced.

Authored semantic controls exercise the cached rebuild and Phase 5 route, stale readiness/judge removal, direct DecisionPacket consumption, and same-ID changed-candidate rejection. These controls have not been run in the constrained author phase. Native source checks and the composed runtime wave remain required after independent review.
