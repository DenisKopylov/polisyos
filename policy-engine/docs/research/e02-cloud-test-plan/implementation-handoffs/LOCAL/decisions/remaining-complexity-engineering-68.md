## Pattern disposition

- **P13:** proportionality favors a responsibility-level split with measurable reduction; repeated micro-extractions that add modules without reducing the seven-file/function burden would add governance cost without closing it.
- **P35:** counts above use the complete `src/**/*.py + tests/**/*.py` denominator, not a search sample.
- **P38:** the expiry checker tests dates/metadata, not LOC or C901. A 900-line file with an expired entry would still fail this check; a renewed entry with a 4,373-logical-line file would satisfy the date check while remaining over cap. Source measurement and exception lifecycle are separate predicates.
- **P40:** same class across all seven rows; widen the work to the actual set, or record a bounded owner/expiry residual rather than advancing one file at a time.
- **P41:** no inherited/owned classification is made. The preflight names the slice base, but this review did not replay the gate at that base or reconcile the full changed-path denominator.
