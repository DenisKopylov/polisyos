# Q2 output-path confinement patch proposal

This is an unapplied helper-only patch proposal, prepared against the existing ignored helper `LOCAL/linux-profile/raw/final-source-linux-wave.sh` at SHA-256 `9241d6d695a27e673cd36f6416cfbf03fbc1c383368d642827d7380cfbc71d81`. Patch artifact: `LOCAL/linux-profile/raw/q2-output-path-confinement.patch`, SHA-256 `b0e10f4258157f592e0fd469e895cc32b52bc68ce9e512d34ea7dd9d5d229c08`.

The proposal replaces the final-path `-e` check plus `mkdir -p` with a component walk over `/scratch`, `/scratch/e02-q2-runs`, and the freeze directory. It uses `-L` as well as `-e`/`-d`, refuses symlinks and non-directory ancestors (including dangling symlinks), creates missing parent components one at a time, and exclusively creates the attempt and orchestration directories. The same `q2_output_action` function is serialized into the worker shell and exercised by the existing `self-test-copy-decisions` mode; twelve pure decision cases cover real/missing parents, regular-file ancestors, existing output, ancestor symlinks, and dangling symlinks.

Classification: **P40 new class, output-path confinement**. The earlier transport-path defect was source/input binding; this finding is about where retained outputs can be written. The implementation property is path containment through real directory components, while the old helper tested only whether the final attempt path existed. The falsifier is a dangling final symlink or symlinked ancestor, which the old guard admits and the proposed classifier refuses before output creation. This proposal does not remove that residual by execution: no helper application, self-test, worker command, product test, build, or Q2 wave was run here. Root must review/apply the patch and run the bounded path-decision self-test before granting the heavy wave.
