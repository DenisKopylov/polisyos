## Bounded custom-Any leaf residual

The verified producer graph guarantee is scoped to finite JSON-like containers and ordinary Pydantic models. A custom runtime object placed after normal construction under the `dict[str, Any]` state params can evade Pydantic revalidation: `_validate_mutation_attachment` traverses dict/list/tuple/BaseModel and returns on an unknown leaf (`src/polisyos/scientist/orchestration/engine/state_branching.py:1325–1351`), while `snapshot_state` deep-copies the top-level mappings (`:276–286`) and may invoke the object's `__deepcopy__`. The engine README explicitly excludes arbitrary custom runtime objects.
