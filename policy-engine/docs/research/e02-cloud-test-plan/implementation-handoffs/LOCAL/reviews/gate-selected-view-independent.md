## Finding

The change closes the concrete **valid-reference** selected-view loss described in `LOCAL/can-options/decision-packet.md`: the request now carries complete typed `ArtifactRef` selectors for valid `ExperimentState.inputs`; the 1.2 request identity includes the serialized context; cache admission verifies the persisted request body against current state; and decision lineage carries the selected request `ArtifactRef`. I independently replayed the selected-view reissue test and the governance audit integration test; both pass.

There is a deeper escape in the same P38 class. `_collect_gate_selected_replay_refs()` omits malformed replay refs from `selected_replay_refs` and relies on `replay_summary.invalid_refs` to carry the limitation. That summary records only the failure class. A controlled temporary-CAS probe changed the raw malformed Trinity ref from `malformed-one` to `malformed-two`. In both cases the key was absent from the typed selected map, `invalid_refs` was `{"trinity_bundle_ref":"malformed_ref"}`, and the request contexts and request IDs were identical. This demonstrates that the request does not identify which malformed-present input was shown to the reviewer. It is **the same P38 selected-view/request-binding class one level deeper (P40)**, not a new class. Probe output: `LOCAL/raw/gate-selected-view-independent/malformed-ref-identity-control.json@sha256:c39fef8c513661c9df1533ccad2a2f3f5af2fa26b22fe5d9ec35afe35ab7ca76`.

The smallest strict resolution is either to structurally bind a typed identity/fingerprint for malformed-present replay inputs into the request context, or to record a bounded residual whose falsifier proves that an approval cannot promote an incomplete/invalid replay basis. The latter is not established by this candidate: `tests/integration/test_human_gate_audit.py:63-88` creates a request whose replay readiness is `incomplete`, supplies `approve`, and observes the governance verdict become `approve`; `_handle_gate_decision()` maps `GateVerdict.APPROVE` to that result at `src/polisyos/scientist/nodes/builtins/governance/run_governance.py:465-472`. This proves the current consumer outcome, not that the verdict is a public, signed, or authority-grade claim; those surfaces are not established by this test. Whether the verdict only records a human continuation or can be read as admissibility/completeness remains the pending G choice. Do not treat the approval test as evidence that malformed input identity is harmless, and do not infer the authority rule in this engineering review.
