## Blocking finding: source-bound requirement is opt-out

The new `MethodJobBenchmarkEvaluator.requires_source_bound_execution_work_packet` property returns true only when both `data_snapshot_bindings` are nonempty and `method_params["capture_execution_work"] is True`. `_evaluate_candidate` invokes the new admission gate only when that property is true or a packet claims status `available`.

The producer has a matching opt-out: `_persist_execution_work_packet` returns `(None, "unavailable", "method_work_capture_not_enabled")` when the flag is absent or false. With nonempty DataSnapshot bindings and a finite result, the receiver therefore skips packet admission, leaves the evaluation metrics and `promotable` state intact, and projects the primary value to Search. This bypass persists even though the method consumed source-bound snapshot fields. The new negative modes all set `capture_execution_work=True`, so they do not falsify the opt-out path.

The applicable boundary is the bound source input, not the producer’s optional capture switch. Keep the legacy no-input route by recognizing empty DataSnapshot bindings; a configured source-bound evaluator must not turn off required evidence while continuing to emit an admissible Search score. The minimal falsifier is the existing finite source-bound setup with the flag omitted/false and the same snapshot bindings: a source value must not appear in evaluation metrics, Search simulation results, or a promotion decision. This is the second occurrence of the same P40 class, so close the class in one receiver invariant or record a bounded residual with its falsifier.

The added receiver otherwise has useful source checks: it resolves the work packet, suite and method result; compares candidate/suite/result/evidence/job/run/evaluation/attempt/snapshot bindings; validates configured method identity, seed, params and slot bindings for `MethodJobBenchmarkEvaluator`; and compares the persisted method-result primary metric and unit to the evaluation. The existing reader recomputes the packet’s CAS input lineage and dispatched input fingerprints. For failed admission, the patch marks the evaluation non-promotable, removes the primary metric from both split maps, and preserves a typed refusal note/status before persistence. The direct red above is the right property-level regression test for this path.
