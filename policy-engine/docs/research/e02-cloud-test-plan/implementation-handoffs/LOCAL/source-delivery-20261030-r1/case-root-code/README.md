# Case-root authored code and helpers

This archive preserves remaining deduplicated UTF-8 source files and patches found in a bounded code-only walk of the named local E02 native case root. The catalog binds hashes and original paths. Some entries are diagnostic supervisors, pytest launchers, test fixtures or experiments, not product code. No results, payloads, databases, test temporary trees, environments or caches are included. These files are retained as work in progress, not claimed to be tested or applied.
