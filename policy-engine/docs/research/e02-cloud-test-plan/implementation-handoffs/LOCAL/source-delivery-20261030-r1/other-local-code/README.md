# Additional local source-code hunks

These source-language hunks and, where available, exact standalone scripts recover code work from patches whose target was a local diagnostic/helper path rather than a tracked product path. They are alternatives or tools for future investigation; their local path headers are provenance and do not make them product changes. Mixed non-code sections, output, databases, CAS and data are excluded. The catalog records every original source patch, SHA-256, target and remaining unrecognized file.
