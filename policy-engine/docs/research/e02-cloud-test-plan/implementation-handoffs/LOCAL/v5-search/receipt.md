# V5 search / MethodJob / CAS receipt

This receipt records the selected configured search path and its remaining
source boundaries. It does not claim that synthetic MethodJob data establishes
fiscal law or native funnel work counts.

## Selected chain and result

`WarmStartBridge` → `BayesianCandidateGenerator` → `SearchLoopRunner` →
`MethodJobBenchmarkEvaluator` → canonical `compute.runner.run_job` → CAS result
and execution-evidence artifacts → fresh CAS reader / transfer receiver.

The MethodJob evaluator binds candidate fields to the registered method, runs
through the existing MethodJob seam, and persists the result/evidence refs into
the evaluation lineage. It admits only the configured primary metric. Missing,
boolean, non-finite, or unit-mismatched values are unavailable rather than zero;
sample counts and guardrails affect promotion only when returned by the method.
MethodJob evidence has `authority_purpose=method_execution` and explicitly
cannot establish governance admissibility or method validity.

The canonical Bayesian optimizer produces the source profile from its effective
optimizer, fitted data, GP, transforms, and likelihood. A cold Sobol row records
the configured native optimizer but has no fitted GP and is not warm-start
eligible. A fitted native profile records its actual training corpus, supported
transform families, learned normalization/standardization/noise states, search
space, immutable run context, and objective identity. The receiver checks the
full profile against its own space, context, and objective. Injected optimizers
remain a separate profile kind and cannot qualify as configured native GP
evidence. Missing introspection or profile fields fail closed for external warm
reuse.

The focused positive test executed a native BoTorch/GPyTorch fit, persisted and
fresh-read its profile through MethodJob/CAS, then transferred one fitted-source
row into a same-context native target search. The target fit contained that
source row and two fresh MethodJob observations. The test also checks context
immutability and rejects cold/unfitted source history. This is an engineering
search-history result, not an authority statement about the source data.
