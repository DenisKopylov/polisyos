# Что сделано и где остаётся работа

## Что означает текущая бухгалтерия

Различаем пять фактов: source существует и получен; property выполнено на точном source/profile; code slice принят G; исходный finding adjudicated G; интегрированный продукт прошёл общий closeout. Это последовательные вопросы, но результат предыдущего не гарантирует следующий. Проверка транспортной целостности results также не доказывает runtime: importer `--check` прошёл, verification содержит 15 transferred texts / 2 074 cells / 0 raw archives и прямо ограничен transfer/navigation.

«Formal closure = 0» у B и D — прежде всего запрет автору присвоить себе приёмку G. Он не отменяет уже измеренные свойства. Но и объявить все их proposed-closed строки процедурно готовыми нельзя: исполнение на другом source, injected worker вместо configured producer или in-memory callback вместо persisted history может не покрывать исходный criterion. Полный разбор каждой строки привязан в [findings.json](findings.json); общий итог предложений вычислен по полным массивам, без суммирования пересекающихся тестовых waves.

## Почему отдача последних циклов падает

1. **Незавершённый вертикальный consumer возвращается всем соседям.** E математически корректно сформировал envelope, A не потребил authentic evidence; C сохранил query profile, live serving caller его не передал; D проверил injected Node, configured producer остаётся отдельным. Новая общая wave внутри E/C/D не создаёт отсутствующий bridge.
2. **Идентичность locator подменяет идентичность consumed basis.** DFI same-ID profile может сменить endpoint/policy без изменения resume basis. Estimand, tenant/view, model/split, time и version нельзя восстанавливать по похожему имени. Нужен один consumer-side bind, затем узкие integration checks.
3. **Буквы закрепляют очереди, но реальные write/read edges другие.** CAS меняет D/F readers; monetary event меняет A/D; B pool меняет C stream; E uncertainty меняет A/C/F. Повторная сдача «всего B» прячет эти зависимости внутри сотен paths и исторических receipts.
4. **Слишком широкий запуск заменяет deciding check.** Cloud startup/offline, SIGKILL, missing optional backend и неверный host могут остановить suite до свойства. Причина signal9 не установлена; это нельзя объявить product failure, исправлением или inherited debt. Наименование нужного selector/profile полезнее нового cohort из тысяч cases.
5. **Proposal scope отличается от criterion scope.** D Node15 доказывает actual Node с injected workers и budget/ledger; History1 — контекстное in-memory reuse с mocked callback. Это полезная работа, но не production history или statistical independence. D «38 verification gaps» — очередь проверки/admission, а не 38 доказанных дефектов.
6. **Иногда наоборот scope расширен сверх finding.** B11 не требует invoice reconciliation; LA-035 relocation неизменной historical формулы не требует нового optimizer mandate; finite sharp-RDD profile не требует fuzzy/cluster универсальности. Такой дополнительный барьер задерживает закрытие без улучшения исходного свойства.

## Что считать дефектом, а что — ограничением

- **Исправимый сейчас дефект/разрыв:** DFI неполная identity; DFK parser; missing configured producer bridge; stale canonical generated surface. Есть конкретный counterexample или отсутствующий edge и fixture-level discriminator.
- **Статический риск, пока не runtime failure:** B59 preflight допускает arbitrary leaf, после чего copy может вызвать producer-controlled hook. Проверить общий допустимый value domain и hostile-copy control; не заявлять воспроизведённый FAIL без запуска.
- **Неисполненная проверка:** B1e, supported Linux F query, current installed artifact, extended GP profile. Есть property, source и профиль; требуется один минимальный deciding run.
- **Отсутствующий factual/authority input:** genuine law/rights/tenant reuse, calibration/evaluator law, native same-run draw evidence, historical0.9 manifest. Generic fixture не создаёт этот факт; инженерный negative path продолжается.
- **Честная граница метода:** iid/positivity, parallel trends, finite/static graph law, sharp fixed-bandwidth RDD, linear-Gaussian posterior. Не устранять кодом само наличие предпосылок. Исправлять ложную promotion, неправильное применение или выход за заявленный профиль.
- **Неопределённая область эксплуатации:** computed/external caller, deployment loaded artifact, live backend. Tracked-Python census даёт свой denominator и `UNRESOLVED`, а не доказательство полного отсутствия consumer.
