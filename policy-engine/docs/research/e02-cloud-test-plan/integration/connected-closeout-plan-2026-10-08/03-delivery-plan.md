## Что специально отложено

Не начинать general PAG/temporal inference, универсальный statistical envelope, новый welfare optimizer, новый scheduler, sovereign permission/billing service или broad corpus migration. Для B214 сначала D05 distinguishing query; для B56 сначала R4 measurement; для LA-036 actual law/conditional sampler. Пока это самостоятельные bounded limitations/held capabilities.

G может публиковать принятые code checkpoints с named limitations. Это не означает full E02 closeout: если исходный criterion требует отсутствующий положительный owner факт или native property, его finding остаётся held/limited/open. Deferred rows не удаляются и не переопределяются более лёгким criterion. Q0 — отдельная очередь exact original-scope adjudication готовых receipts; она не заставляет исполнять новый V5/default или production profile для всех proposed-closed строк.

## Critical path и четыре declared edges

Dependency graph имеет несколько параллельных ветвей: `Q1 → R1 → R2/V6`; `Q1 → R3/V5`; `I1 → affected I4`; `S1 → S3/V2/V3/V7`; `T1 → T2`. Они сходятся в relevant Q2/generated consumers и independent reviews перед source freeze/final replay. R3/V5 не ждут всю R1 очередь, если их selected source inputs unchanged и уже квалифицированы; при changed R contract сначала выполняется его конкретный defining check. F Linux reader ждёт именно selected CAS delta, а не все monetary tasks.

Кроме hard task dependencies есть supplier-input edges: relevant `I1/I3/I4 source artifact → V3` и `V1 source profile → V6`. Требуется именно admitted immutable input, а не завершение всего соседнего task: уже существующий matching source profile может быть предоставлен напрямую; changed Catalog resume basis должен сначала пройти I1. Пока supplier отсутствует, fixture preparation и unrelated checks продолжаются, этот particular authentic consumer остаётся UNRUN. `tasks.json` сохраняет такие edges как conditional inputs.

Одновременно идут I1/I2, S1 и T1; V2/V3/V4 могут работать на собственных immutable slices, когда их конкретный supplier готов. I4 production facts не задерживают I1 generic basis repair. B56 и B214 выделены отдельно: отсутствие их wider admission не заставляет F повторять остальные 33 bounded proposals.
