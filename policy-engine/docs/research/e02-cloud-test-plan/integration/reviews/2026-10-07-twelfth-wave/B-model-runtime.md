## Property and implementation

The property is that a producer with a `NodeSpec.state_writes` grant cannot mutate a Pydantic field through any live branch path outside that grant, including typed `ArtifactRef` leaves and aliases; denied mutations leave branch/base state and the replay journal unchanged. `NodeSpec.state_writes` remains the authority source. Nested `branch_state` can narrow that grant, not release or widen it.

At enforced-scope admission, candidate `branch_state()` validates the state graph before its copy and wraps mutable graph values, including ordinary BaseModel descendants. `_TrackedModelMixin` intercepts declared-field assignment and `model_copy(update=...)`; it resolves current parent/root paths before admitting mutation, checks all discovered live paths against the original grant, wraps/reconciles the value actually stored by Pydantic, and only then records through the existing `StateMutationJournal`. It preserves frozen assignment/copy behavior, returns detached copies without treating them as live effects until attached, and refuses model-field deletion because the current replay format has no such operation. Custom hooks, private/extra runtime state, undeclared attributes, cycles, and arbitrary object/reflection/validator side effects remain outside the declared finite-graph profile. This is not a Python sandbox.

The candidate changes the canonical writer in `state_branching.py`; it does not add a parallel merge writer. Existing `NodeResultCache`/CAS persists the outcome and mutation journal, and `merge_parallel_outcomes` applies replay to the consumer’s current state.
