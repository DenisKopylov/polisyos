## A332 red and the fix

The original G candidate `332ba0b91e9a85774d48d101d4af86e3a3baf911` (tree `4e21c90467913c6dae1c85b84b8c7a42a1dc9124`) has a genuine deciding failure in `test_default_cycle_preserves_simulation_only_result_and_history`: the producer persists typed `conditional_interaction_evidence` in both root and cycle `value_port`; the reader projects as frozen v3, drops those fields, and returns `generation_cycle_historical_projection_mismatch`. The exact native receipt is `policy-engine/docs/research/e02-cloud-test-plan/integration/reviews/2026-10-07-A332/native-receipt.json` (candidate failure, 1/1, output SHA `48eec877…`); `history-divergence.md` explains the two dropped paths. The base selector was not replayed, so P41 attribution is **not established**; do not label the failure inherited or newly introduced.

The correction is structural and addresses that mismatch at the shared versioned serializer. `_generation_cycle_history_schema.py` copies the existing v3 model graph to a separate v5 graph, adding the typed interaction owner only there. v3 remains unchanged, and v4 remains its source-limited shape. v6 serializes as the v5 core plus the existing typed source-custody limitation. The producer selects v5/v6 only when a cycle actually carries interaction evidence; it does not relabel evidence-bearing v3/v4 runs. The HTTP normative CAS writer now records `node.cycle_run.schema_version`, so its manifest uses the leaf run's real epoch.

`GenerationCycleRun` refuses non-null interaction evidence relabeled v3/v4, v5/v6 without evidence, v5/v6 with no cycles, and disagreement between the run-level value port and last-cycle value port. Source-limited v6 requires its limitation and rejects a preservation receipt; v5 rejects a source-custody limitation. The serializer and history reader therefore cannot make the evidence disappear while retaining the old version marker. This closes the observed P38 divergence (actual v3 projection omitted a field the v3 runtime emitted) by moving the field to an explicit epoch, rather than whitelisting it in frozen v3. This is the same serializer-width class as A332, repaired at the shared epoch mechanism (P40).

Three atoms get an explicit third-order residual; four or more are only an aggregate `three_plus` residual.
