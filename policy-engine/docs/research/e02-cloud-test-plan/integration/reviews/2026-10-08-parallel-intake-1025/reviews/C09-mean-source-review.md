## Property and limits

`_mean_estimator_error` computes `sample_std(ddof=1) / sqrt(n)` over the actual finite result rows, only when the current random path has typed, nondegenerate Normal fits, non-adaptive sampling, at least two finite outputs, and a complete requested/attempted/finite denominator. It records the seed, counts, input-envelope content digests and the formula in both envelope metadata and result diagnostics. Unsupported laws, adaptive or incomplete runs, and QMC without retained scramble means return unavailable. The previous quantiles, outcome `mc_std`, and interval fields remain distinct.

The independent Fraction oracle computes `SEM² = sum((xi-xbar)²)/(n(n-1))` from persisted sample bytes, not NumPy's implementation. The positive native records show the expected profile on 100 and 400 draws (SEM about 0.09978 and 0.04986); same-seed output is reproducible. Fresh CAS readback and a separate child process reopen the artifacts. The counterfeit input metadata (`mean_estimator_error=999`, `status=admitted`) does not replace recomputation. Weighted empirical data carrying fake `iid`/law strings, pooled two-scramble QMC rows, and a real 1-success/100-attempt case are unavailable. Removing each guard causes the corresponding adversarial case to report a value; the supported-profile control still passes under removal. These receipts establish arithmetic/dataflow and refusal behavior, not statistical coverage.

The code does **not** establish that the callback is deterministic, outputs are independent, response variance is finite, or the declared input law is scientifically authoritative. It explicitly sets `assumptions_verified=false`, `source_law_authority=not_established`, and `gate_eligible=false`; it does not issue a CI or promote an outer gate. Independent oracle counterexamples `Yi=Z` and `Y=exp(0.3X²)` remain real boundaries, not resolved by the finite fixture. Also, `_build_results` converts values to JAX `float32` before this SEM is calculated; the Fraction oracle checks the persisted/quantized corpus. Treat this as conditional sampling SEM for the current represented outputs, not a total callback-vs-real-number or floating-point error bound.

**P38 metadata divergence:** the helper initializes `sampling_law="implemented_product_of_typed_normal_fits"` before checking the input profile. Both the independent `weighted_fake_iid` record and the supplemental root readback are weighted `PosteriorSamplesCarrier` inputs (the latter has `DistributionFamily.BOOTSTRAP` and weights `[0.9, 0.1]`), yet the fresh persisted diagnostic retains the typed-Normal label with `status=unavailable`, `standard_error=null`, and `gate_eligible=false`. The supplied execution receipt records return code 1 as the expected property-assertion failure; the observation reached a fresh CAS reader and reports 99 loaded PolisyOS modules with zero mismatches. Thus the false label is confirmed, while SEM promotion is still refused. Make the law field reflect the observed profile or use `not_established`/omit it on unsupported inputs.
