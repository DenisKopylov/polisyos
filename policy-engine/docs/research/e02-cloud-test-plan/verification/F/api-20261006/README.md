# Installed causal facade verification — API-01 / LA-020

The existing `causal_engine` and `interference` initializers have explicit
public bindings and retain historical private/test bindings. This slice adds
verification of their existing behavior. It retires no additional symbol.

`census.py` reads every blob in the selected immutable Git tree, independently
reconciles the complete entry list, parses every UTF-8 Python member, and
enumerates literal imports, address strings, case-insensitive lexical mentions
in all text file types, and computed import candidates. The output discloses
file-type denominators, source identity, binary/symlink exclusions, parse
failures and unresolved expressions. Lexical mentions in research receipts
are navigation, not evidence of supported execution. Arbitrary Python alias
flow, computed `exec`, plugin configuration and third-party private callers
remain outside the static resolution claim.

```bash
python docs/research/e02-cloud-test-plan/verification/F/api-20261006/census.py \
  --root .. --ref <implementation-sha> --output <receipt-path>
```

The mirrored `test_installed_facade_contract.py` runs unchanged against source,
an installed wheel, and a wheel rebuilt from the sdist. A neutral consumer
directory and Python isolated mode exclude checkout paths. Each consumer uses
its own virtual environment and installed product; the recorded read-only
third-party dependency directory is reused without processing its editable
`.pth` files. The runner checks every loaded `polisyos` module origin against
the owned installed package directory and verifies relevant archive bytes
against the frozen source blobs. This is product-installation isolation, not
a claim that all third-party dependencies were independently re-resolved.

The native consumers cover direct/star imports, every supported public and
retained private object identity, pickle FQNs, runtime pydoc generation, all
four historical algorithm monkeypatch addresses with real algorithm execution
and restoration, incidental/unknown exports, and fresh CAS evidence readback.
A same-name wrapper clone and a deleted patch bridge preserve declaration
markers while losing the tested ABI. Independent removal runs must fail the
unchanged positive tests. The immutable-input fixture also exercises changed,
untracked, binary, computed and absent inputs to the census itself.

Installed `id_engine` package execution and both Foundry layout addresses are
companion checks for GRF-01 LA-007/LA-019 and FRY-01 LA-037. Their primary owners
retain closure decisions. A native family IC certificate is a certificate
witness; it alone does not establish a family-to-state execution chain. The
compiler seed/state activation bridge remains with the FRY owner.

The deciding handoff records exact commands, source/archive/environment
identities, full outputs and per-criterion outcomes. A known graph fixture or
native algorithm result does not admit real-data causal identification.
DoWhy/EconML excluded by the Python 3.14 markers are UNRUN, never backend PASS.
Architecture or utility-judge failures are unattributed unless P41 exact-base
replay and complete input-denominator disjointness are both established.
