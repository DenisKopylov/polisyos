# INT-R2 — Seam And Crosscheck

## 1. Package-Internal Seams

The package contains four internal boundaries that must remain explicit.

| Upstream object | Downstream object | Correct seam | Audit result |
| --- | --- | --- | --- |
| typed refusal / residual | `GapShapeAssessment` | the demanding predicate and evidence regime are frozen before classification | sound, classifier construction incomplete |
| shape assessment | `GapAcquisitionCase` | only `one_case` or `split_required` with positive-eligible predicates creates case(s) | sound as a rule; branch predicates absent |
| admitted acquisition artifact | demanding owner gate | artifact permits re-evaluation; owner recomputes closure | strong and correctly non-substitutable |
| demanding owner result | Atlas/public projection | surface renders canonical result and ceiling; it never composes or mints authority | strong boundary, consumer integration absent |

The package does not create a second status lattice and does not let a route, producer or surface close
its own case. Those are important positive results.

## 2. GY And CG5 Seam

### 2.1 Existing data acquisition

The N13/DS15 path is a genuine worked example of refusal-with-a-path:

```text
typed data demand
→ eligible strategy
→ source/right re-resolution
→ content-bound admission passport
→ quarantine or overlay epoch
→ owner-visible before/after availability recomputation
```

INT-R2 correctly generalises the discipline and rejects the storage shape. A relation, estimand,
mandate, decision or audit must not be forced to terminate in an observation row merely because the
existing machinery does.

### 2.2 CG5 ownership

`grounding_active_controller.py` states that CG5 reads gate certificates, chooses bounded actions and
routes results back; it never closes obligations, injects evidence or marks resolution. The package
therefore correctly refuses to make CG5 the non-data producer.

The missing seam is not “CG5 needs more fields.” It is:

```text
CG5 action ticket
→ competent per-type producer / external institution
→ admitted non-data artifact
→ exact CG owner re-entry
```

That chain remains `absent/unallocated`. This is an expected residual, not an audit defect.

### 2.3 Three capstones

The package preserves the distinctions:

- `education` is a candidate `estimand_binding` case;
- `first_vertical` and `unseen` remain a relation/writability disjunction or an ordered two-case
  sequence;
- none defaults to ordinary data acquisition.

This is the correct treatment. The wording “three structural gaps” in the supplied orientation is
stronger than the committed route evidence, which establishes `not_a_data_gap` and names a structural-
looking reason string, not a completed structural-shape classification.

## 3. Atlas And Consumer Seam

The package's surface rule is correct:

- Atlas may render a canonical refusal, case, ceiling, re-entry requirement or terminal;
- Atlas may not infer a case type, produce institutional evidence, compute a broader ceiling or turn
  an admitted artifact into readiness/approval;
- acquisition process states must project into the one existing lattice rather than become a second
  authority system.

The commission described a drafted `gap_acquisition_case_union` non-closure row as unmerged demand
evidence. At the package pin, exact-key connector search did not resolve that token. Fuzzy search found
related Atlas/DS9 planning material, including an `implementation_receipts_complete_unmerged` plan,
but not the exact row or its quoted closure text. Because a search index settles neither a zero nor a
positive, this audit records the row as **institutionally supplied and not independently resolved at
the pin**.

The package mostly observes that boundary, calling the row demand evidence only. It should add the
holder label wherever the row is cited. That is a minor orientation/source-status repair, not a reason
to reject the union.

## 4. INT-R5 And Human-Authority Seam

The sibling `research/int-r5-research` package exists at its own research head and defines a
`DecisionAuthorityGraph` plus pre-action `DelegationValidityCertificate`. Its question is whether a
person or collegial body had authority for an exact decision; it explicitly says a signed
`HumanDecisionRecord` does not by itself prove institutional competence.

INT-R2's `competent_human_decision` acquires a different object:

- actual case-specific work;
- a reconstructable attributable judgment;
- a conclusion bounded by the person's competence and role.

The seam must be:

```text
INT-R5 authority validity for actor/body and act
+ INT-R2 competent work/decision acquisition
→ demanding action gate may evaluate the exact human decision
```

Neither closes the other. INT-R2 correctly recommends consolidation with INT-R5/GY-PA2/DS9 instead
of a second competence certificate. The future implementation must reference the ratified authority
graph rather than re-encode mandate, delegation, quorum or conflict rules inside the acquisition
union.

## 6. Cross-Package Analogue Sweep

### 6.1 Finding-register analogue

The INT-R3 independent-audit line contains a claim-evidence ledger that separates stage-1 standing,
auditor evidence class, audit result and consequence/finding linkage. INT-R2's F01–F40 table omits that
structure. The analogue is therefore confirmed: the same pipeline requires per-finding evidence class
and effect, and INT-R2 is thinner at precisely that seam.

### 6.2 Repository-zero analogue

Both INT-R3 and INT-R2 contain strong local source readings followed by broader absence language. The
INT-R3 audit refused repository-wide zeroes lacking complete walks. INT-R2 itself applies that rule
correctly to the institutionally supplied structural zero, but not consistently to F05, F07, F11 and
F32. The analogue is confirmed and recorded as AUD-F004.

### 6.3 Source-ledger analogue

INT-R3's external rows lacked durable per-transfer locators. INT-R2 improves materially by binding all
22 sources to propositions and non-effects. The remaining analogue is narrower: mutable landing pages
are still not version/content-bound. AUD-F006 therefore does not repeat the stronger INT-R3 accusation
that the ledger is merely a citation list.

### 6.4 Benchmark-self-proof analogue

The failure-pattern register's authorial-proof class applies here: a fixture pack must fail an
implementation that preserves labels while deleting the guarded property. INT-R2 names adversarial
families but does not instantiate all 63 cases or demonstrate mutant failure. This analogue is
confirmed as AUD-F008.

### 6.5 Negative sweep

No further analogue was found for:

- a parallel status lattice;
- CG5 closing its own obligations;
- Atlas minting a union branch;
- audit evidence substituting for a competent management decision;
- survey vocabulary being declared registered PolicyOS vocabulary.

These negatives are bounded to the five-file package, not claimed as repository-wide zeroes.

## 7. Result

The canonical-owner seams are conceptually strong. The package correctly routes rather than absorbs
external institutions and existing owners. Required revisions are:

1. construct the shape classifier rather than only recording its output;
2. bind the consumer-row claim to holder-relative evidence;
3. consolidate HD with INT-R5 and IA with core/audit without cross-satisfaction;
4. reconcile capacity semantics with the sibling Wave-8 pair during consolidation;
5. preserve the no-mint/no-auto-close projection seam.

Seam verdict: **GO_WITH_REVISIONS**.
