## Claim-By-Claim Analysis

### Separation and D4-A1

The package correctly distinguishes product chrome, authority-bearing texts, renditions, semantic identities and audience variants. Ukraine and Canada examples preserve the distinctions. The revision should replace “orthogonal coordinates” with “record dimensions/layers” and show dependency edges; it should not collapse the model.

### English pivot

The target architecture does not covertly reintroduce English. Jurisdiction concept IDs survive; mappings retain relation/provenance; English indexing is expressly non-authoritative. The repository’s `SPOCandidate.subject_en` shape is correctly treated as a current adapter/gap.

### IDs and status vocabularies

The no-second-lattice argument survives because the package marks relationship modes, refusal examples and risk classes as candidates or mapped values. Runtime already owns distinct validity states and versioned namespaced blocker IDs. Implementation must map/register; research prose does not establish new members.

### Falsification versus certification

For source `s`, target `t` and enumerated context `c`, a target-only permission or lost prohibition decisively fails. The converse is invalid unless the context set is complete. The package has no completeness oracle for unrestricted language. A positive certificate may attest only:

```text
source/target digests + proposition + purpose + frame version
+ complete declared fixture/context population + human decision
+ residual/exclusions + invalidation triggers
```

It must not mean “all meanings are identical”.

### Zero holders and N+1

Cardinality zero is legitimate: the required role exists, appointment is empty, the governed purpose refuses, listed source-view/draft functions remain available. That is a target-model result. The package has no type/producer/bridge/consumer/surface implementing it. Likewise “N+1 without schema change” is established for designated, co-authentic and RTL-source examples, not every conceivable jurisdiction.

## Invalid Or Overbroad Inferences

- distinct record type ≠ independent coordinate;
- zero found counterexamples ≠ universal equivalence;
- Markdown representability ≠ capability;
- a named lane ≠ an accountable owner;
- historical attribution ≠ current measurement;
- correcting one duplicate ≠ superseding all duplicates.

## Arguments That Survive Audit

D4 composition; UI/source separation; authority-text sets; jurisdiction-specific co-authentic reconciliation; rejection of mandatory English authority pivot; separate translation/adaptation; ID-preserving status projection; red-first action-profile falsification; and zero-holder representation in the target model.

## Residual Band

The audit did not prove semantic-frame completeness for every language or legal doctrine. External regimes generally allocate authority, process and responsibility rather than mathematically prove translation identity; that supports narrowing ARG-06, not abandoning MAEP.
