## Per-Finding Closure Criteria

### Standing and evidence custody — A01/A02

A01 closes only when no package file contains non-member fields/tokens or a contradictory tuple. A revision-ledger assertion does not supersede reader-facing text.

A02 closes only when each old measured row is: (a) reproduced at a named current SHA, (b) retained as historical with original executor/date, or (c) explicitly retracted with reason. Filename succession alone is insufficient.

### Capability and claim orientation — A03/A06

Every present-tense capability must have repository coordinates. Otherwise use `the target model can represent` / `the protocol would return`. W4 capability standing stays unchanged unless another authorised stage constructs the chain.

### Catalogue census — A04

The executable walker must recursively flatten primitive string leaves by full path across exactly three JSON files; report key-set differences and target equality only on shared paths; name executor; and cross-check through an independent parser/test.

### Ownership — A05

Every one of 30 finding rows names an existing owner identity or explicitly records no allocation. A role definition is not an appointment where a human decision is required.

### Proof strength — A07

A positive certificate binds exact source/target digests, proposition, purpose, frame version, complete declared context/fixture population, glossary/vocabulary versions, reviewer basis, residual/exclusions and invalidation on new counterexample. A stronger claim needs a defended completeness oracle.

### Architecture/citations/entrypoint — A08/A09/A10

A08 closes with explicit selector/dependency relations, including `PresentationVariant.parent_*`. A09 closes with the corrected SCC link and durable source spans. A10 closes when an existing artifact identifies the substantive entrypoint and headings-only scaffold disposition without losing delivery history.

## Properties A Revision Must Preserve

1. D4-A1 unchanged: `en` authored UI, `uk` translation, `ru` frozen, source rendering separate, RTL UI unsupported.
2. UI locale never selects legal authority.
3. Authority attaches to versioned jurisdictional text/member/set.
4. Co-authentic peers remain peers absent jurisdictional precedence.
5. English may aid UI/indexing but is not universal legal authority.
6. Existing namespaced status/refusal owners are reused.
7. `stale`, `superseded`, `withdrawn` remain distinct in human/machine output.
8. Translation and adaptation remain separate decisions.
9. Three falsifiers remain red-first beyond parity.
10. Zero holders remain representable and block only governed purpose.
11. History is append-only; invalidation does not rewrite it.
12. External practice remains evidence, not repository capability.

## Verdict-Lift Conditions

Lift aggregate `GO_WITH_REVISIONS` to `GO` only when:

- A01–A10 close with the evidence above;
- **every fix appears in every defective package artifact**, not only a ledger/appendix;
- current locale census is independently executed and attributable;
- package remains research Markdown rather than prematurely implementing capability;
- re-audit has zero blocking and zero material findings;
- exactly one conforming W4 tuple is published, separate from audit verdict;
- C01–C04 survive;
- principal links/source spans resolve;
- complete package inventory shows no undeclared artifact/path regression.

## Conditions That Force NO_GO

Any one forces re-audit `NO_GO`:

- non-member/audit-verdict token remains in a standing field;
- historical or supplied census is labelled current/recomputed;
- finite fixture passage is presented as universal equivalence proof;
- informative translation is promoted by score, certificate name or UI locale;
- co-authentic law is forced through English fallback;
- Stage 3 creates a parallel status/refusal lattice;
- vacant high-stakes role silently passes, self-appoints or globally blocks unrelated functions;
- generic lane is presented as owner;
- correction exists only in a revision ledger while defective artifact remains;
- unauthorised source/workflow/`AGENTS.md`/pattern/binary/staging edit appears;
- amendment ancestry or exact delta cannot be enumerated.
