## 3. Gate §1.2 — bidirectional seam adjudication

### 3.1 Adjudication vocabulary

- **direct_match** — the opposite side delivers or can bind the same semantic obligation.
- **naming_difference** — the obligation is present but expressed through a different semantic decomposition.
- **scope_allocation** — the item is intentionally split: one task supplies semantic content and the other supplies proof/custody construction.
- **real_gap** — neither side supplies nor correctly allocates the obligation.
- **correctly_out_of_scope** — the item belongs to a named external dependency and is not required to be invented by either task.

The lists are intentionally asymmetric: INT-R7 asks what INT-R8 must produce; INT-R8 asks what INT-R7's proof must bind.

#### Dynamic verifier status test

A solver status such as `timeout` is a dynamic execution result. The two sides mean the same thing only under this bounded reading:

1. the artifact binds the exact model/rule versions, inputs, transcript head, completeness disposition, solver/evaluator identity as applicable, and returned disposition;
2. the retained evidence is sufficient to reproduce or challenge that historical evaluation offline;
3. `timeout`, `unsupported`, `empty`, and `unproved approximation` remain non-positive historical outcomes;
4. a later exact evaluation is a successor evaluation over an explicitly related evidence state, not a retroactive rewrite of the old result.

INT-R8 requires those reproducible inputs and prohibits a status-only pass. INT-R7's disconnected preservation profile supplies the authenticated evidence closure. There is therefore no semantic mismatch.

**Adjudication:** direct requirement match; construction not established. Every future candidate proof remains obliged to falsify the metadata-oracle attack. Failure by a concrete candidate would block that candidate, not reopen the abstract seam automatically.
