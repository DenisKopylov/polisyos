## Capability-chain reality check

Across the wave, research contracts and candidate schemas exist. No package supplies the complete
chain:

```text
typed contract/artifact -> producer -> persisted event -> orchestration bridge
-> consumer -> verification -> audit/API/dashboard surface -> negative/e2e semantic test
```

The controlling package label is `absent/unallocated`. Missing prerequisites include producers,
artifacts, bridges, consumers, verification and semantic tests, but no stronger typed capability label
is assigned without a separately named admitted sub-capability. Calling any package `contract_only`
would be too strong where no admitted runtime type exists.

## Consolidation non-effect

appoint an owner, allocate an institution, authorize a policy action, open a public-signature gate or
change any package artifact. Only the human principal may ratify the separately presented candidates.
