### 2.1 Canonical arithmetic now carried

The revised derivation is:

```text
alpha_{s,t}
  = delta_s
    * expanded_class_weight(q_{s,t})
    * schedule_mass_s
    * (76614/126025)
    / (t+1)^2
```

with `max expanded_class_weight = 3/20`, so

```text
sum_t alpha_{s,t} < delta_s * schedule_mass_s * 3/20.
```

An exact three-member mass-one family is below `(9/20) * delta` under the named maintained
assumptions. The arithmetic is a theorem, not a live owner projection.
