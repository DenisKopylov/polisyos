## `P37` predicate register

| Gate predicate | Required construction | Failure behavior |
| --- | --- | --- |
| item semantic validity | registered vocabulary applied by an independent verifier | item `invalid`; no scoring |
| scenario fact integrity | packet/manifest digest and replay | item `invalid` |
| action admissibility | pre-sealed policy source and adjudication record | `contestable` or excluded |
| accessible equivalence | propositional-relation parity, not node count | modality/item `invalid` |
| operator comprehension | real scored terminal action on frozen target | remains `not_established` without a run |
| high-confidence threshold | appointed governance rule | publish the threshold curve only; no autonomous gate |
| capability promotion | admitted contract, producer, event, bridge, consumer, verification and surface | remain `absent/unallocated` |

Every condition introduced to preserve a positive becomes a gate predicate. For example, “screen
reader equivalent **if** all strings are present” creates a new predicate; string presence is not the
relation-equivalence property and cannot preserve the positive.

## `P38` divergent cases

### 1. Staleness marker versus refusal behavior

- **Property:** the operator refuses stale evidence for a currentness-dependent act.
- **Cheap implementation:** test that a `STALE` badge exists.
- **Divergence:** the badge is rendered and announced, but the operator selects the stale datum and
  commits. The marker passes; the property fails.

### 2. Weakest-link marker versus chain semantics

- **Property:** the operator understands that one blocking link controls the overall posture.
- **Cheap implementation:** verify that the blocked component is red and appears in the DOM.
- **Divergence:** the operator names it but averages the chain and presses `PASS`.

### 3. Accessible atoms versus conditional relation

- **Property:** conditional δ meaning survives the accessible path.
- **Cheap implementation:** all number and rider text nodes exist in the accessibility tree.
- **Divergence:** the reader encounters them in different groups after the action control and never
  binds them.

### 4. Hard stop versus comprehension

- **Property:** the operator understood why the act was prohibited and chose the safe route.
- **Cheap implementation:** prohibited commit cannot be completed.
- **Divergence:** every participant attempts the prohibited action and is technically blocked.

## Pass conclusion

No pattern requires an architect stop at stage 1. This package does not establish actionability and
therefore does not contradict the demonstrability ruling. A real run showing systematic
non-actionability of the canonical typed-refusal pattern would meet the prompt’s stop condition and
require architect adjudication rather than a cosmetic design workaround.
