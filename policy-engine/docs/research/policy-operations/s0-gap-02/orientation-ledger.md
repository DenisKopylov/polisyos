This is the amended Pass-I orientation ledger. That delivery-provenance correction does not change the original content digests.

| `exact_ref_read` | The named file/range was read at the stated pin. |
| `bounded_concept_sample` | A predeclared finite set was read and judged; it supports only that denominator. |

### 3.2 Reproducer

The controlling complete-walk shape is:

```bash
PIN=109ba3f44e09e0d34cf49ae19aa25ba4048ee3ee
for token in benchmark evaluator oracle; do
  py_files=$(git grep -I -l -F "$token" "$PIN" -- 'policy-engine/src/**/*.py' | wc -l)
  all_files=$(git grep -I -l -F "$token" "$PIN" -- policy-engine/src | wc -l)
  lines=$(git grep -I -n -F "$token" "$PIN" -- policy-engine/src | wc -l)
  occurrences=$(git grep -I -h -F "$token" "$PIN" -- policy-engine/src \
    | awk -v t="$token" '{n+=gsub(t,t)} END{print n+0}')
  printf '%s py_files=%s all_files=%s lines=%s occurrences=%s\\n' \
    "$token" "$py_files" "$all_files" "$lines" "$occurrences"
done
```

The counts in §3.1 are architect-supplied complete-walk results. This amendment does not claim that the original research process executed the command.

## 6. Orientation conclusions

1. **The inherited 183/80/44 figures are reconciled.** They are correct Python-only matching-file counts under path denominator `policy-engine/src`, case-sensitive fixed-string content matching, binary excluded. The all-source/line/occurrence denominators are recorded separately.
2. **The researcher’s original refusal remains a commendable P35 result.** An unstated file-type denominator could not be reconstructed from ranked search, so `not_established` was correct in that environment.
3. **The census proves vocabulary density, not semantic ownership.** The supportable repository statement is: **no eligible independent custody oracle was established by the complete OPS-R15 evidence chain and the bounded three-owner sample.** The universal alternative—that the tree contains no independent oracle of any kind—remains unsupported because token counts cannot classify every module’s semantics.
4. **The bounded 3/3 sample is correctly characterized.** In particular, `grounding_benchmark.py` imports product admission/relation/phrasing code and exposes expected-answer fields; it is positive evidence of the prohibited pattern, not a candidate verifier.
5. **P27/P28 do not win by default.** Canonical-owner discipline governs product facts and diagnostics; `S0-K14` requires answer-producing verification outside product semantic provenance. The amended `P37` gate prevents neutrality or adequacy from being supplied merely by declaration.
6. **No score, unblock, or capability claim follows.** The evidence establishes an architecture need and boundary only.
