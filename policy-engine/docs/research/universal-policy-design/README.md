# Universal Policy Design Research

This directory contains research material for the universal policy design
architecture. Treat these files as design evidence and rationale, not as
runtime contracts. Capability claims still close through committed architecture
records, producers, validators, and semantic tests.

## External foundations

[Открытый атлас внешних оснований](external-foundations/README.md) связывает
универсальное видение PolicyOS с содержательными основаниями, их поиском,
композицией, обучением и наблюдаемостью. Содержит открытые семейства и начальные
primary-source cards; это research proposal, не runtime authority registry.
