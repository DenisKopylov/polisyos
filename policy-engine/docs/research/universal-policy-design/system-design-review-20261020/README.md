## Граница применения

Атлас внешних оснований пополняется непосредственно по разрешению пользователя. Для изменения SDD требуется отдельное решение; согласование от 21 октября разрешило именно перечисленные дополнения, включая target choices B07/C01/C02. Оно не является code acceptance, evidence admission или finding closure.

Перед применением сверены все 20 исходных SDD hashes. Неприменённые коды и исторические draft разделы сохраняют свой standing. Первоначальная карта и receipt описывают свой исходный срез, а не файлы после принятия; новые архитектурные изменения по-прежнему требуют отдельного согласования.

Исследование охватывает все tracked файлы указанной директории на исходном срезе. Оно не проверяет полноту реализации или текущее production состояние. Исторические implementation claims читаются с их исходной датой и scope.
