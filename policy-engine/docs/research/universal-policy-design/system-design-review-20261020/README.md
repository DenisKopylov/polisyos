## Граница применения

Атлас внешних оснований пополняется непосредственно по разрешению пользователя. Этот пакет устроен иначе: для каждого изменения SDD нужно согласование. Подготовленные файлы не импортируются в runtime, не регистрируются как принятые решения и не меняют действующие authority/status/closure semantics.

При последующем согласовании проверяется исходный hash каждого затронутого файла. Если документация изменилась, предложение нужно сверить с новым состоянием, сохраняя решения и правки других авторов. Согласование текста как design proposal не ратифицирует новые инварианты, не назначает институционального adjudicator и не принимает код.

Исследование охватывает все tracked файлы указанной директории на исходном срезе. Оно не проверяет полноту реализации или текущее production состояние. Исторические implementation claims читаются с их исходной датой и scope.
