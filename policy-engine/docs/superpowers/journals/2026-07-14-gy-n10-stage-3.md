## What landed

### Thin recursive router and plain-language bridge

- `runtime/quality/recursive_generation_cycle.py` owns only routing, depth/node/cycle budgets,
  strict persistence, branch identity checks, terminal folding, and the GY-G caller census.
- `runtime/http/services/control/generation_cycle.py` compiles plain language through the existing
  `DesignProblem` compiler and calls the recursive owner. Production selects the default recursive
  controller; the explicit contract-testing constructor remains stamped non-authoritative.
- Recursion and composition authority remains in `RecursiveDesignGraph`, `SubDesignContract`,
  `CompositionCertificate`, `compose_subdesigns`, and the canonical N5/N6 controllers.
- The caller-selected model id is carried into the leaf N6 owner. No method/model default is pinned
  in the router.
- A supplied `CycleSubstrateContext` must be consumed by every contract-testing leaf controller or
  the run refuses `recursive_contract_testing_context_not_consumed`.
- Persisted runs re-verify graph topology/hash, problem-by-node bindings, leaf N6 runs, N5 atom
  problem refs, N5-to-certificate pairing, certificate parent binding, leaf and parent terminals,
  root terminal, budgets, and content hash. Cross-branch transplantation, missing subdesign
  denominators, and recomputed-hash tampering are negative tests.

The Scientist `BudgetState` owner is exposed through the existing lazy root facade. Both new
runtime modules type against `polisyos.scientist`, not a deep engine module. This is a facade export
of the existing owner type, not a new budget contract.

  cached owners, and the existing read-only production-data mounts.
