# GY-DEF6 — discovery provenance and N8 denominator journal

Task: `GY-DEF6`, registered in
`docs/plans/active/layer3-slices/GY-engine-subordination.md` Rev 28.

Base: `90e20d31e89ca1d8d70a2a45d2c573d0ebfc8b25`.

## Scope and outcome

The repair makes the governed N8 method denominator a function of a controlled, manifest-bound
builtins-only registry. Entry-point and development-scan discovery remain visible as a separately
bound ambient member, but they are excluded from the governed count and snapshot. An environment
with an additional plugin therefore keeps the same governed denominator and either reproduces the
same declared ambient manifest or fails with named provenance mismatches. It cannot silently move
the count.

This is the narrower alternative explicitly allowed by the defect row. The implementation also
extends the canonical discovery and registry owners with reusable provenance/admission primitives.
It does **not** claim that every governed catalog consumer has adopted those primitives. The P31
census below names the live siblings that remain open.

Capability state at the implementation boundary is `implemented_but_not_orchestrated` until the
N8/N10a reissue and E12 replay complete. The final state and terminal receipts are filled after the
one permitted expensive wave.

## Design decision: governed builtins, separately bound ambient discovery

### Why the full-manifest alternative was rejected

The measured one-method difference is the editable entry-point distribution
`polisyos-foundry-method-example==0.1.0`, contributing
`example.summary.weighted_average@1.0.0`. Both installed entry-point distributions in this
worktree are editable. Distribution name/version, `entry_points.txt`, and `direct_url.json` can
identify the installation declaration, but they do not close the loaded factory's Python source,
transitive imports, data files, dynamic factory inputs, or backend runtime. Labelling that metadata
as a complete source-byte manifest would repeat P37 under a more impressive hash.

The canonical discovery manifest therefore records entry-point distribution metadata while
labelling entry-point source-byte closure `not_established`. Development scans bind each declared
root and every contributing `components.py` byte, but label transitive import closure
`not_established` when a development file contributes components. Missing declared roots and
entry-point enumeration errors are explicit unbound inputs.

For N8, the governed registry uses only the canonical builtin loader, with entry points and the
development scan disabled. Its source policy, component membership, admitted registry content,
catalog membership, per-entry runtime bindings, backend fingerprints, package versions, and Python
runtime identity are bound. A second ambient discovery pass is recorded but has
`included_in_governed_denominator=false`; unbound ambient members are quarantined. This keeps the
denominator reproducible without pretending arbitrary extension code has a closed import graph.

### Canonical owner and admission seam

The repair extends, rather than bypasses, the existing owners:

- `discover_components` produces `ComponentDiscoveryManifest` on the existing `DiscoveryReport`;
- `bootstrap_foundry_method_registry` returns that manifest with one atomically frozen registry
  membership/content binding;
- `ensure_all_methods_registered` returns the canonical bootstrap report instead of discarding it;
- `build_method_catalog_snapshot` accepts that admitted report, checks membership and stable
  registry content, and can require bound discovery without re-running ambient bootstrap;
- `build_method_catalog_provenance_manifest` binds governed discovery, quarantined ambient
  discovery, and snapshot-owned runtime/backend identity;
- the N8 producer constructs its denominator exclusively through those owners.

Operational plugin discovery remains tolerant by default. Governed consumers must opt into the
strict admission seam; this preserves existing extension behavior while giving authority-bearing
artifacts a fail-closed path.

## Predicate provenance (P37)

Every predicate admitted by the N8 denominator is frozen in the persisted provenance rows. The
consumer compares the full row set and the explicit admission policy against live recomputation.
It also derives the complete set of denominator fields at runtime and requires every field other
than the provenance container to map to one or more named predicate rows. A future denominator
field without a binding therefore fails `catalog_predicate_binding_coverage_mismatch`.

| Predicate family | Classification | Decisive? | Fail-closed behavior |
| --- | --- | ---: | --- |
| Governed source policy (builtins on; entry points/dev scan off) | `recomputed` | yes | Reject. |
| Governed entry-point enumeration/distribution/source closure | `recomputed` for the empty declared sets | yes | Reject any unbound row or source-policy change. |
| Governed development roots/bytes/import closure | `recomputed` for the empty declared sets | yes | Reject. |
| Governed duplicate precedence and component membership | `recomputed` | yes | Reject. |
| Frozen registry membership/content equals governed manifest and catalog | `recomputed` | yes | Named rejection before catalog use. |
| Ambient discovery exclusion from governed registry/catalog/value selection | `recomputed` | yes | Reject a false admission policy; unbound ambient rows remain quarantined. |
| Catalog/registry denominator equality and content identity | `recomputed` | yes | Reject. |
| Two-snapshot repeatability | `recomputed` | yes | Reject before returning a denominator. |
| Value-capability owner reconciliation and FQN-set hash derivation | `recomputed` | yes | Reject. |
| Evaluation-mode, identification-status, and native-family taxonomies | `recomputed` | yes | Reject incomplete or drifted bases. |
| Ambient entry-point group enumeration | `recomputed` when enumeration succeeds; otherwise `not_established` | no | Quarantine; manifest mismatch fails N8 recomputation. |
| Ambient distribution identity | `recomputed` when metadata is present; otherwise `not_established` | no | Quarantine. |
| Ambient entry-point source-byte closure | `not_established` for arbitrary factories | no | Quarantine; never enters governed denominator. |
| Ambient dev-root membership and contributing file bytes | `recomputed` when present/readable; otherwise `not_established` | no | Quarantine and named mismatch. |
| Ambient dev transitive import closure | `not_established` when a dev file contributes | no | Quarantine. |
| Ambient duplicate precedence/component membership | `recomputed` absent discovery errors; otherwise `not_established` | no | Quarantine. |
| Runtime package versions, Python identity, entry runtime targets and backend fingerprints | `recomputed` | yes | Reject missing policy-engine identity or live mismatch. |
| Recorded/live provenance equality | `recomputed` by the N8 consumer | yes | Reject with field-specific provenance code; count drift is secondary. |

The admission table accepts only `recomputed` and `independently_reconciled`. A
`consumer_asserted`, `institutionally_supplied`, or `not_established` decisive row fails closed;
nondecisive ambient rows must carry `reject` or `quarantine`. Parameterized tests falsify each of
the last three labels while preserving the row shape and prove rejection.
