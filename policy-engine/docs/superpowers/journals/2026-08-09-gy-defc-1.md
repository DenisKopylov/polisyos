        if not isinstance(node, ast.Call):

## Design decisions (frozen before repair)

### Consumed-set owner

Extend `runtime/quality/authority.py`, which already owns `SameInputClosure`, rather than creating a
parallel consumed-set module. Discovery remains an upstream producer of a typed manifest. The
authority owner admits the complete set: source closure, ambient/process environment, durable
authority history, resolved artifact bytes, runtime ABI, and generic loader-owned callable slots.
Each member carries its identity and predicate-provenance class. Sealing requires exact sorted
membership; use requires re-resolution and exact identity. Missing, unbound, or substituted members
fail with a named member code.

The existing N13b cache fence becomes a consumer of the sealed set rather than a second owner.
Both confidence-ledger session modes use the same live-code admission. Frozen N10/Depth producers
receive the non-authorizing verification session explicitly; production authority keeps the
durable `from_repo` path.

### Canonical-projection owner

Extend the existing artifact algebra in `pdc/_impl/gy_waist.py`. Writer and every verifier obtain
the same canonical comparable form. Pairwise reconciliation first proves equal semantic
projections and identical structure, then preserves only operational leaves already present on both
sides. It never manufactures a missing leaf. Added/removed leaves, shape changes, and semantic
changes remain named failures.

GY-DEF7 and GY-DEF10 close only when the N10a writer/audit and Depth-N writer/admission are the same
owner call. The ten exact self-hash sites and the alternate projection census must either consume a
canonical artifact projection or be classified as a distinct artifact/API projection; no call site
may choose equality by spelling a local exclusion set.

### No semantic movement

No repair may change a governed denominator or semantic value. Operational values may be projected
or preserved only after independently recomputed semantic equality. The artifact wave is one
ordered reissue after source freeze, never a rebaseline.
