# Execution journals

Maintenance route: team-devx / owning product teams.

Keep one concise completion account per task with deciding commands, actual exit statuses, limitations and routed findings. Cite tracked inputs as path@revision. Retain complete large command output under a locally ignored raw directory and bind it by hash; do not duplicate derivable source inventories in prose.

Owning entrypoint: `CONTRIBUTING.md`.

This local document explains the directory role. Its presence does not certify the contents or close a product capability.
