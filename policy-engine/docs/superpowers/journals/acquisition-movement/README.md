# Acquisition movement journal

This directory contains the staged acquisition-movement research journal, including
positive, refusal and outlier probes. `STAGE1.md`, `STAGE2.md` and `EVIDENCE.md` explain
the recorded stages; the Python probes are reproducible research inputs, not product
runtime entrypoints or authority by themselves.

Treat each result as bounded to its recorded inputs and source. Current product behavior
must be checked in the canonical implementation and tests.
