# Refusal-expansion construction rule (no official outcomes)

The new diagnostic exercises the existing CG1 relation engine and CG2 binder.
It changes no production owner and does not revise the frozen 2026-09-08 frame,
suite, report, or journals. The complete held inputs remain the original
assignment frame, its owner-derived atoms, and the exact Core-verified proof-world
snapshot. The executable declaration will pin their existing paths, byte/blob
identities, logical hashes and current owner versions before the official run.

The complete raw-source census is `input-census.json`; it enumerates the whole
frame input array, whole raw knob dictionary object, whole WMR policy-slot array,
and whole frozen mismatch array. Direct nested enumeration and an independent
Cartesian product minus the actual assignments agree on identity sets. This is
algorithmic reconciliation over shared sources, not independent evidence.

## Proposed complete construction

1. Preserve every original opposite-sign construction. Start from the existing
   owner's original assignment atom and change only its categorical sign.
2. For every original assignment, substitute every other held WMR slot. Preserve
   its L6 knob identity, original operator parameters and intended outcome;
   update the target-bearing fields and use the existing owner's target unit,
   scope and population projections. This does not assert that the substituted
   target is a supported intervention. Its known mismatch is with the held L6
   assignment, not with independently adjudicated causal or legal truth.

The official construction therefore contains all 48 executable negatives from
`input-census.json`: 3 sign reversals and 45 target-assignment transpositions.
The 3 original matched controls remain outside that negative denominator.
The declaration also records the existing owner's complete source-cluster
partition; sharing support is not independence.

An optional exploratory magnitude-grid proposal was rejected before declaration.
`owner-intake-corrected.json` executed the complete original assignment-atom intake
and reconciled its identities with the frozen suite. Every numeric leaf was an
operator-domain bound; no original effect magnitude exists in those typed inputs.
The proposed 96 magnitude coordinates are neither user-required cases nor members
of the official denominator. They have no residual implementation home beyond
this rejected proposal and its retained measurement. No bounds or units are
invented, and no magnitude/tolerance coverage is claimed.

No admission, solver outcome, refusal reason or accepted-binding label chooses
the set. No post-execution exclusions, replacement cases or tuning are allowed.
Identical normalized proposal signatures within a family are rejected as duplicate
constructions rather than counted again. The existing opposite-sign-only
`DeclaredRefusalSuite.v1` is unchanged: the larger research matrix is a separate
diagnostic declaration, never a claim that the old typed suite accepted new
transforms.

## Deciding properties

Every original assignment gets an unchanged matched control outside the negative
denominator. Its real CG1 relation must remain exact or certified specialization;
its synthetic CG2 output must grant no governed authority. A refused positive
caused by the missing production calibration is not a correctness label.

Sign cases require a contradiction on the sign axis against the predeclared
source atom, actual solver satisfaction for the coherent proposal, and the real
CG2 reason `false_analog_hard_abstain`. Assignment cases require actual CG1 UNSAT
with the source-specific knob/target contradiction and CG2
`relation_not_bind_eligible`. Other refusals remain reported but do not count as
successful detection of the intended mismatch. Every result and diagnostic
artifact is explicitly synthetic.

The run records all outcomes, complete identity-set hashes, counts and deltas.
It does not copy tracked inputs or whole derived source sets into audit artifacts.
Every location displaying a refusal ratio includes the full limitation:

> A high refusal rate on constructed mismatches is not evidence that accepted bindings are correct.

All probes share the held source population. The target and sign families test
different failure mechanisms, not independent correctness evidence.
Correctness bounds, legal truth, causal correctness and independent adjudication
remain `not_established`.

## Falsifiers and scope

- Before the official baseline, run the unchanged new diagnostic with the real
  sign comparison removed in memory, leaving declarations and markers intact.
- Remove both existing views of target assignment in memory: the L6 target
  equality supplied by `_knob_target` and the hard check supplied by
  `_knob_maps_to`. Keep all proposal markers and matched controls. A fallback
  refusal cannot satisfy the source-specific UNSAT requirement.
- Remove the actual binder critical-contradiction guard. Sign sensitivity must
  fail even if calibration later refuses the same proposal for another reason.
- Corrupt one decisive field in the new saved result, run the actual independent
  checker, require drift failure, and restore the exact new artifact bytes.
- Change or omit a declared identity without updating its source set: complete
  declaration rederivation must refuse it.

The independent checker takes its replay time from the separate retained original
writer capture and compares both saved and recomputed complete outcomes with that
emission. A timestamp edited only in the saved artifact cannot choose its own
replay time. This corroborates local run chronology; it is not an external time
authority or independent scientific evidence.

No production source is patched on disk. Any discovered owner escape is recorded
and routed; the closed A/B/C2 mechanisms are not repaired in this workstream.
This adds a diagnostic, so no production default or legacy path is replaced.
P27/P29/P35/P37/P38 govern the owner, denominator and decisive refusals. The
different target examples are one P40 failure class, not independent findings.
