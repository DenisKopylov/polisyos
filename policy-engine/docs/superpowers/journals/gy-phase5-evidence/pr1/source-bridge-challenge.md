   returning a reference. This is not a missing appointment. It is the concrete
   `claim-explicit-evidence-axis/B1-B2; historical-cohorts/HC-F11-HC-F14` forwarding
   boundary. Replacing it with a scoped L6/WMR view or reconstructing historical
   confidence would bypass that boundary.

   retained recording array in `stage3-n4-recorded.json`. Its successful result
   contract does carry atom/proposal provenance; its present terminal result
   cannot carry candidates by its own strict validation.
3. **N6 does have a nonempty fallback source**, which this challenge executes
   rather than incorrectly reporting zero generation. The actual grammar fallback
   produces search candidates from the actual problem lever set. Its atom has only
   intervention ID, content hash, target slots, fallback WMR reference and status.
   Every resulting object fails the real `InterventionAtomBinding` validator on
   substantive missing fields (operator, direct effect, do-expression, estimand,

   any source persistence; the missing reference raises
   `effect_credal_reference_missing`. A carrier that invokes it with the current
   missing source adds no deciding property. Its existing source schema requires
   the resolved L6, CG1 and reference replay records, so accepting a different

   when actual producer inputs exist; it is not permission to manufacture an
   admitted batch or call the protected promotion evaluator on an unadmitted
   candidate. Source preservation would therefore need an explicit evidence-stage
   method of the existing owner before admission, separate from promotion authority.

The deciding missing quantity is an actual owner atom/proposal **and** a forwardable
reference, not a positive N8 result or a complete promotion. Present N6 fallback
