# S3 decision proposal for the lane plan

Source: S3-R01–S3-R12 in `findings.md` and exact run records beside it. No production change is authorized by this file alone; root incorporates the decisions into the stage-2 lane plan and commits it first.

## Decisions

1. **Manifest projection remains with the live route owner.** Extend `src/polisyos/runtime/quality/intervention_substrate.py`. Reuse `ObservationToContractManifest` from `ir/observation/bundles.py` where typed schema parsing is needed; reuse `_manifest_route`, `_route_contract`, `_assert_compiled_contract`, and real registry resolution. Do not add nested `routes/target_contract` parsing to `advisor.py`. The projection is derived from the complete bundle/manifest and requested observation family, and carries its real route identity/hash plus the registry-resolved allowed methods. It must represent blocked/malformed/ambiguous/unknown families explicitly, not silently omit them. A runtime projection is candidate method-routing evidence, not an independently signed legal or effect certificate.

2. **N8 consumes an explicit owner constraint.** `generation_cycle._select_value_method` owns the runtime bridge and invokes the route owner before the Foundry selector. `advisor.select_value_method_for_problem` consumes the projected constraint using its existing registry/catalog owner; it must validate the constraint's method identities against the real registry and preserve native value-output eligibility. Raw nested manifests arriving at the selector without the owner projection fail closed rather than becoming empty hints. Requested methods outside the allowed route are refused. The selector context binds the full effective route projection, so a content-relevant route mutation changes its receipt even if the final method remains equal. A route whose methods lack value-output capability returns an explicit blocker; do not broaden native eligibility to fake 4/4 success. The real method-route denominator remains intact in the report, separately from its N8 value eligibility.

3. **N4 consumes the same route owner.** Replace the S3-input family-count projection in `design_generation.rank_shadow_candidates_with_graph_causal_surrogate` with validated owner routes. Remove/subordinate `_observation_manifest_families` as a live route-validation source. Preserve N4's candidate-only `promotion_allowed=False` semantics. This is S3 consumer wiring into the existing N4 function, not a reopening of other executed GY-N4 work. Unknown/invalid route data cannot earn a routing score bonus or `search_guiding` on the basis of names alone. Do not truncate the complete owner route set in the evidence surface.

4. **Law trace is candidate evidence until correspondence is established.** Keep real knob and law identity sets, owner atoms, threshold/provision resolution and temporal/numeric evaluation. Extend existing `LawLeverResolution` in `intervention_substrate.py` with an explicit typed mapping-admission predicate and an empty independent-mapping-evidence slot. Freeze `consumer_asserted` for current tracked declarations; use `not_established` where no correspondence declaration resolves. Current `legal_threshold_evaluation.status=admitted` is preserved as the result of evaluating that threshold, but it cannot set law-level `status=admissible`. The overall output is blocked with a precise mapping-correspondence reason. Do not implement a positive independent-mapping producer without finding one to reuse; do not accept metadata, a confidence value, self-issued verifier strings, or a caller-supplied True as a positive. An empty slot alone is not a new capability claim. This closes current false authority and preserves trace work; it does not establish the missing accepted semantic correspondence conjunct.

5. **Version changes follow the exact changed semantics.** Current measured epochs: `policyos.runtime.intervention_substrate_lift.v1`; report `policyos.policy_design_case.layer3_gy.intervention_substrate_contract.v1`; `policyos.foundry.method_selection_context.v3`; receipt `policyos.foundry.method_selection_receipt.v2`. Law output semantics and new receipt fields require **lift v1→v2** and **report v1→v2**. Route-bound selector context requires **context v3→v4**. Preserve receipt v2 if its shape and authority labels stay unchanged and it merely binds the new context; if implementation needs a new `owner_manifest_route` authority label or explicit route receipt field, bump **receipt v2→v3** and preserve old v2 reading under its own rule. Do not bump N9 epochs for this task unless N9 obligation records actually change. Do not rewrite the tracked `l6_owner_authority_bindings.v1` declarations into fabricated correspondences. Existing v1 artifacts remain readable as historical/candidate records and cannot silently acquire v2 authority. Native law-free candidate flows must not be blocked merely by loading a historical bundle.

6. **One recomputing S3 contract closes the consumer boundary.** Extend `intervention_substrate_behavior_report` and `check_layer3_gy_intervention_substrate_contract`, retaining every existing real input case and every decisive owner-negative. Add actual N8/N4 consumer calls, independent full identity checks, real-but-unrelated law-target transposition, data-only new routes, unknown and malformed inputs, explicit-request bypass, and in-memory owner-validation removal. Retain the candidate-law free-grow outcome as a valid trace with explicitly blocked authority; do not describe it as admissible. Regenerate only the S3-owned artifact with its writer, then corrupt a decisive field and prove `--check` red before restoring the writer's bytes.

7. **Default changes have run-emitted StrangleReceipts.** Persist receipts in the S3 report for (a) raw/flat manifest ignored-or-hint-only N8 default → owner-projected route constraint by default; (b) N4 family-name-count route bonus → owner-validated routes; (c) threshold-pass-implies-law-admissible → correspondence-gated authority with candidate trace retained. Use the existing strangle artifact conventions (`predecessor_ref`, `replacement_ref`, `default_before`, `default_after`, `remaining_callers`, disposition, verifier, content hash), owned by this report. Recompute the full source-call denominator via AST for predecessor calls and execute the real negative/default paths; marker-only scans are insufficient. Any intentional legacy reader is explicitly historical/candidate-only; no parallel positive default remains.
