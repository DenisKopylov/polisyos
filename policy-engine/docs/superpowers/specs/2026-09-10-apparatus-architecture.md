## Decision and scope

A completed measurement must describe the artifact at the selected source tree.
Building an environment is a prerequisite, not a finding about that artifact.
The existing producer/checker chain remains authoritative: compose its canonical
owners, repair environment creation, and distinguish an unrun measurement from
an artifact rejection at the CLI boundary. Do not introduce a new generated
artifact registry, alternate generator, permissive comparison, or station cache
that can establish freshness.

## Error algebra and boundaries

The check has three meanings, not two: completed and clean (0), completed and
artifact-invalid (1), or incomplete/unrun (2). Preserve the existing ordinary
`GuardrailViolation` for artifact facts only. Introduce a narrow typed exception
or equivalent typed outcome in the existing module for unavailable measurement:
phase, affected family identities, command diagnostic and any partial observed
artifact findings. The CLI catches it, prints a conspicuous `UNRUN` headline,
identifies measurements that were not completed, and exits 2. Partial observations
must never be followed by the complete 'passed' or ordinary complete 'FAILED'
headline. An exception exemption must not waive an unrun required check.

A child generator returning nonzero has not emitted an admissible complete
candidate, even if a partial output happens to exist. Do not compare that output
and infer drift from it. Preserve actual stdout/stderr and classify producer
failure as unrun. Missing generator executable, failed private setup, and copied
source creation failures are the same execution-availability class at different
boundaries. A declared output omitted by a successfully completed generator,
unregistered output, escaped write, or mismatched byte is instead a measured
artifact violation. Test these mixed outcomes explicitly.

The optional `--all-generated-checks` branch invokes heterogeneous older check
commands, which lack a shared completion protocol. This work does not invent
one from exit codes or parse arbitrary tracebacks as authoritative status. Its
legacy optional results remain outside the default-freshness repair claim; the
journal must name any observed limitation. Explicit `--skip-generated-checks`
must announce the omitted scope, not claim a complete freshness verdict. The
normal invocation remains fully enforcing.

Schema import/generation failures similarly must say UNRUN with non-drift exit
status; do not turn exceptions into a stale-schema list. Preserve the optional
ABI entry policy, version-header provenance and full selected-model traversal.
Reject vacuous selection in check mode or clearly declare its scope if no model
can be measured. Do not modify the schemas to make an unavailable import pass.

## Shared effects and scheduling

Root serializes all commits, pyproject/lock/lefthook changes and all `architecture/`
writes. Workstreams A (this one), B (dashboard), C (station/CI) run concurrently
at most. Shared Python provisioning and the full Vitest/browser resource are
serialized; source readers and bounded Python logic tests may run alongside it.

The replacement private venv changes every lane's default guardrail invocation:
working managed Python replaces an abort; uncached dependencies may download;
unavailable provisioning becomes exit 2. Dependency requirements and freshness
comparison strength stay the same. Workspace pnpm install remains the declared
Node bootstrap; a missing required tool is an explicit unrun condition, not a
claim that generated bytes are wrong. Fresh witnesses execute this bootstrap
with an empty private store rather than symlinking another lane's node_modules.

The independent schema job adds a small separately provisioned CI job on push
and PR, not another broad unit suite. Aggregate success requires its success;
skipped, cancelled, missing or failed schema measurement cannot be accepted.
The original import/ratchet jobs continue to report their own reds. This prevents
those reds from censoring a schema witness without weakening either check.
No remote CI completion is claimed: this task explicitly prohibits push, so a
new hosted-run receipt is impossible here and is handed to the architect.

Station C's proposed default-dev test extra is a distinct shared dependency
change and is explained in its decision. No duplicate pytest dependency pins
will be introduced here. A fresh offline station lacking JAX cannot be repaired
by asserting Python path compatibility; network-backed bootstrap or a verified
artifact cache is required, and absent either it must remain loud/unrun.

## Pattern pass and stop property

P04/P05/P09: an unrun check cannot inhabit the completed artifact finding lattice.
P07/P08: source tree, lock, interpreter provenance and generated content have
different roles; headers cannot determine schema truth. P27/P31: extend existing
station and emission owners rather than adding per-family fixes. P29/P32/P33:
real execution and corrupt-field/removal probes, including sibling consumers,
not markers or command success alone. P35/P36: complete logs and exact finding
sets; historical prose is not an adequate inventory. P37: actual child execution
and byte comparison are `recomputed`; a handed result is
`institutionally_supplied` until replayed. P38 divergent case is now witnessed:
a private interpreter aborts while the API says one artifact finding. P39:
decisions, journal, raw receipts and generated companions are mandatory records,
not independent mechanism scope. P40: explicit class-first review. P41: baseline
is the task source c49449343, not a later cluster whose failures might be ours.

Stop on the property: default freshness completes in an independently provisioned
fresh tree, unavailable checks cannot be green or ordinary completed findings,
and identical invocation/tree/provisioning gives the same verdict across CWDs.
A product artifact can be honestly red; routing its cause cannot claim it green.
The journal will distinguish repaired apparatus, remaining artifact findings,
and hosted-CI evidence unavailable because this authorized task does not push.
