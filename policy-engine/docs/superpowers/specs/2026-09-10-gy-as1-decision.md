## Decision and epistemic boundary

Compose the delivered GY-AQ1 classifier, candidate intake, eight-dimension ceiling
owner, CAS persistence and recomputing receipt consumer. Add a contract-testing
reference demanding owner, a frozen acquisition corpus and an assurance instrument.
The instrument is a non-test program that actually runs every case through AQ1 and
checks its persisted observations against a separately authored sealed oracle.
The oracle never imports the subject, decodes the subject fixture format, calls its
loader, or reuses its comparison helpers. Its author receives the research property
requirements and the observation wire contract, not the subject's implementation.

This is software assurance over synthetic `contract_testing` evidence. It does not
appoint a relation adjudicator, mandate grantor, capacity assessor or assurance
institution. Neither a synthetic favorable proof nor the resulting test grade can
issue publication authority. AQ1's `authority_granted=False`, empty institutional
signer and candidate-only purpose remain observable in every admitted receipt.

The binding research is INT-R2 `AUD-F008`, amendment §4.3, and operational closure
§§4–6. `AUD-F009` bounds terminal knowledge; `AUD-F010` keeps substantive and
technical writability separate; `AUD-F011` prohibits human-decision/audit substitution.
The full builders-A decision and journal were read. Their claimed architecture-gate
prohibition is superseded by this lane's explicit instruction to run that gate.

types/four counts. Stage 2 will enumerate the entire committed corpus with two
independently written parsers and reconcile both family membership and stable IDs,
not only a total. The expected arithmetic is `8+8+12+16+8+8+3=63`.

The eight types, in the source union's order, are `grounding_relation`,
`estimand_binding`, `owner_writability`, `legal_mandate`, `normative_authorization`,
`implementation_capacity_evidence`, `competent_human_decision`, `independent_audit`.
The corpus contains full immutable synthetic input bundles plus its schema version,
research basis and per-case property/mutant bindings. No runtime expected-result
branch is selected by a `case_id`. Input materialization may consume fixture facts,
but expected answers live only in the separate oracle artifact. Content identities
seal corpus/oracle files; tampering must fail before a new favorable grade exists.
A separate ordinary data-availability positive control is outside the 63-case
non-data denominator and must close only after an admitted observation changes the
availability predicate, proving the instrument can observe an actual positive.

## Delivered AQ1 limitations and adjudication

AQ1's `NonDataReceipt.resolution_state` has no `deeper_terminal`, stale state or
event-id field. Its verifier/re-entry ports return booleans. AS1 must not widen
that closed task, invent that it already emits those research states, or relabel
a provisional AQ1 receipt into a terminal runtime receipt.

A new reference-adapter observation therefore carries **two separate facts**:
(1) the real persisted AQ1 disposition, and (2) reference terminal knowledge derived
from admitted synthetic boundary evidence. On both members of a deeper/provisional
pair AQ1 correctly remains `reentry_provisional_refusal`; only the independently
checked boundary-knowledge field differs. The deeper proof is never authority or
success and cannot bypass closure. The reference terminal classifier must verify
scope, current epoch, actual excluded alternatives and coverage, rather than read
a terminal flag. A forged full-coverage declaration with an unsearched alternative
fails. A general institutional terminal/custody API remains deferred to acquisition
custody composition, not silently delivered by an assurance fixture.

Likewise reference event processing verifies event subject/predicate, occurrence
versus evaluation time, material evidence, uniqueness and rule binding before
asking AQ1 to rerun. A duplicate adds no second acquisition effect; a late event
is retained as historical input and cannot make stale evidence current; a rule
change requires new verification while the old receipt remains replayable under
its old context. This reference adapter is an executable contract for those
research semantics, not a new Atlas lifecycle machine or a repair to CR1/AQ1.
The observations must name the event effect and actual re-entry-call evidence,
so receiving an event is insufficient to assert a successful rerun.

## Independence is enforced, then falsified

The oracle uses a separate tab-delimited expectation format and its own parsing
and comparison implementation. The subject uses JSON input decoding. No project
helper, subject decoder, fixture loader or observation comparator is shared.
The allowed shared surface is the documented serialized observation protocol:
case identity, observed classification/types, actual persisted AQ1 state,
reference boundary knowledge, reason, event/re-entry evidence, ceiling result,
authority and empty signer. Shared standard-library infrastructure is not a
shared domain decoder; the oracle must not use the subject's domain code.

The independent process starts with isolated import state. A read/import boundary
permits only the separately owned oracle source and sealed expectation artifact
from this repository; subject sources, corpus files, test helpers and alternate
oracle material are denied. Observations arrive on stdin. This is a capability
restriction exercised by attempted access, not a declaration of `independent=True`.
The grader recomputes the complete observed/expected ID correspondence, rejects
duplicates/missing/extraneous/unreadable rows, and reports field-specific divergent
reasons. Independent authorship and file identity are recorded as evidence; no
institutional verifier is appointed by a filename or owner string.

The binding removal probe replaces that independence with three actual dependency
attempts: shared subject decoder, shared fixture loader and shared comparison
helper. Each must turn the entire battery red at the boundary even if all numeric
answers would otherwise match. Separately change a semantic observed answer while
preserving all source/owner labels; the oracle must reject for the changed property.
If the access boundary is disabled, its own forbidden-read challenge must succeed
and the assurance instrument must refuse the resulting independence receipt.

## Seven exact mutants and their own falsifiers

| Exact mutant ID from AUD-F008 | Mutation and distinct deciding field/reason |
| --- | --- |
| `mutant.row_count_auto_closes_relation_estimand_mandate` | Replace missing-object refusal at nonzero row count with closure; protected rows fail `row_inflation_false_close`. |
| `mutant.form_or_signature_auto_admits` | Bypass substantive candidate verification while retaining valid-looking form; form cases fail `form_without_proof_admitted`. |
| `mutant.route_or_artifact_auto_closes_without_owner_reentry` | Receipt/route bypasses demanding recomputation; provisional or targeted re-entry case fails `owner_reentry_bypassed`. |
| `mutant.exact_membership_used_for_hierarchy_or_subset` | Replace the real semantic relation with equality; a legitimate narrower population/use fails `subset_use_refused`, independently of negative ceiling controls. |
| `mutant.timeout_or_silence_emits_terminal` | Convert missing boundary evidence after a timeout into terminal knowledge; provisional case fails `unproved_terminal`. |
| `mutant.surface_composes_authority` | Project a candidate process closure as publication authority; surface observation fails `candidate_authority_escape`. |
| `mutant.remove_property_keep_markers` | Remove non-closure enforcement while preserving case IDs, labels and oracle markers; missing-object case fails `missing_object_nonclosure_removed`. |

Mutants alter the executed subject path or its actual reference projection, not the
expected answer file. Each is independently invoked against the same frozen corpus
and every run retains its complete findings/exit status. The baseline must pass;
a mutant must fail with its designated field/reason, not merely crash or fail the
common fixture seal. No mutant run can be counted red from an import failure.
