## Standing check for the class

Decision: add the internal runnable module
`src/polisyos/runtime/quality/production_invocation.py`. It constructs a static
call graph from complete tracked source, tooling and test Python denominators,
and identifies newly introduced or regressed callable mechanisms with no
resolved call path from a non-test runnable root. The source acceptance set is
derived from definitions and the base delta, not a list of these five rows.
Definitions, imports, annotations and a call that merely constructs a class
must not be conflated with invocation of one of its methods. A helper whose
only caller is another unreachable helper remains unreachable.

| Mechanism | Production caller, written before implementation |
| --- | --- |
| Static parsing and call-edge resolution | `production_invocation.audit_sources`, called by `audit_repository` |
| New/regressed invocation assessment | `production_invocation.audit_repository`, called by `main` |
| Receipt emission / CLI refusal | `production_invocation.main`, reached by `python -m polisyos.runtime.quality.production_invocation --base BASE --receipt PATH` |
| Independent complete call census | Research `census.py.main` CLI; complete-source AST plus independent token cross-check, no product authority |
| Existing GY-C1 semantic verifier | `workflow_playbook_projection.admit_playbook_step` → `WorkspaceLoop.run_intent` → workspace served route / loop checker |
| Existing GY-C3 result verifier | `workspace.foundry_consumption` owner intake → `WorkspaceLoop.run_intent` → same runnable workspace roots |
| Existing GY-S3 selector verifier | `foundry.methods.selection.advisor.select_method_for_input_contract` → `_phase2_value_method_selection` → workspace loop |
| Existing GY-K extractor | `ir.analytics.literature.evaluate_openalex_claim_extractor_accuracy` → OpenAlex artifact checker CLI |
| Existing GY-L post-output GX verifier | loop artifact checker execution → `validate_outcome_run` → loop checker CLI |

The standing checker is a **bounded static regression instrument**. Its result
must say `static_path` rather than `wired`: a branch guarded by `False`, a callback
registry, reflection or runtime dependency injection is not proven by syntax.
It cannot certify persistence, institutional authority or gate substance; those
require execution and removal evidence. Resolve simple imports/aliases, local
functions, explicit class methods and constructors conservatively. Unresolved
dynamic edges cannot be counted as proof of a root path. Classes are separate
nodes from their methods. A documented deferral needs a nonempty task and reason;
it is emitted as a deferral, never silently accepted as wiring.

For all-source existing orphan findings, report their standing without pretending
this lane can repair unrelated domains. The deciding regression set consists of
new callable bodies and mechanisms that lose their formerly resolved root path
relative to the supplied base. Public concrete functions/methods are mechanisms;
annotations, protocol declarations, DTO fields and private helpers are not an
independent acceptance set, though helper edges are traversed. New latent
behavior with reflective adoption must carry an explicit declared limitation
or named caller task, not an invented static edge.

Every future mechanism decision document must name its non-test production
caller and runnable terminus, or its named deferred caller task and reason.
The pattern register's existing P01/P02 maintenance instruction will carry
this rule. No new status enum, governance gate or institution is created.

Rejected: a grep count, import-only check, fixed five-symbol allowlist, or new
helper called only by its own tests. Also rejected: pretending static reachability
proves semantic admission or automatically treating every historically uncalled
library export as an authorized repair task.
