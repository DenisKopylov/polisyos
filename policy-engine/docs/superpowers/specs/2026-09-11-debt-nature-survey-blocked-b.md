The pattern pass applies P01/P02/P03/P05/P29/P32/P35/P36/P37/P38: separate source slot from candidate artifact, institutional act from our intake, refusal from a missing positive consumer, and matching names from shared deciding properties. For each row, *unblocks* means a prerequisite changes; *discharges* means the row's full stated property is demonstrated. A typed `None` placeholder is not automatically a fillable admission port. Dynamic checks use the existing main-worktree interpreter read-only, explicitly bind imported modules to this worktree's `src`, and run only existing tests. No appointment or new test is made.

The five questions are recorded in both the per-row prose and the assessment: **Q1** identifies the exact narrower/false premise without declaring the full row discharged; **Q2** names its wider demanded denominator; **Q3** permits reduction only by a shared deciding property; **Q4** states mechanism, missing work and holder, separating unblocking from discharge; **Q5** tests the actual source slot, caller and appointment counterfactual. `Measured` concerns a source body, complete census or actual test/data result; the implication of a fixed negative for a hypothetical appointment is an inference; uninspected alternative implementations and formal institutions remain unestablished.
