# Bureaucratic Rendering Assets

These assets are placeholders for PolicyOS draft rendering.

- `tryzub.svg` is a simplified, non-official outline marker. It is not a seal,
  signature, state emblem reproduction, or proof of state authority.
- `draft-watermark.svg` carries the mandatory draft disclaimer:
  `Generated by PolicyOS / Draft / Not an official state document`.

Legal/document review remains required before replacing placeholders with any
jurisdiction-specific public-domain or licensed symbol. Renderers must keep the
visible and machine-readable watermark in all exported artifacts.
