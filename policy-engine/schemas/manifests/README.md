# Manifest Schemas

Canonical JSON Schemas for stage, publish, lineage, snapshot, and generated
artifact manifests.

Planned examples:

```text
manifests/
|-- stage_manifest_v1.json
|-- publish_manifest_v1.json
|-- lineage_record_v1.json
`-- snapshot_commit_v1.json
```

Manifest schema changes require compatibility rules and migration entries.
