# snapshots — Contract-Check Baseline

`snapshots/` contains the committed baseline CI uses to check drift and ABI/connector-contract compatibility.

## Structure

The current baseline tree contains `ir/`, `fabric/`, and `connectors/`. There is no `scientist/` directory here. This is a short map of the main artifacts, not a complete file listing:

- `ir/_manifest.json` and `ir/*.schema.json`;
- `fabric/_manifest.json`, `fabric/*.schema.json`, and adjacent JSON artifacts;
- `connectors/contracts.json`.

## Subdirectory Roles

| Directory              | Purpose                                                                  |
| ---------------------- | ------------------------------------------------------------------------ |
| `snapshots/ir`         | ABI JSON Schema for IR models (`src/polisyos/ir/**`)                     |
| `snapshots/fabric`     | ABI JSON Schema for the world-ABI enums (`src/polisyos/ir/world/abi.py`) |
| `snapshots/connectors` | Baseline for source-connector contracts                                  |

## Artifact Format

- `ir` and `fabric`: schema snapshots and `_manifest.json`, generated by `tools/quality/diagnostics/gen_schema.py`.
- `fabric/` also contains `connector_contract_registry.json`, `source_contracts_v2.json`, and `source_scorecards.json`.
- The current snapshot tree has no directory for versioned Scientist payloads; this inventory does not describe their runtime serialization behavior.
- IR/Fabric manifests carry per-model compatibility, lifecycle, and hash metadata. Version-variant runtime behavior is outside this snapshot inventory.
- `connectors/contracts.json`: format `version=1`, with the `contracts` payload keyed by `contract_id`.

## Canonical Inventory Sources

The contents and generation time of the IR and Fabric baselines are recorded in `ir/_manifest.json` and `fabric/_manifest.json`; the connector-contract inventory is in `connectors/contracts.json`. Read these tracked artifacts as the inventory. This README intentionally does not duplicate their changing counts and timestamps.

## Commands (from `policy-engine/`)

```bash
# Check the baseline
python3 tools/quality/diagnostics/gen_schema.py --check
uv run polisyos-tools connectors check-contracts --check
```

```bash
# Update the baseline
python3 tools/quality/diagnostics/gen_schema.py
uv run polisyos-tools connectors check-contracts --update
```

## Invariants

- Do not manually edit `ir/*.schema.json`, `fabric/*.schema.json`, or `_manifest.json`.
- Do not edit `connectors/contracts.json` manually; update it only through `check_contracts.py --update`.
