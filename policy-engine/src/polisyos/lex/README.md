# Lex Module

Модуль Lex предоставляет высокоуровневый API для работы с юридическими документами, включая их обработку, анализ и оценку соответствия нормам.

## Архитектура

Модуль состоит из трех основных компонентов:

- **corpus** - управление корпусом юридических документов (ингест, структурирование, версионирование)
- **legal_evaluation** - оценка легальности и анализ соответствия
- **normpack** - сборка нормативных пакетов для конкретных юрисдикций

## Основные функции

### Управление документами
- `ingest_legal_doc_bytes()` - загрузка и первичная обработка юридических документов
- `build_legal_structure()` - структурирование документов на разделы и статьи
- `build_version_index()` - построение индекса версий документов
- `resolve_active_version()` - определение активной версии документа на заданную дату

### Оценка легальности
- `evaluate_legality()` - оценка соответствия действий юридическим нормам
- `propose_changes()` - генерация предложений по изменениям на основе отчетов оценки

### Сборка нормативных пакетов
- `assemble_norm_pack()` - сборка пакета норм для конкретной юрисдикции и даты

## Связь с другими модулями

### Зависимости
- **fabric.docs** - обработка документов (нормализация, структурирование, чанкинг)
- **fabric.world** - управление мировым состоянием и событиями
- **fabric.claims** - извлечение и разрешение конфликтов норм
- **ir.world** - структуры данных для мировых объектов
- **core.contracts.lex** - контракты для юридических оценок

### Интеграция
- Использует FileSystemCAS для хранения артефактов
- Работает с SimulationDB для симуляций
- Интегрируется с provenance системой для отслеживания изменений

## Типы данных

- `LegalDocSource` - метаданные источника юридического документа
- `LexIngestResult` - результат обработки документа
- `NormPackBuildRequest/Result` - запрос/результат сборки нормативного пакета
- `LegalEvaluationRequest` - запрос на оценку легальности

## Ошибки

Модуль определяет специализированные исключения для различных типов ошибок:
- `LexIngestError` - ошибки загрузки документов
- `LexStructureError` - ошибки структурирования
- `LexValidationError` - ошибки валидации данных
- `LexVersioningError` - ошибки версионирования
