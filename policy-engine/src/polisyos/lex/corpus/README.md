# Corpus Module

Модуль Corpus отвечает за управление корпусом юридических документов, включая их загрузку, структурирование и версионирование.

## Компоненты

### ingest.py
Обработка входящих юридических документов:
- Загрузка сырых байтов документов
- Нормализация текста через fabric.docs
- Опциональное структурирование и чанкинг
- Сохранение метаданных в мировое состояние

### structure.py
Структурирование юридических документов:
- Автоматическое выявление статей и разделов
- Построение индекса положений (ProvisionIndex)
- Создание фрагментов документов
- Поддержка иерархической структуры (статьи → пункты → подпункты)

### versioning.py
Управление версиями документов:
- Построение индекса версий для источников документов
- Разрешение активной версии на заданную дату
- Политики выбора версий (по дате вступления в силу, публикации)
- Сохранение свойств источников документов

### index.py
Структуры данных для индексации:
- `VersionIndexV1` - индекс версий документов
- `ProvisionIndexV1` - индекс положений в документе
- `DocSourcePropsV1` - свойства источников документов
- Функции сериализации/десериализации индексов

## Основные функции

- `ingest_legal_doc_bytes()` - загрузка документа в систему
- `build_legal_structure()` - структурирование загруженного документа
- `build_version_index()` - построение индекса версий для источника
- `resolve_active_version()` - определение активной версии на дату

## Особенности

- Интегрируется с fabric.world для сохранения фактов
- Использует provenance для отслеживания происхождения данных
- Поддерживает различные MIME-типы документов
- Настраиваемые опции обработки через LexIngestOptions/StructureOptions

## Связь с другими модулями

- **fabric.docs** - обработка текста документов
- **fabric.world** - хранение мировых фактов и событий
- **ir.world** - структуры данных документов
- **core.artifacts** - хранение артефактов в CAS
