# Legal Evaluation Module

Модуль Legal Evaluation предоставляет систему оценки соответствия действий юридическим нормам и генерации предложений по изменениям.

## Компоненты

### evaluate.py
Основная логика оценки легальности:
- Интеграция с Trinity моделями для анализа
- Построение контекста через LegalContextBuilder
- Оценка правил на соответствие нормам
- Генерация отчетов о легальности

### change_proposals.py
Генерация предложений по изменениям:
- Анализ несоответствий в отчетах оценки
- Предложения корректирующих действий
- Работа с числовыми, булевыми и текстовыми метриками
- Определение severity и confidence для предложений

### evaluator_registry.py
Регистр оценщиков легальности:
- Динамическое обнаружение и загрузка оценщиков
- Поддержка entry points для расширений
- Управление версиями оценщиков
- Bootstrap процесс для инициализации

### context_builder.py
Построитель контекста для оценки:
- Сбор релевантных норм из NormPack
- Подготовка данных для Trinity моделей
- Фильтрация применимых правил
- Создание RuleObservation объектов

### backends/simple_v1.py
Простой backend оценки правил:
- Операторы сравнения для числовых значений
- Логические операторы для булевых значений
- Текстовые сравнения с нормализацией
- Настраиваемая строгость оценки

## Основные функции

- `evaluate_legality_impl()` - оценка соответствия нормам
- `propose_changes_impl()` - генерация предложений изменений
- `discover_and_bootstrap_evaluators()` - инициализация оценщиков

## Особенности

- Плагинируемая архитектура через component registry
- Интеграция с Trinity для сложного анализа
- Поддержка различных типов данных (числа, текст, булевы)
- Confidence scoring для предложений
- Severity levels (info, warning, blocker)

## Связь с другими модулями

- **ir.trinity** - Trinity модели для оценки
- **normpack** - источники нормативных правил
- **fabric.world** - сохранение результатов оценки
- **core.contracts.lex** - контракты для запросов/отчетов
- **core.components** - система плагинов оценщиков
