# NormPack Module

Модуль NormPack отвечает за сборку нормативных пакетов - структурированных коллекций норм для конкретных юрисдикций и доменов.

## Компоненты

### assemble_pack.py
Основная логика сборки нормативных пакетов:
- Выбор активных версий документов на заданную дату
- Извлечение норм из положений документов
- Разрешение конфликтов между нормами
- Оценка доверия к нормам
- Создание структурированного NormPack

### select_sources.py
Выбор источников документов для пакета:
- Разрешение активных версий через corpus.versioning
- Фильтрация по юрисдикции и домену
- Нормализация дат и периодов действия
- Построение списка SelectedDocVersion

### extract_norm_claims.py
Извлечение норм из текстов положений:
- Интеграция с fabric.claims.extractors
- Преобразование текста в структурированные нормы
- Поддержка различных типов правил (числовые, булевые, текстовые)
- Создание claim set артефактов

### policies.py
Конфигурация политик и констант:
- Политики выбора версий документов
- Политики разрешения конфликтов
- Политики оценки доверия
- Настройки доменов и юрисдикций
- Конфигурация типов положений для включения

### provider_registry.py
Регистр провайдеров нормативных пакетов:
- Плагинируемая система провайдеров
- Поддержка статических и динамических пакетов
- Управление доменами и юрисдикциями
- Bootstrap процесс для инициализации

### applicability.py
Определение применимости норм:
- Анализ условий применения правил
- Фильтрация норм по контексту
- Определение релевантных норм для оценки

## Основные функции

- `assemble_norm_pack()` - сборка полного нормативного пакета
- `normalize_as_of()` - нормализация даты для запросов
- `discover_and_bootstrap_providers()` - инициализация провайдеров

## Особенности

- Поддержка бюджетов (ограничения на количество документов/положений/норм)
- Разрешение конфликтов между противоречащими нормами
- Оценка доверия к источникам норм
- Кластеризация норм по типам и доменам
- Интеграция с SimulationDB для тестирования

## Связь с другими модулями

- **corpus** - источники документов и их версии
- **fabric.claims** - извлечение и разрешение конфликтов норм
- **ir.norm_pack** - структуры данных нормативных пакетов
- **core.components** - система плагинов провайдеров
- **fabric.io.db** - работа с симуляционными базами данных
