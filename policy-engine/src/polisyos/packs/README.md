# PolicyOS Built-in Component Packs

Встроенные компонентные пакеты для PolicyOS Phase 19, предоставляющие готовые компоненты для различных доменов.

## Архитектура

Папка `packs` содержит модульные компоненты, организованные по доменам. Каждый пакет предоставляет набор компонентов для конкретной предметной области.

## Доступные пакеты

### `econ/`
Экономический пакет для демонстрации конфликтов IR-фрагментов. Содержит альтернативные определения единиц измерения для тестирования приоритетов.

**Компоненты:**
- `econ.ir.registry_fragment@1.0.0` - Конфликтный фрагмент единиц измерения скорости (kmh)

### `roads/`
Полнофункциональный дорожный пакет с компонентами для моделирования транспортных правил и ограничений.

**Компоненты:**
- `roads.ir.registry_fragment@1.0.0` - Базовые единицы измерения для дорог
- `roads.method.speed_cap@1.0.0` - Метод ограничения скорости агентов
- `roads.scholar.speed_limit@1.0.0` - Экстрактор ограничений скорости из текста
- `lex.norm_extractor.regex_v1@1.0.0` - Регулярный экстрактор норм
- `lex.eval.simple_v1@1.0.0` - Простой оценщик легальности
- `roads.normpack.static_provider@1.0.0` - Статический провайдер норм для дорог

## Связь с другими модулями

- **core/components** - Базовые интерфейсы компонентов
- **ir/** - Работа с IR-фрагментами и единицами измерения
- **foundry/** - Методы моделирования и компиляции
- **lex/** - Лингвистическая обработка и оценка норм
- **fabric/** - Экстракция фактов и claims
- **scientist/** - Научные методы и workflows

## Особенности

- **Модульность**: Каждый пакет независим и может использоваться отдельно
- **Конфликты**: Пакет `econ` демонстрирует обработку конфликтов между компонентами
- **Демо-ориентированность**: Компоненты оптимизированы для демонстраций и тестирования
- **Статическая природа**: Большинство компонентов предоставляют статические данные для UA юрисдикции
