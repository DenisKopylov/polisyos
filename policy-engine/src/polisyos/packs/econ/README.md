# Econ Pack - Демонстрация конфликтов IR-фрагментов

Экономический пакет для демонстрации обработки конфликтов между компонентами PolicyOS.

## Архитектура

```
econ/
├── __init__.py          # Экспорт компонентов пакета
├── components.py         # Регистрация компонентов
└── ir_fragments.py       # Определение конфликтного IR-фрагмента
```

## Компоненты

### `econ.ir.registry_fragment@1.0.0`
**Тип:** IR Fragment Component

Конфликтный фрагмент реестра единиц измерения для демонстрации приоритетов. Определяет альтернативную единицу измерения скорости `roads.kmh` с приоритетом 90.

**Особенности:**
- Конфликтует с аналогичным компонентом из пакета `roads`
- Низкий приоритет (90) для демонстрации переопределения
- Используется в тестах precedence и conflict resolution

## Связь с другими модулями

- **ir.kernel.units** - Работа с единицами измерения
- **ir.registry_fragments** - Управление фрагментами реестра
- **core.components** - Базовые интерфейсы компонентов

## Назначение

Пакет `econ` предназначен исключительно для демонстрации механизмов разрешения конфликтов между компонентами. Показывает, как PolicyOS обрабатывает ситуации, когда несколько компонентов предоставляют одинаковые ресурсы с разными приоритетами.
