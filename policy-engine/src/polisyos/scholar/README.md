# Scholar: Система сбора и обогащения знаний

Модуль **Scholar** представляет собой интеллектуальную систему для автоматического сбора, обработки и обогащения знаний из различных источников данных. Система реализует полный пайплайн от обнаружения источников до формирования структурированных пакетов знаний.

## Архитектура

### Основные компоненты

- **`api.py`** - Основной API для работы с системой обогащения знаний
- **`types.py`** - Определения типов данных и структур пайплайна
- **`policies.py`** - Политики и настройки работы системы
- **`errors.py`** - Иерархия специализированных ошибок
- **`discover/`** - Модуль обнаружения и получения источников знаний
- **`orchestrator/`** - Оркестратор процесса обогащения знаний

### Ключевые абстракции

- **KnowledgeBundle** - структурированный пакет знаний с метаданными
- **EnrichmentReport** - отчет об обогащении с метриками качества
- **SourceSpec** - спецификация источника данных (URL, файл, байты)
- **ResearchIntent** - намерение исследования с параметрами

## Функционал

### Основной API

```python
from polisyos.scholar import ScholarService, enrich_topic

# Создание сервиса
service = ScholarService(
    fact_log_root=Path("/path/to/logs"),
    db=simulation_db,
    policy=scholar_policy
)

# Обогащение темы
result = service.enrich(cas_store, research_intent)
```

### Пайплайн обогащения

1. **Обнаружение** (`discover`) - сбор и нормализация источников
2. **Получение** (`acquire`) - загрузка данных из источников
3. **Обработка документов** (`docs`) - нормализация, структурирование, чанкинг
4. **Извлечение утверждений** (`claims`) - парсинг фактов из документов
5. **Разрешение конфликтов** (`reconcile`) - устранение противоречий
6. **Оценка доверия** (`trust`) - анализ надежности источников
7. **Формирование пакета** (`bundle`) - сбор финального результата

## Политики и ограничения

### Бюджеты
- Максимальное количество документов (по умолчанию: 16)
- Максимальный объем данных (по умолчанию: 20MB)
- Максимальное количество утверждений (по умолчанию: 2000)

### Пороги качества
- Минимальный уровень доверия источников (по умолчанию: MEDIUM)
- Настраиваемые параметры обработки документов и утверждений

## Связи с другими модулями

### Зависимости
- **`polisyos.core.artifacts`** - хранилище артефактов (CAS)
- **`polisyos.core.contracts`** - контракты для данных
- **`polisyos.fabric.docs`** - обработка документов
- **`polisyos.fabric.claims`** - извлечение и нормализация утверждений
- **`polisyos.fabric.io.db`** - база данных симуляций
- **`polisyos.ir.world.trust`** - оценка доверия

### Использование в Scientist
Модуль Scholar интегрируется с модулем Scientist для:
- Автоматического сбора данных для экспериментов
- Обогащения контекста исследований
- Валидации источников информации

## Особенности реализации

- **Типизированные контракты** - все границы защищены типами данных
- **Content-addressed storage** - все артефакты адресуются по содержимому
- **Аудит и трассировка** - полный лог всех операций
- **Настраиваемые политики** - гибкая конфигурация поведения
- **Обработка ошибок** - специализированные исключения для каждой стадии

## Поддерживаемые типы источников

- **URL** - веб-страницы с автоматической нормализацией
- **Локальные файлы** - файлы с различных носителей
- **Байты в памяти** - программно генерируемые данные
- **Расширяемая архитектура** - поддержка новых типов источников
