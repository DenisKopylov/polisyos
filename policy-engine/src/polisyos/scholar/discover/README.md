# Discover: Модуль обнаружения и получения источников знаний

Модуль **Discover** отвечает за обнаружение, нормализацию и получение данных из различных источников знаний. Реализует унифицированный интерфейс для работы с разнородными источниками данных.

## Архитектура

### Основные компоненты

- **`manual.py`** - Ручное управление источниками и их нормализация
- **`http_fetch.py`** - Получение данных по HTTP/HTTPS URL
- **`local_files.py`** - Работа с локальными файлами
- **`__init__.py`** - Экспорт основных функций модуля

## Функционал

### Нормализация источников

```python
from polisyos.scholar.discover import normalize_seed_sources

# Нормализация списка источников
normalized_sources = normalize_seed_sources(seed_sources, max_docs=10)
```

**Особенности нормализации:**
- Канонизация URL (сортировка параметров, нормализация хоста)
- Разрешение путей для локальных файлов
- Генерация идентификаторов для байтовых данных
- Дедупликация по уникальным ключам
- Ограничение количества документов

### Получение данных

#### HTTP источники
```python
from polisyos.scholar.discover import fetch_url

result = fetch_url(
    source_spec,
    timeout_s=10.0,
    user_agent="polisyos-scholar/1.0",
    max_bytes=5_000_000
)
```

**Возможности:**
- Автоматическое определение MIME-типа
- Ограничение размера ответа
- Обработка HTTP ошибок
- Таймауты и пользовательские агенты

#### Локальные файлы
```python
from polisyos.scholar.discover import read_local_file

result = read_local_file(source_spec, max_bytes=10_000_000)
```

**Поддержка форматов:**
- Текстовые файлы (.txt, .html, .htm)
- Произвольные бинарные файлы (с явным mime_hint)
- Автоматическое определение MIME по расширению

## Типы источников

### URL источники
- **Канонизация**: нормализация URL, сортировка параметров
- **Валидация**: проверка корректности схемы и хоста
- **Метаданные**: лицензия, юрисдикция, язык, тип источника

### Локальные файлы
- **Разрешение путей**: обработка ~ и относительных путей
- **Валидация**: проверка существования файла
- **Идентификация**: полный путь как source_locator

### Байтовые данные
- **Хеширование**: SHA256 для идентификации
- **Локатор**: `bytes.sha256_{hash}` формат

## Ключевые функции

### `normalize_seed_sources()`
- Валидация и нормализация списка источников
- Дедупликация по идентификаторам
- Ограничение количества документов
- Сортировка для детерминированного поведения

### `source_identity_key()`
- Генерация уникального ключа для источника
- Приоритет: canonical_url > official_id > source_locator

### `fetch_url()` / `read_local_file()`
- Унифицированный результат `AcquireResult`
- Метаданные источника `DocSourceSpec`
- MIME-тип и необработанные байты

## Обработка ошибок

### Специализированные исключения
- **`ScholarValidationError`** - некорректные параметры
- **`ScholarAcquireError`** - ошибки получения данных
- **`ScholarDiscoverError`** - ошибки обнаружения источников

### Валидация данных
- Проверка обязательных полей для каждого типа источника
- Валидация URL форматов
- Проверка существования файлов
- Ограничения размеров

## Особенности реализации

- **Идемпотентность** - повторные вызовы дают одинаковый результат
- **Безопасность** - ограничения размеров, таймауты
- **Расширяемость** - простой интерфейс для новых типов источников
- **Типизация** - полная типизация с Pydantic моделями
