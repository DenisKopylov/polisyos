# Research DAG Methods (`polisyos.scientist.methods.research_dag`)

Research DAG methods own the models, persistence, projections, diffing,
invalidation, comparison, and replay helpers that make Scientist research paths
auditable and reproducible.

Legacy imports from `polisyos.scientist.research_dag` remain supported through a
compatibility shim until `2027-03-02`; new first-party code should use this
canonical package.
