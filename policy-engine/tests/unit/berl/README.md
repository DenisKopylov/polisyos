# BERL unit tests

This mirrored suite covers the Bounded Explanation Reliability Layer: explanation
contracts, persistence, metrics, adapters and service behavior. Package-level API and
current authority limits are documented in [`src/polisyos/berl/README.md`](../../../src/polisyos/berl/README.md).

Run the suite from `policy-engine/` with `uv run pytest tests/unit/berl -q`.
