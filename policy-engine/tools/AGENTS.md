# Measurement rules for tools

Write or update repository documentation in English, following the
[documentation language policy](../docs/reference/documentation-language.md).

Before adding or changing a checker, diagnostic, audit or absence verdict, follow
[Authoring repository measurement instruments](../docs/how-to/author-measurement-instruments.md).
Actual inputs, selection limits and named unresolved boundaries travel with the
verdict. Prove the original failure and the outside-selector counterexample through
the real caller. Register readers tokenize cells before assigning column roles.
